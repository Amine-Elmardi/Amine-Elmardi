FI-L1-001 · L1

Altersklassen fehlen im Debitorenbericht

Problem

Die benötigten Fälligkeits- oder Altersklassenspalten werden nicht angezeigt.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Berichtsvariante oder Layout enthält die Felder nicht.

Betroffene Module

FI-AR

Transaktionen

FBL5N, S_ALR_87012168

Analyse / Anforderungen

  1. Bericht und benötigte Felder bestimmen
  2. Gewähltes Layout prüfen

Lösung

  1. Verfügbare Fälligkeits- und Altersklassenspalten im Layout ergänzen
  2. Layout zur Wiederverwendung speichern

Erfolgskontrolle / Customizing

Spalten im Bericht kontrollieren. Feldverfügbarkeit für eingesetzte Version prüfen.

Einordnung

L1: Operativer Support.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
