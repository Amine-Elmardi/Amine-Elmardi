FI-L1-001 · L1

Colonnes d’ancienneté absentes du rapport client

Problème

Les colonnes d’échéance nécessaires ne sont pas visibles.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La variante ou présentation exclut ces champs.

Modules concernés

FI-AR

Transactions

FBL5N, S_ALR_87012168

Diagnostic / besoins

  1. Identifier rapport et champs requis
  2. Examiner la présentation sélectionnée

Solution

  1. Ajouter les colonnes disponibles liées aux échéances
  2. Enregistrer la présentation

Validation / paramétrage

Vérifier les colonnes dans le rapport et leur disponibilité selon la version.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
