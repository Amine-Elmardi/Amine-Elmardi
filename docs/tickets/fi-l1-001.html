FI-L1-001 · L1

Ageing columns missing from customer report

Problem

The user cannot see the required due-date ageing columns in the report.

Error message / number

Exact error text and number not provided.

Root cause

The selected report variant or layout excludes the fields.

Affected modules

FI-AR

Transactions

FBL5N, S_ALR_87012168

Diagnosis / requirements

  1. Identify the report and required ageing fields
  2. Review the selected layout

Solution

  1. Add the applicable due-date ageing columns through the report layout
  2. Save the layout for reuse

Validation / configuration

Confirm the columns are available in the selected report; verify field availability for the actual version.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
