FI-L1-002 · L1

Fiche client requise pour un nouveau partenaire

Problème

Le client n’est pas disponible pour la société ou le domaine commercial prévu.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La fiche manque ou n’a pas été étendue.

Modules concernés

FI-AR / SD

Transactions

XD01, FD01, BP

Diagnostic / besoins

  1. Identifier groupe, société et domaine
  2. Vérifier les données existantes

Solution

  1. Créer ou étendre le client autorisé via XD01/FD01/BP selon version
  2. Maintenir données générales, société et commerciales requises

Validation / paramétrage

Vérifier compte collectif et disponibilité.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
