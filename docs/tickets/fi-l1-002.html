FI-L1-002 · L1

Customer master required for a new business partner

Problem

A customer is unavailable for the intended company code or sales area.

Error message / number

Exact error text and number not provided.

Root cause

The customer master does not exist or has not been extended.

Affected modules

FI-AR / SD

Transactions

XD01, FD01, BP

Diagnosis / requirements

  1. Identify required account group, company code and sales area
  2. Check existing master data

Solution

  1. Create or extend the authorized customer master using the applicable XD01/FD01/BP route
  2. Maintain general, company-code and sales-area data as required

Validation / configuration

Verify reconciliation account and availability for the intended process.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
