FI-L1-003 · L1

Compte général bloqué à la comptabilisation

Problème

Un utilisateur ne peut pas imputer un compte existant.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le segment société comporte un blocage ou une restriction.

Modules concernés

FI-GL

Transactions

FS00, FS03

Diagnostic / besoins

  1. Afficher le compte dans FS03 ou FS00
  2. Confirmer avec FI si le blocage est volontaire

Solution

  1. Lever le blocage erroné dans FS00 après accord
  2. Conserver les restrictions voulues

Validation / paramétrage

Vérifier l’écriture autorisée sans modifier les autres réglages.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
