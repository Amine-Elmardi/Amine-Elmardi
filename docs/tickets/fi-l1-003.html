FI-L1-003 · L1

Posting blocked on a G/L account

Problem

A user cannot post to an existing account.

Error message / number

Exact error text and number not provided.

Root cause

The company-code segment contains a posting restriction or block.

Affected modules

FI-GL

Transactions

FS00, FS03

Diagnosis / requirements

  1. Display the account in FS03 or FS00
  2. Confirm with the FI lead whether the restriction is intentional

Solution

  1. Remove an erroneous block in FS00 only after approval
  2. Keep intentional restrictions in place

Validation / configuration

Confirm the approved posting is possible without changing unrelated account settings.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
