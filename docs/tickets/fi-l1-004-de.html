FI-L1-004 · L1

Benötigte Spalte in Sachkonten-Einzelpostenliste fehlt

Problem

Ein Anwender sieht ein benötigtes Feld wie Zuordnung oder Profitcenter nicht.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Das gewählte Layout enthält das Feld nicht.

Betroffene Module

FI-GL

Transaktionen

FBL3N

Analyse / Anforderungen

  1. Bericht öffnen und aktuelles Layout prüfen

Lösung

  1. Benötigte Spalte über Layout ändern in FBL3N hinzufügen
  2. Zulässiges benutzerspezifisches oder allgemeines Layout speichern

Erfolgskontrolle / Customizing

Bericht erneut öffnen und Spalte kontrollieren.

Einordnung

L1: Operativer Support.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
