FI-L1-004 · L1

Colonne manquante dans la liste des postes généraux

Problème

L’utilisateur ne voit pas un champ requis, par exemple affectation ou centre de profit.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La présentation sélectionnée exclut le champ.

Modules concernés

FI-GL

Transactions

FBL3N

Diagnostic / besoins

  1. Ouvrir le rapport et examiner la présentation

Solution

  1. Ajouter la colonne via modification de présentation dans FBL3N
  2. Enregistrer la présentation personnelle ou générale autorisée

Validation / paramétrage

Rouvrir le rapport et vérifier la colonne.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
