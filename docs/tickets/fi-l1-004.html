FI-L1-004 · L1

Required column missing from G/L line item report

Problem

The user cannot see a needed reporting field, such as assignment or profit center.

Error message / number

Exact error text and number not provided.

Root cause

The selected layout excludes that field.

Affected modules

FI-GL

Transactions

FBL3N

Diagnosis / requirements

  1. Open the report and inspect the current layout

Solution

  1. Add the required column through Change Layout in FBL3N
  2. Save the permitted user-specific or general layout

Validation / configuration

Reopen the report and verify the column is displayed.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
