FI-L1-005 · L1

Nouvelle fiche fournisseur requise

Problème

Un nouveau fournisseur est indisponible pour les achats et la comptabilité.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La fiche manque pour la société et l’organisation d’achats.

Modules concernés

FI-AP / MM

Transactions

XK01, FK01, BP

Diagnostic / besoins

  1. Confirmer groupe de comptes et périmètre organisationnel.

Solution

  1. Créer le fournisseur via la transaction applicable
  2. Renseigner données générales, société, achats, compte collectif et conditions de paiement.

Validation / paramétrage

Vérifier la disponibilité pour les unités concernées.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
