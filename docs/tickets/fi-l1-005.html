FI-L1-005 · L1

New supplier master required

Problem

A newly onboarded supplier is unavailable for purchasing and accounting.

Error message / number

Exact error text and number not provided.

Root cause

The master record is missing for the required company code and purchasing organization.

Affected modules

FI-AP / MM

Transactions

XK01, FK01, BP

Diagnosis / requirements

  1. Confirm account group and organizational scope.

Solution

  1. Create the supplier using the applicable transaction
  2. Maintain general, company-code and purchasing data, reconciliation account and payment terms.

Validation / configuration

Verify availability for the intended organizational units.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
