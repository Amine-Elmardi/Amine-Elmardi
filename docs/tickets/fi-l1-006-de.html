FI-L1-006 · L1

Lieferant nicht auf weiteren Buchungskreis erweitert

Problem

Ein vorhandener Lieferant ist für eine neue Geschäftseinheit nicht nutzbar.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Zentraler Stammsatz vorhanden, benötigtes Buchungskreissegment fehlt.

Betroffene Module

FI-AP / MM

Transaktionen

XK01, XK02

Analyse / Anforderungen

  1. Bestehenden Lieferanten und gewünschten Buchungskreis prüfen.

Lösung

  1. Lieferanten über den passenden XK01-Referenzweg erweitern
  2. Buchungskreisspezifische Zahlungs- und Abstimmkontodaten pflegen.

Erfolgskontrolle / Customizing

Verfügbarkeit im neuen Buchungskreis kontrollieren.

Einordnung

L1: Operativer Support.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
