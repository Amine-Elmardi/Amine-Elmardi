FI-L1-006 · L1

Fournisseur non étendu à une nouvelle société

Problème

Un fournisseur existant est inutilisable pour une nouvelle unité.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La fiche centrale existe mais le segment société manque.

Modules concernés

FI-AP / MM

Transactions

XK01, XK02

Diagnostic / besoins

  1. Vérifier fournisseur existant et société demandée.

Solution

  1. Étendre via l’approche XK01 avec référence si applicable
  2. Maintenir données de paiement et compte collectif propres à la société.

Validation / paramétrage

Vérifier la disponibilité dans la nouvelle société.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
