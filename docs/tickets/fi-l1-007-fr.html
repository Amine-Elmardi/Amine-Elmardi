FI-L1-007 · L1

Centre de coûts bloqué pour coûts réels

Problème

Les utilisateurs ne peuvent pas imputer les coûts réels.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La fiche contient un blocage des coûts primaires, secondaires ou produits réels.

Modules concernés

CO-OM

Transactions

KS02, KS03

Diagnostic / besoins

  1. Afficher le centre dans KS03
  2. Confirmer le motif avec CO.

Solution

  1. Lever uniquement le blocage erroné après accord dans KS02.

Validation / paramétrage

Retester l’écriture autorisée et conserver les restrictions voulues.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
