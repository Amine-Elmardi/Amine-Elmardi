FI-L1-007 · L1

Cost center blocked for actual costs

Problem

Users cannot post actual costs to an existing center.

Error message / number

Exact error text and number not provided.

Root cause

Master data contains a lock for actual primary or secondary costs or revenues.

Affected modules

CO-OM

Transactions

KS02, KS03

Diagnosis / requirements

  1. Display the center in KS03
  2. Confirm the reason with the CO lead.

Solution

  1. Remove only the erroneous lock in KS02 after approval.

Validation / configuration

Retest the authorized posting; preserve intentional restrictions.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
