FI-L1-008 · L1

Centre de coûts requis pour un nouveau service

Problème

Un nouveau service nécessite un objet de collecte des coûts.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le centre correspondant manque.

Modules concernés

CO-OM

Transactions

KS01, KS02

Diagnostic / besoins

  1. Confirmer périmètre analytique, catégorie et hiérarchie.

Solution

  1. Créer le centre approuvé dans KS01
  2. Communiquer le code aux services concernés.

Validation / paramétrage

Vérifier fiche et disponibilité.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
