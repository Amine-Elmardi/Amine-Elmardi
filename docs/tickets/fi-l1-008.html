FI-L1-008 · L1

Cost center needed for new department

Problem

A new department needs an object for cost collection.

Error message / number

Exact error text and number not provided.

Root cause

No cost center represents the department.

Affected modules

CO-OM

Transactions

KS01, KS02

Diagnosis / requirements

  1. Confirm controlling area, category and hierarchy area.

Solution

  1. Create the approved cost center in KS01
  2. Communicate the code to relevant departments.

Validation / configuration

Check master data and availability.

Classification

L1: Operational support.
