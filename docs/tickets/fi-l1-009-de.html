FI-L1-009 · L1

Innenauftragsstatus blockiert Istbuchung

Problem

Eine Istkostenbuchung scheitert an einer Statusmeldung.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Der Innenauftrag steht auf CRTD (Angelegt) statt REL (Freigegeben).

Betroffene Module

CO-OM

Transaktionen

KO02, KO01

Analyse / Anforderungen

  1. Status in KO02 prüfen
  2. Freigabeberechtigung bestätigen.

Lösung

  1. Auftrag nach Genehmigung über Statusfunktion freigeben
  2. Buchung wiederholen.

Erfolgskontrolle / Customizing

REL-Status und Buchungsergebnis kontrollieren.

Einordnung

L1: Operativer Support.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
