FI-L1-015 · L1

Managementbericht benötigt zusätzliche Spalte

Problem

Das Reportingteam braucht ein weiteres Feld in regelmäßigen Einzelpostenauswertungen.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Das Standardlayout enthält das benötigte Feld nicht.

Betroffene Module

FI-GL / FI-AR / FI-AP

Transaktionen

FBL3N, FBL5N, FBL1N

Analyse / Anforderungen

  1. Bericht und gewünschtes Feld bestimmen
  2. Verfügbarkeit über Layout ändern prüfen.

Lösung

  1. Verfügbares Feld ergänzen und genehmigtes gemeinsames Layout speichern.

Erfolgskontrolle / Customizing

Gespeichertes Layout erneut öffnen und Spalte prüfen.

Einordnung

L1: Operativer Support.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
