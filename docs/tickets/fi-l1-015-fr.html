FI-L1-015 · L1

Colonne supplémentaire requise pour le reporting de gestion

Problème

L’équipe souhaite un champ supplémentaire dans les rapports récurrents.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La présentation par défaut exclut le champ.

Modules concernés

FI-GL / FI-AR / FI-AP

Transactions

FBL3N, FBL5N, FBL1N

Diagnostic / besoins

  1. Identifier rapport et champ
  2. Vérifier sa disponibilité dans la modification de présentation.

Solution

  1. Ajouter le champ disponible et enregistrer la présentation partagée autorisée.

Validation / paramétrage

Rouvrir et vérifier la colonne.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
