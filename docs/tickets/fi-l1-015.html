FI-L1-015 · L1

Management report layout needs an additional column

Problem

The reporting team needs an extra field in recurring line-item reviews.

Error message / number

Exact error text and number not provided.

Root cause

The default layout excludes the required field.

Affected modules

FI-GL / FI-AR / FI-AP

Transactions

FBL3N, FBL5N, FBL1N

Diagnosis / requirements

  1. Identify report and requested field
  2. Check whether the field is available in Change Layout.

Solution

  1. Add the available field and save the authorized shared layout for the reporting team.

Validation / configuration

Reopen the saved layout and confirm the column appears.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
