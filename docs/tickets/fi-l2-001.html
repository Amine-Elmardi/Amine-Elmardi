FI-L2-001 · L2

Changed field status not reflected in new postings

Problem

New entries still display fields according to an outdated setting.

Error message / number

Exact error text and number not provided.

Root cause

The G/L account references an incorrect field status group or variant.

Affected modules

FI-GL

Transactions

FS00, OBC4

Diagnosis / requirements

  1. Review the company-code segment in FS00 and field status settings in OBC4

Solution

  1. Correct the approved field status group assignment on the G/L account
  2. Escalate shared variant changes separately

Validation / configuration

Test a new posting and confirm required fields appear correctly.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
