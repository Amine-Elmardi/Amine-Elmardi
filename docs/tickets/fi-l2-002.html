FI-L2-002 · L2

Credit memo not cleared against original invoice

Problem

A customer credit memo remains open instead of offsetting its invoice.

Error message / number

Exact error text and number not provided.

Root cause

The assignment number differs and automatic clearing criteria do not match.

Affected modules

FI-AR

Transactions

F-32, OB74

Diagnosis / requirements

  1. Compare original invoice and credit memo references and amounts

Solution

  1. Manually clear the confirmed matching items via F-32
  2. Review any broader OB74 criteria change separately with finance

Validation / configuration

Check clearing status; test approved rule changes independently.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
