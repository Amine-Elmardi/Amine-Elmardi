FI-L2-003 · L2

Kreditsperre verhindert Auftragsfreigabe

Problem

Der Vertrieb kann einen Auftrag für einen gesperrten Debitor nicht freigeben.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Eine Kredit- oder Buchungssperre wurde gesetzt, etwa wegen überschrittener Kreditgrenze.

Betroffene Module

FI-AR / SD

Transaktionen

FD32, XD02, VKM3

Analyse / Anforderungen

  1. Sperrgrund und Kreditstatus in FD32/XD02 prüfen
  2. Kreditverantwortliche einbinden

Lösung

  1. Betroffene Sperre nur nach Zahlung oder ausdrücklicher Freigabe aufheben
  2. Auftragsfreigabe über genannte VKM3-Referenz abstimmen

Erfolgskontrolle / Customizing

Auftragsverarbeitung unter Einhaltung genehmigter Kreditkontrollen prüfen.

Einordnung

L2: Funktionale Analyse.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
