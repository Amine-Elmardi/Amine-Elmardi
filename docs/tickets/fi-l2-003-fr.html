FI-L2-003 · L2

Blocage crédit empêchant la libération de commande

Problème

La vente ne peut pas libérer une commande client bloquée.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Un blocage crédit ou comptable a été appliqué, par exemple après dépassement de limite.

Modules concernés

FI-AR / SD

Transactions

FD32, XD02, VKM3

Diagnostic / besoins

  1. Examiner motif et statut dans FD32/XD02
  2. Consulter le responsable crédit

Solution

  1. Lever uniquement le blocage approuvé après paiement ou autorisation
  2. Coordonner la libération selon la référence VKM3

Validation / paramétrage

Vérifier le traitement conforme au contrôle crédit.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
