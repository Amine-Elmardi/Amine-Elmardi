FI-L2-003 · L2

Customer credit block prevents sales order release

Problem

Sales cannot release an order for a blocked customer.

Error message / number

Exact error text and number not provided.

Root cause

A credit or posting block was applied, for example after overdue balances exceeded the limit.

Affected modules

FI-AR / SD

Transactions

FD32, XD02, VKM3

Diagnosis / requirements

  1. Review the customer block reason and credit status in FD32/XD02
  2. Consult the credit controller

Solution

  1. Release the relevant block only after payment or formal approval as applicable
  2. Coordinate the sales order release via the documented VKM3 reference

Validation / configuration

Confirm the order can proceed within approved credit controls.
