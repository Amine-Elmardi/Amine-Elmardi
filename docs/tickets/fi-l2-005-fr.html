FI-L2-005 · L2

Période comptable FI fermée

Problème

Une écriture est rejetée car la période requise est fermée.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La variante de période est fermée pour la période ou le type de compte.

Modules concernés

FI-GL

Transactions

OB52, OB65

Diagnostic / besoins

  1. Identifier date, variante et type de compte
  2. Examiner OB52 et obtenir l’accord du contrôleur

Solution

  1. Faire ouvrir uniquement la période et le type de compte autorisés par l’équipe responsable

Validation / paramétrage

Vérifier l’écriture et le périmètre approuvé.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
