FI-L2-005 · L2

FI posting period closed

Problem

A posting is rejected because the required accounting period is not open.

Error message / number

Exact error text and number not provided.

Root cause

The posting period variant is closed for the period or account type.

Affected modules

FI-GL

Transactions

OB52, OB65

Diagnosis / requirements

  1. Identify posting date, variant and affected account type
  2. Check OB52 and confirm authorization with the finance controller

Solution

  1. Have the responsible team open the required period for the applicable account type only after authorization

Validation / configuration

Confirm the posting can proceed and the approved period scope is respected.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
