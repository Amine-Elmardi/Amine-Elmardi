FI-L2-006 · L2

Évaluation en devises avec cours incorrect

Problème

L’évaluation n’utilise pas le cours attendu à la date de référence.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le cours manque pour le type sélectionné ou la méthode utilise un type incorrect.

Modules concernés

FI-GL

Transactions

OB08, OB59, FAGL_FC_VAL

Diagnostic / besoins

  1. Identifier date et type
  2. Examiner cours OB08 et méthode OB59

Solution

  1. Maintenir le cours manquant autorisé
  2. Transmettre toute correction de méthode au paramétrage
  3. Relancer après contrôle

Validation / paramétrage

Comparer le résultat au cours et à la méthode approuvés.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
