FI-L2-006 · L2

Foreign currency valuation uses incorrect exchange rate

Problem

Valuation does not use the expected rate for the valuation date.

Error message / number

Exact error text and number not provided.

Root cause

The rate is missing for the selected exchange-rate type or the method references the wrong type.

Affected modules

FI-GL

Transactions

OB08, OB59, FAGL_FC_VAL

Diagnosis / requirements

  1. Identify valuation date and rate type
  2. Check rates in OB08 and method in OB59

Solution

  1. Maintain the authorized missing rate
  2. If the method is incorrect, escalate the configuration change
  3. Repeat valuation after review

Validation / configuration

Compare the valuation result with the approved rate and method.

Classification

L2: Functional analysis.
