FI-L2-007 · L2

Écriture générale rejetée par validation

Problème

Une écriture FI échoue lors de la validation.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Une règle spécifique active rejette la combinaison compte, centre de coûts ou domaine d’activité.

Modules concernés

FI-GL

Transactions

GGB0, OB28, FB50

Diagnostic / besoins

  1. Identifier société et point d’appel dans GGB0
  2. Examiner activation OB28 et valeurs saisies

Solution

  1. Corriger les données
  2. Si le métier approuve un changement de règle, transmettre la modification erreur vers avertissement au paramétrage

Validation / paramétrage

Retester la combinaison autorisée dans FB50 et contrôler la règle.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
