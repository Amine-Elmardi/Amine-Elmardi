FI-L2-007 · L2

GL posting rejected by validation

Problem

A journal entry fails a validation check.

Error message / number

Exact error text and number not provided.

Root cause

An active custom rule rejects the combination of account, cost center or business area.

Affected modules

FI-GL

Transactions

GGB0, OB28, FB50

Diagnosis / requirements

  1. Identify company code and failing call-up point in GGB0
  2. Review rule activation in OB28 and entered values

Solution

  1. Correct the posting data
  2. Only if the business approves a rule change, refer the error-to-warning change to customizing

Validation / configuration

Retest the permitted combination in FB50; confirm the intended control remains effective.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
