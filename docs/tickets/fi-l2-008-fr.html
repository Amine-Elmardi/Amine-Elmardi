FI-L2-008 · L2

Pièces préenregistrées absentes de la liste d’approbation

Problème

L’approbateur ne retrouve pas les pièces FI.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Les filtres société ou type de pièce ne correspondent pas, ou le workflow n’a pas démarré.

Modules concernés

FI-GL / Workflow

Transactions

FBV0, FBV3, FB03

Diagnostic / besoins

  1. Afficher la pièce dans FBV3
  2. Comparer filtres et déclencheur

Solution

  1. Utiliser la sélection correcte dans la transaction d’approbation
  2. Coordonner la correction approuvée du workflow si nécessaire

Validation / paramétrage

Vérifier la présence de la pièce pour l’approbateur prévu.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
