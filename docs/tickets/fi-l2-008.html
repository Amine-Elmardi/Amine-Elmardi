FI-L2-008 · L2

Parked documents missing from approval worklist

Problem

An approver cannot find parked accounting documents.

Error message / number

Exact error text and number not provided.

Root cause

The worklist filters do not match company code or document type, or workflow was not triggered.

Affected modules

FI-GL / Workflow

Transactions

FBV0, FBV3, FB03

Diagnosis / requirements

  1. Display the parked document in FBV3
  2. Compare worklist selection and release trigger

Solution

  1. Use the correct selection in the approval transaction
  2. If the workflow trigger is incorrect, coordinate its approved correction

Validation / configuration

Verify the document appears for the intended approver.

Classification

L2: Functional analysis.
