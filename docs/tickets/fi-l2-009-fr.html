FI-L2-009 · L2

Total d’ancienneté clients différent du compte collectif

Problème

Le rapport clients ne concorde pas avec le solde général.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Dans le scénario, une écriture directe a contourné l’auxiliaire client.

Modules concernés

FI-AR / FI-GL

Transactions

FBL3N, FBL5N

Diagnostic / besoins

  1. Comparer postes clients FBL5N et compte FBL3N
  2. Identifier l’écriture directe non rapprochée

Solution

  1. Coordonner annulation autorisée et nouvelle écriture via le client

Validation / paramétrage

Refaire le rapprochement AR-GL et vérifier l’écart.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
