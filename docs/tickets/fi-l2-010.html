FI-L2-010 · L2

Recurring journal entry not generated

Problem

Scheduled recurring postings are missing.

Error message / number

Exact error text and number not provided.

Root cause

The posting run was omitted or the recurring document run-date settings are inconsistent.

Affected modules

FI-GL

Transactions

F.14, FBD1, FBD3

Diagnosis / requirements

  1. Display the recurring document in FBD3
  2. Review the last execution date and planned schedule

Solution

  1. Correct the authorized schedule
  2. Execute the recurring entry program through F.14

Validation / configuration

Check generated documents against the expected recurrence and avoid duplicate postings.

Classification

L2: Functional analysis.
