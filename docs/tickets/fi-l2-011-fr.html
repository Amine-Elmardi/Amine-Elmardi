FI-L2-011 · L2

Écart entre comptabilité auxiliaire et générale

Problème

Le rapprochement révèle des soldes différents.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le scénario cite un type de pièce inadapté ou une écriture directe sur un compte collectif.

Modules concernés

FI-GL / AR / AP

Transactions

FBL3N, FS10N, FB03

Diagnostic / besoins

  1. Comparer soldes FS10N et postes FBL3N
  2. Examiner les pièces suspectes dans FB03

Solution

  1. Identifier l’écriture directe erronée
  2. Coordonner annulation et nouvelle écriture approuvées via l’auxiliaire approprié

Validation / paramétrage

Refaire le rapprochement et documenter l’écart corrigé.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
