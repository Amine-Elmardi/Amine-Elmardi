FI-L2-011 · L2

Subledger balance differs from general ledger

Problem

A reconciliation reveals different balances between the subsidiary ledger and G/L.

Error message / number

Exact error text and number not provided.

Root cause

The scenario attributes the difference to an incorrect document type or a direct reconciliation-account posting.

Affected modules

FI-GL / AR / AP

Transactions

FBL3N, FS10N, FB03

Diagnosis / requirements

  1. Compare balances in FS10N and line items in FBL3N
  2. Inspect suspect documents in FB03

Solution

  1. Identify the erroneous direct posting
  2. Coordinate approved reversal and reposting through the appropriate subledger

Validation / configuration

Repeat reconciliation and document the corrected difference.

Classification

L2: Functional analysis.
