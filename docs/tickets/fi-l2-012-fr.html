FI-L2-012 · L2

Retenue à la source absente sur opération client

Problème

Un acompte ou une facture client ne calcule pas la retenue attendue.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Type ou code de retenue client absent, ou retenue étendue inactive pour la société.

Modules concernés

FI-AR / WHT

Transactions

XD02, OBWW, FK02

Diagnostic / besoins

  1. Examiner données client et paramètres société
  2. Confirmer le traitement fiscal attendu

Solution

  1. Maintenir type et code approuvés
  2. Transmettre toute activation société comme changement de paramétrage distinct

Validation / paramétrage

Tester l’opération. FK02 est cité sans que son applicabilité au client soit établie.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
