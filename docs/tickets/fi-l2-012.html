FI-L2-012 · L2

Withholding tax missing on customer transaction

Problem

A customer down payment or incoming invoice does not calculate the expected withholding tax.

Error message / number

Exact error text and number not provided.

Root cause

The customer tax type or code is missing, or extended withholding tax is not active for the company code.

Affected modules

FI-AR / WHT

Transactions

XD02, OBWW, FK02

Diagnosis / requirements

  1. Check customer withholding tax data and company-code settings
  2. Confirm the intended tax treatment

Solution

  1. Maintain approved customer withholding tax type and code
  2. Escalate any required company-code activation as a separate configuration change

Validation / configuration

Test the relevant customer transaction. FK02 is listed as a reference but its customer-process applicability is not established.

Classification

L2: Functional analysis.
