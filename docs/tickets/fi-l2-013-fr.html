FI-L2-013 · L2

Écart de rapprochement entre immobilisations et comptabilité générale

Problème

Le rapport révèle un écart entre immobilisations et comptes généraux.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Dans ce scénario, une écriture directe a contourné l’auxiliaire immobilisations.

Modules concernés

FI-AA / FI-GL

Transactions

ABST2, FS10N

Diagnostic / besoins

  1. Examiner ABST2 et comparer les soldes FS10N
  2. Identifier la pièce incohérente.

Solution

  1. Coordonner contrepassation autorisée et nouvelle écriture via la transaction d’immobilisation appropriée.

Validation / paramétrage

Refaire le rapprochement et vérifier la disparition de l’écart.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
