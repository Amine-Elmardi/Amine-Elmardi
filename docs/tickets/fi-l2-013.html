FI-L2-013 · L2

Asset accounting and general ledger reconciliation variance

Problem

The reconciliation report reveals a difference between assets and G/L.

Error message / number

Exact error text and number not provided.

Root cause

In this scenario a direct posting bypassed the asset subledger.

Affected modules

FI-AA / FI-GL

Transactions

ABST2, FS10N

Diagnosis / requirements

  1. Review the ABST2 reconciliation and compare account balances in FS10N
  2. Identify the inconsistent document.

Solution

  1. Coordinate authorized reversal and reposting through the appropriate asset transaction.

Validation / configuration

Repeat reconciliation and confirm the variance is resolved.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
