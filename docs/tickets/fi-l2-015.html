FI-L2-015 · L2

Asset transfer not reflected in cost center reporting

Problem

Reporting still shows the former cost center or business area after an asset transfer.

Error message / number

Exact error text and number not provided.

Root cause

Time-dependent asset master assignments were not updated correctly.

Affected modules

FI-AA / CO

Transactions

ABUMN, AS02, S_ALR_87011990

Diagnosis / requirements

  1. Review the transfer and time-dependent data in the asset master.

Solution

  1. Correct the approved time-dependent assignment in AS02.

Validation / configuration

Validate reporting using the asset history sheet.

Classification

L2: Functional analysis.
