FI-L2-016 · L2

Asset-under-construction settlement uses wrong receiver

Problem

Construction costs are assigned to an unintended receiver asset during settlement.

Error message / number

Exact error text and number not provided.

Root cause

The distribution or settlement rule refers to an incorrect or obsolete receiver.

Affected modules

FI-AA / CO / PS

Transactions

AIAB, AIBU, KO02

Diagnosis / requirements

  1. Review the AUC or WBS settlement rule and confirm the correct receiver.

Solution

  1. Correct the approved distribution rule
  2. Reprocess settlement in the appropriate sequence.

Validation / configuration

Check that the intended asset receives the settlement and reconcile remaining balances.
