FI-L2-017 · L2

Annulation intersociétés bloquée par le lettrage associé

Problème

L’annulation d’une facture fournisseur intersociétés échoue à une validation.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Une pièce liée est déjà lettrée alors qu’une seule partie doit être annulée.

Modules concernés

FI-AP / FI-GL

Transactions

FB08, FBU8

Diagnostic / besoins

  1. Identifier les deux pièces liées et leur statut de lettrage.

Solution

  1. Coordonner l’annulation de lettrage autorisée
  2. Contrepasser les pièces liées dans l’ordre intersociétés vérifié via FBU8 si applicable.

Validation / paramétrage

Rapprocher les deux sociétés et vérifier l’annulation complète.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
