FI-L2-017 · L2

Cross-company invoice reversal blocked by linked clearing

Problem

Reversal of a cross-company vendor invoice fails a validation check.

Error message / number

Exact error text and number not provided.

Root cause

One linked company-code document is already cleared while only one leg is being reversed.

Affected modules

FI-AP / FI-GL

Transactions

FB08, FBU8

Diagnosis / requirements

  1. Identify both linked accounting documents and their clearing status.

Solution

  1. Coordinate an authorized clearing reset on the linked document
  2. Reverse the related documents in the verified cross-company sequence using FBU8 as applicable.

Validation / configuration

Reconcile both company codes and ensure the reversal is complete.

Classification

L2: Functional analysis.
