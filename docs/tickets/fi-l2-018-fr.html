FI-L2-018 · L2

Traitement d’amortissement en erreur pour certaines immobilisations

Problème

AFAB signale des erreurs sur une partie du parc.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Un tableau contient des paramètres incohérents, par exemple clé absente ou valeur nette négative.

Modules concernés

FI-AA

Transactions

AFAB, AW01N

Diagnostic / besoins

  1. Examiner le journal AFAB et identifier les immobilisations
  2. Contrôler valeurs et paramètres dans AW01N.

Solution

  1. Corriger uniquement l’incohérence confirmée et approuvée
  2. Relancer le traitement applicable.

Validation / paramétrage

Vérifier les résultats et le journal.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
