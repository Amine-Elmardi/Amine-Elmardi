FI-L2-018 · L2

Depreciation run fails for selected assets

Problem

AFAB reports errors affecting only part of the asset population.

Error message / number

Exact error text and number not provided.

Root cause

A depreciation area has inconsistent parameters, such as missing depreciation key or negative net book value.

Affected modules

FI-AA

Transactions

AFAB, AW01N

Diagnosis / requirements

  1. Review the AFAB error log and identify affected assets
  2. Inspect values and parameters in AW01N.

Solution

  1. Correct only the confirmed and approved depreciation-area inconsistency
  2. Rerun the applicable depreciation posting.

Validation / configuration

Verify the affected asset results and run log.

Classification

L2: Functional analysis.
