FI-L2-019 · L2

Factures fournisseurs exclues de la proposition de paiement

Problème

Certaines factures ouvertes manquent dans F110.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Échéance hors paramètres ou blocage de paiement.

Modules concernés

FI-AP / Payments

Transactions

F110, FBL1N

Diagnostic / besoins

  1. Examiner le journal F110
  2. Contrôler conditions, échéances et blocages dans FBL1N.

Solution

  1. Corriger les paramètres autorisés ou lever un blocage injustifié après accord
  2. Relancer la proposition.

Validation / paramétrage

Vérifier les factures éligibles avant paiement.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
