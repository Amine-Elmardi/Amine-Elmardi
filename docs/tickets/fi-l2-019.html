FI-L2-019 · L2

Due supplier invoices excluded from payment proposal

Problem

Some open invoices are missing from an F110 proposal.

Error message / number

Exact error text and number not provided.

Root cause

The due date is outside run parameters or a payment block exists.

Affected modules

FI-AP / Payments

Transactions

F110, FBL1N

Diagnosis / requirements

  1. Review F110 exception log
  2. Inspect terms, due dates and block indicators in FBL1N.

Solution

  1. Correct authorized parameters or remove only an unjustified block after approval
  2. Rerun the proposal.

Validation / configuration

Confirm eligible invoices appear before payment execution.

Classification

L2: Functional analysis.
