FI-L2-020 · L2

Compte de charges indisponible à la saisie de facture

Problème

Une facture nécessite un nouveau compte de charges non sélectionnable.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le compte manque dans le plan ou la société concernée.

Modules concernés

FI-AP / FI-GL

Transactions

FS00, FB60

Diagnostic / besoins

  1. Confirmer compte, groupe et statut de zones avec FI.

Solution

  1. Créer ou étendre le compte approuvé dans FS00 avec les bons paramètres.

Validation / paramétrage

Vérifier sa disponibilité via un test FB60.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
