FI-L2-020 · L2

Expense account unavailable for invoice entry

Problem

A supplier invoice requires a new expense account that cannot be selected.

Error message / number

Exact error text and number not provided.

Root cause

The account has not been created or made available for the relevant chart and company code.

Affected modules

FI-AP / FI-GL

Transactions

FS00, FB60

Diagnosis / requirements

  1. Confirm the requested account, account group and field status with FI.

Solution

  1. Create or extend the approved G/L account in FS00 with correct master settings.

Validation / configuration

Confirm availability in the company code through an FB60 test.

Classification

L2: Functional analysis.
