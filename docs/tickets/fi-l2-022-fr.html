FI-L2-022 · L2

Reprise d’immobilisations historiques en erreur sur certains enregistrements

Problème

Le chargement rejette certaines immobilisations historiques.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Formats incorrects ou amortissements cumulés supérieurs à la valeur d’acquisition du tableau.

Modules concernés

FI-AA / Migration

Transactions

AS91, OASV

Diagnostic / besoins

  1. Identifier les rejets et examiner formats et montants.

Solution

  1. Corriger les erreurs confirmées dans le fichier
  2. Retraiter les enregistrements via la transaction de reprise applicable.

Validation / paramétrage

Rapprocher valeurs d’acquisition et amortissements cumulés repris.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
