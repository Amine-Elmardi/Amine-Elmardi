FI-L2-022 · L2

Legacy asset upload fails for selected records

Problem

A takeover upload rejects certain legacy asset records.

Error message / number

Exact error text and number not provided.

Root cause

Values have incorrect formats or accumulated depreciation exceeds acquisition value for the area.

Affected modules

FI-AA / Migration

Transactions

AS91, OASV

Diagnosis / requirements

  1. Identify rejected records and inspect field formats and valuation amounts.

Solution

  1. Correct the confirmed errors in the legacy file
  2. Reprocess the affected records using the applicable asset takeover transaction.

Validation / configuration

Reconcile accepted acquisition and accumulated depreciation values.

Classification

L2: Functional analysis.
