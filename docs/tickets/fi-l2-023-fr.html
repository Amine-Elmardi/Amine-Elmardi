FI-L2-023 · L2

Amortissement absent sur une immobilisation récemment activée

Problème

L’amortissement manque pour une immobilisation récente.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

L’activation est postérieure au traitement ou la date de début est incorrecte.

Modules concernés

FI-AA

Transactions

AS02, AFAB, AFAR

Diagnostic / besoins

  1. Comparer date d’activation, début d’amortissement et historique des traitements.

Solution

  1. Corriger la date approuvée dans AS02 si nécessaire
  2. Inclure l’immobilisation dans le traitement suivant ou répété approprié.

Validation / paramétrage

Contrôler le recalcul et le résultat AFAB.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
