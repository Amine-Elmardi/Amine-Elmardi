FI-L2-023 · L2

Newly capitalized asset has no depreciation

Problem

Depreciation is missing for a recently capitalized asset.

Error message / number

Exact error text and number not provided.

Root cause

Capitalization occurred after the depreciation run or the depreciation start date is incorrect.

Affected modules

FI-AA

Transactions

AS02, AFAB, AFAR

Diagnosis / requirements

  1. Compare capitalization date, depreciation start date and run history.

Solution

  1. Correct the approved start date in AS02 where necessary
  2. Include the asset in the appropriate subsequent or repeat run.

Validation / configuration

Check recalculated depreciation and the AFAB result.

Classification

L2: Functional analysis.
