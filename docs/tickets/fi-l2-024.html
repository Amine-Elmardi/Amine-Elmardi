FI-L2-024 · L2

Planned depreciation differs from G/L forecast

Problem

Asset Explorer values disagree with the finance forecast.

Error message / number

Exact error text and number not provided.

Root cause

The depreciation key or period control method distributes depreciation differently from expectations.

Affected modules

FI-AA / FI-GL

Transactions

AW01N, AFAMA, AFAMP

Diagnosis / requirements

  1. Compare planned values in AW01N with the expected schedule
  2. Review key in AFAMA and period control in AFAMP.

Solution

  1. Confirm the intended method with finance
  2. Correct approved asset master parameters if required.

Validation / configuration

Compare revised planned depreciation with the agreed forecast.

Classification

L2: Functional analysis.
