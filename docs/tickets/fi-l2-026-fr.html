FI-L2-026 · L2

Chèques individuels au lieu d’un paiement groupé

Problème

Plusieurs factures sont regroupées alors que des chèques distincts sont requis.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

L’indicateur de paiement individuel manque dans les paramètres fournisseur ou mode de paiement.

Modules concernés

FI-AP

Transactions

FK02, F110

Diagnostic / besoins

  1. Examiner données de paiement et clé de regroupement.

Solution

  1. Activer l’indicateur approuvé dans FK02
  2. Contrôler le regroupement avant une nouvelle proposition.

Validation / paramétrage

Vérifier les pièces de paiement séparées lors du test F110.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
