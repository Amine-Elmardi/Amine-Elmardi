FI-L2-026 · L2

Separate cheques instead of collective payments

Problem

Several supplier invoices are grouped into one payment although individual cheques are required.

Error message / number

Exact error text and number not provided.

Root cause

The individual payment indicator is absent in the supplier or payment method settings.

Affected modules

FI-AP

Transactions

FK02, F110

Diagnosis / requirements

  1. Inspect supplier payment data and grouping key.

Solution

  1. Set the approved individual payment indicator in FK02
  2. Verify grouping settings before rerunning the proposal.

Validation / configuration

Confirm separate payment documents in an F110 test.

Classification

L2: Functional analysis.
