FI-L2-028 · L2

Postes fournisseurs non rapprochés avant clôture annuelle

Problème

La liste de clôture révèle des factures ou paiements non résolus.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Certains postes n’ont pas été lettrés ou justifiés avant l’échéance.

Modules concernés

FI-AP / Closing

Transactions

FBL1N, F.13, F.19

Diagnostic / besoins

  1. Examiner les postes dans FBL1N
  2. Identifier les soldes non résolus avec AP.

Solution

  1. Coordonner le lettrage approuvé via F.13 si applicable
  2. Justifier les postes restant ouverts.

Validation / paramétrage

Mettre à jour la liste et rapprocher les soldes; F.19 est une référence associée.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
