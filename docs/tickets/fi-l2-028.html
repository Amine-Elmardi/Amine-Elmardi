FI-L2-028 · L2

Unreconciled supplier items before year-end

Problem

The closing checklist identifies unresolved vendor invoices or payments.

Error message / number

Exact error text and number not provided.

Root cause

Some items were not cleared or justified before the closing deadline.

Affected modules

FI-AP / Closing

Transactions

FBL1N, F.13, F.19

Diagnosis / requirements

  1. Review vendor open items in FBL1N
  2. Identify unresolved balances with AP.

Solution

  1. Coordinate approved clearing of matched items, using F.13 where applicable
  2. Document justification for items that remain open.

Validation / configuration

Update the year-end checklist and reconcile balances; F.19 is a related reference.

Classification

L2: Functional analysis.
