FI-L2-029 · L2

Nutzungsdauer einer Anlage im Bewertungsbereich ändern

Problem

FI verlangt eine Änderung von fünf auf drei Jahre für einen Bewertungsbereich.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Bisherige Abschreibungsparameter entsprechen nicht mehr der neuen Richtlinie.

Betroffene Module

FI-AA

Transaktionen

AS02, AFAR, AFAB

Analyse / Anforderungen

  1. Anlage, Bewertungsbereich und genehmigte Nutzungsdauer bestätigen.

Lösung

  1. Nutzungsdauer in AS02 ändern
  2. Abschreibung über AFAR neu berechnen.

Erfolgskontrolle / Customizing

AFAB-Testlauf vor Buchung auswerten.

Einordnung

L2: Funktionale Analyse.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
