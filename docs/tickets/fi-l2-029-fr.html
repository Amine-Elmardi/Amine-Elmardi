FI-L2-029 · L2

Modification de durée d’utilité dans un tableau d’amortissement

Problème

FI demande de passer de cinq à trois ans pour un tableau d’une immobilisation.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Les conditions actuelles ne correspondent plus à la politique révisée.

Modules concernés

FI-AA

Transactions

AS02, AFAR, AFAB

Diagnostic / besoins

  1. Confirmer immobilisation, tableau et durée approuvée.

Solution

  1. Modifier la durée dans AS02
  2. Recalculer via AFAR.

Validation / paramétrage

Contrôler le test AFAB avant comptabilisation.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
