FI-L2-029 · L2

Useful life change for an individual depreciation area

Problem

Finance requests a change from five to three years for an asset depreciation area.

Error message / number

Exact error text and number not provided.

Root cause

Existing depreciation terms no longer match the revised policy.

Affected modules

FI-AA

Transactions

AS02, AFAR, AFAB

Diagnosis / requirements

  1. Confirm asset, depreciation area and approved useful life.

Solution

  1. Change useful life in AS02
  2. Recalculate depreciation using the documented AFAR approach.

Validation / configuration

Check the AFAB test run before any posting.
