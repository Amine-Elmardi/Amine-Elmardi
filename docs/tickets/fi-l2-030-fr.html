FI-L2-030 · L2

Révision de durée d’utilité d’un groupe d’immobilisations

Problème

Une nouvelle politique réduit la durée de cinq à trois ans pour plusieurs immobilisations.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Les conditions d’amortissement reflètent l’ancienne politique.

Modules concernés

FI-AA

Transactions

AS02, AR01, AR31, AFAR

Diagnostic / besoins

  1. Confirmer sélection, tableaux et durée approuvée.

Solution

  1. Modifier les fiches via AS02 ou une procédure de masse autorisée applicable
  2. Recalculer via AFAR.

Validation / paramétrage

Comparer les valeurs recalculées et confirmer l’applicabilité des transactions de masse.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
