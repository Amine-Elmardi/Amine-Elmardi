FI-L2-030 · L2

Useful life revision for a group of assets

Problem

A policy change requires reducing useful life from five to three years for several assets.

Error message / number

Exact error text and number not provided.

Root cause

Existing asset depreciation terms reflect the former policy.

Affected modules

FI-AA

Transactions

AS02, AR01, AR31, AFAR

Diagnosis / requirements

  1. Confirm asset selection, depreciation areas and revised approved duration.

Solution

  1. Update each affected asset in AS02 or use an applicable authorized mass-change approach
  2. Recalculate depreciation in AFAR.

Validation / configuration

Compare recalculated values across the selected assets; verify mass-change transaction applicability.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
