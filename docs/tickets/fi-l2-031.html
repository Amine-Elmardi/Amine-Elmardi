FI-L2-031 · L2

Vendor debit balance not reclassified

Problem

A vendor debit balance is reported under liabilities rather than the required asset presentation.

Error message / number

Exact error text and number not provided.

Root cause

The year-end regrouping did not reclassify debit-balance vendors.

Affected modules

FI-AP / Closing

Transactions

F.5D, F101

Diagnosis / requirements

  1. Identify affected vendor balances and review closing regrouping.

Solution

  1. Execute the approved vendor/customer regrouping procedure using the applicable program.

Validation / configuration

Verify the resulting financial statement presentation of vendor debit and customer credit balances.

Classification

L2: Functional analysis.
