FI-L2-032 · L2

Activity type price calculated incorrectly

Problem

Calculated activity price differs from the expected value.

Error message / number

Exact error text and number not provided.

Root cause

Planned activity quantities or costs were not updated before calculation.

Affected modules

CO-OM

Transactions

KP26, KSPI, KSII

Diagnosis / requirements

  1. Identify center, activity type, period and planning values
  2. Compare quantities and costs.

Solution

  1. Update approved planning data using the applicable process including KP26
  2. Repeat the appropriate price calculation.

Validation / configuration

Reconcile calculated price with planning basis.

Classification

L2: Functional analysis.
