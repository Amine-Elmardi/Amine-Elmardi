FI-L2-033 · L2

Actual costs posted to wrong cost center

Problem

An original posting charges the incorrect cost center.

Error message / number

Exact error text and number not provided.

Root cause

The wrong cost center was entered during posting.

Affected modules

CO-OM

Transactions

KB61, KB65, KSB1

Diagnosis / requirements

  1. Identify original document and line item
  2. Confirm the intended cost center.

Solution

  1. Use the applicable approved CO reposting procedure with original document reference.

Validation / configuration

Verify correction on both centers in KSB1.

Classification

L2: Functional analysis.
