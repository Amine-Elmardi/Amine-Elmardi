FI-L2-034 · L2

Contrôle de disponibilité budgétaire bloquant l’écriture

Problème

Une imputation sur ordre ou élément OTP est bloquée.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Budget disponible épuisé ou seuil de tolérance atteint.

Modules concernés

CO-OM / PS / FM

Transactions

KO23, KO26, FMBB

Diagnostic / besoins

  1. Examiner consommation et budget restant
  2. Identifier objet et message.

Solution

  1. Coordonner supplément ou exception approuvée avec responsable
  2. Retenter après autorisation.

Validation / paramétrage

Vérifier écriture et budget restant, confirmer les transactions applicables.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
