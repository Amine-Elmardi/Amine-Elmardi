FI-L2-035 · L2

Cheque number sequence contains gaps

Problem

Generated cheque numbers skip expected numbers.

Error message / number

Exact error text and number not provided.

Root cause

The cheque lot interval is incorrect or a voided cheque was not recorded properly.

Affected modules

FI-BL

Transactions

FCHI, FCH1, FCHN

Diagnosis / requirements

  1. Review cheque register, void records and assigned lot.

Solution

  1. Coordinate authorized correction of the interval
  2. Reissue only if existing cheque and payment status permits.

Validation / configuration

Reconcile numbering and document skipped or voided numbers.

Classification

L2: Functional analysis.
