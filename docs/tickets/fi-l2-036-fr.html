FI-L2-036 · L2

Impression des chèques absente après paiement

Problème

Le traitement se termine sans sortie de chèque.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Affectation du programme ou paramètres de sortie manquants ou incorrects.

Modules concernés

FI-BL / FI-AP

Transactions

FBZP, F110, FCH7

Diagnostic / besoins

  1. Examiner sortie F110 et paramètres imprimante
  2. Contrôler affectation FBZP.

Solution

  1. Corriger paramètres autorisés
  2. Transmettre défauts partagés
  3. Réimprimer via FCH7 selon statut.

Validation / paramétrage

Vérifier la sortie et éviter les chèques valides en double.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
