FI-L2-036 · L2

Cheque printing missing after payment run

Problem

The payment run finishes without cheque output.

Error message / number

Exact error text and number not provided.

Root cause

Print program assignment or output parameters are missing or incorrect.

Affected modules

FI-BL / FI-AP

Transactions

FBZP, F110, FCH7

Diagnosis / requirements

  1. Inspect F110 output and printer parameters
  2. Review FBZP program assignment.

Solution

  1. Correct authorized output parameters
  2. Escalate shared assignment defects
  3. Reprint via applicable FCH7 route after checking cheque status.

Validation / configuration

Verify output and avoid duplicate valid cheques.

Classification

L2: Functional analysis.
