FI-L2-037 · L2

Période comptable CO verrouillée

Problème

Les écritures réelles du mois prévu sont rejetées.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La période CO n’est pas ouverte pour l’activité.

Modules concernés

CO-OM

Transactions

OKP1

Diagnostic / besoins

  1. Identifier périmètre, période et activité
  2. Examiner verrouillage OKP1.

Solution

  1. Faire adapter le verrouillage par CO après accord
  2. Retenter l’écriture.

Validation / paramétrage

Vérifier écriture autorisée et préserver les autres restrictions.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
