FI-L2-037 · L2

CO posting period locked

Problem

Actual postings for the intended month are rejected.

Error message / number

Exact error text and number not provided.

Root cause

The relevant CO period has not been opened for the activity.

Affected modules

CO-OM

Transactions

OKP1

Diagnosis / requirements

  1. Identify controlling area, period and activity
  2. Review lock in OKP1.

Solution

  1. Have the CO team adjust the period lock only after approval
  2. Retry the posting.

Validation / configuration

Verify intended posting while preserving other period restrictions.

Classification

L2: Functional analysis.
