FI-L2-039 · L2

Falscher Bankschlüssel im Lieferantenstamm

Problem

Die Bank lehnt eine Zahlungsdatei wegen falscher Bankdaten ab.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Bankschlüssel oder Filialcode wurde bei Lieferantenanlage falsch erfasst.

Betroffene Module

FI-BL / FI-AP

Transaktionen

FI01, XK02

Analyse / Anforderungen

  1. Bankstamm und Lieferantenbankdaten mit verifizierten genehmigten Informationen vergleichen.

Lösung

  1. Bankstamm über passende Pflege korrigieren
  2. Genehmigte Lieferantenbankdaten gegebenenfalls in XK02 aktualisieren.

Erfolgskontrolle / Customizing

Datei gegen bestätigte Daten prüfen. FI01 ist eine Referenz, Pflegetransaktion bestätigen.

Einordnung

L2: Funktionale Analyse.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
