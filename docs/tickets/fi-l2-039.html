FI-L2-039 · L2

Incorrect bank key in supplier master

Problem

The bank rejects a payment file due to incorrect bank details.

Error message / number

Exact error text and number not provided.

Root cause

Bank key or branch code was entered incorrectly during supplier creation.

Affected modules

FI-BL / FI-AP

Transactions

FI01, XK02

Diagnosis / requirements

  1. Compare bank master and supplier bank details with verified authorized information.

Solution

  1. Correct the bank master via the applicable maintenance route
  2. Update approved supplier bank details via XK02 as applicable.

Validation / configuration

Verify payment file against confirmed details; FI01 is a reference, confirm the maintenance transaction.

Classification

L2: Functional analysis.
