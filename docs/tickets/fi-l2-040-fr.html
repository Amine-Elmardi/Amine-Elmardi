FI-L2-040 · L2

Comparaison plan/réel incorrecte du centre de coûts

Problème

Les valeurs planifiées attendues manquent dans le rapport.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Les données de planification manquent pour l’exercice et la version.

Modules concernés

CO-OM

Transactions

KP06, KSB1, S_ALR_87013611

Diagnostic / besoins

  1. Identifier centre, exercice et version
  2. Comparer plan et réel.

Solution

  1. Saisir ou charger les valeurs approuvées dans KP06
  2. Relancer le rapport.

Validation / paramétrage

Rapprocher les écarts du plan convenu.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
