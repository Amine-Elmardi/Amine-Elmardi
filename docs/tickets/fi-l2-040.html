FI-L2-040 · L2

Incorrect cost center plan/actual comparison

Problem

The report omits expected plan values.

Error message / number

Exact error text and number not provided.

Root cause

Planning data is missing for the year and version.

Affected modules

CO-OM

Transactions

KP06, KSB1, S_ALR_87013611

Diagnosis / requirements

  1. Identify cost center, year and version
  2. Compare plan and actual data.

Solution

  1. Enter or upload the approved planning values in KP06
  2. Rerun the report.

Validation / configuration

Reconcile variance figures against the agreed plan.

Classification

L2: Functional analysis.
