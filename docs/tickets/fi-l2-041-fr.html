FI-L2-041 · L2

Écart de change réalisé incorrect au paiement

Problème

Le paiement en devises indique un gain ou une perte inattendus.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le cours manque pour le type et la date de paiement.

Modules concernés

FI-BL / FI-GL

Transactions

OB08, F110

Diagnostic / besoins

  1. Identifier devise, type et date
  2. Examiner OB08.

Solution

  1. Maintenir le cours approuvé manquant
  2. Relancer calcul ou écriture après contrôle du statut de paiement.

Validation / paramétrage

Comparer l’écart réalisé au cours approuvé.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
