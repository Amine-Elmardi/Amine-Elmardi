FI-L2-043 · L2

Écart d’ordre de fabrication incorrect

Problème

Le reporting de coûts ou rentabilité affiche un écart inattendu.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Calcul des écarts absent ou variante de calcul incohérente.

Modules concernés

CO-PC / CO-PA

Transactions

KKS1, KKS2, CO88

Diagnostic / besoins

  1. Identifier ordre et période
  2. Examiner statut et variante.

Solution

  1. Exécuter le calcul applicable via KKS1 ou KKS2
  2. Transmettre les défauts de variante confirmés.

Validation / paramétrage

Vérifier l’écart selon la comparaison standard attendue.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
