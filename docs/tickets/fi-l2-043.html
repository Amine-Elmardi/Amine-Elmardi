FI-L2-043 · L2

Manufacturing order variance incorrect

Problem

Product costing or profitability reporting shows an unexpected variance.

Error message / number

Exact error text and number not provided.

Root cause

Variance calculation is missing or the costing variant is inconsistent.

Affected modules

CO-PC / CO-PA

Transactions

KKS1, KKS2, CO88

Diagnosis / requirements

  1. Identify order and period
  2. Inspect calculation status and costing variant.

Solution

  1. Run the applicable variance calculation via KKS1 or KKS2
  2. Refer confirmed variant defects to the responsible team.

Validation / configuration

Recheck variance against the expected standard-cost comparison.

Classification

L2: Functional analysis.
