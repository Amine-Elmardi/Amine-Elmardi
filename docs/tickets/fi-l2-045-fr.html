FI-L2-045 · L2

Nature de coût primaire manquante pour compte général

Problème

Un nouveau compte de charges ou produits ne peut être utilisé comme prévu dans CO.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Dans ce scénario, la nature primaire correspondante n’a pas été créée.

Modules concernés

CO-OM / FI-GL

Transactions

KA01, OKB2, FS00

Diagnostic / besoins

  1. Examiner compte et catégorie requise
  2. Confirmer le modèle de données installé.

Solution

  1. Maintenir la nature approuvée via KA01 ou OKB2 selon le cas
  2. Transmettre le paramétrage automatique si nécessaire.

Validation / paramétrage

Vérifier catégorie et écriture CO, confirmer les transactions selon version.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
