FI-L2-045 · L2

Primary cost element missing for G/L account

Problem

A new expense or revenue account cannot be used as intended in CO.

Error message / number

Exact error text and number not provided.

Root cause

In this scenario, the corresponding primary cost element has not been created.

Affected modules

CO-OM / FI-GL

Transactions

KA01, OKB2, FS00

Diagnosis / requirements

  1. Inspect the G/L account and required category
  2. Confirm the installed master-data model.

Solution

  1. Maintain the approved cost element via the applicable KA01 or OKB2 approach
  2. Escalate automatic creation configuration where needed.

Validation / configuration

Verify category and CO posting; confirm release-specific transaction suitability.

Classification

L2: Functional analysis.
