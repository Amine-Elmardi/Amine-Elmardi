FI-L2-046 · L2

Centre de profit non dérivé dans FI/CO

Problème

La pièce ne contient pas le centre de profit attendu.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Affectation au centre de coûts ou substitution manquante pour le type d’objet.

Modules concernés

CO-PCA / FI

Transactions

KE52, GGB1, KS02

Diagnostic / besoins

  1. Identifier l’objet d’imputation
  2. Examiner centre de coûts et substitution.

Solution

  1. Corriger les données approuvées
  2. Transmettre la logique GGB1 manquante au paramétrage
  3. Retenter l’écriture.

Validation / paramétrage

Vérifier le centre dans la pièce.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
