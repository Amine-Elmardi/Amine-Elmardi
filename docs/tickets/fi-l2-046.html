FI-L2-046 · L2

Profit center not derived on FI/CO posting

Problem

The accounting document lacks the expected profit center.

Error message / number

Exact error text and number not provided.

Root cause

The cost center assignment or derivation substitution is missing for the object type.

Affected modules

CO-PCA / FI

Transactions

KE52, GGB1, KS02

Diagnosis / requirements

  1. Identify account assignment object
  2. Inspect cost center and substitution.

Solution

  1. Correct approved master data
  2. Refer missing GGB1 substitution logic to configuration support
  3. Retry posting.

Validation / configuration

Check profit center in the resulting document.

Classification

L2: Functional analysis.
