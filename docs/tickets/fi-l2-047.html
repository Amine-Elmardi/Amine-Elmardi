FI-L2-047 · L2

Residual balance after order settlement

Problem

The settled amount is below actual costs and a sender balance remains.

Error message / number

Exact error text and number not provided.

Root cause

The settlement rule does not cover the full intended distribution.

Affected modules

CO-OM

Transactions

KO02, KO88

Diagnosis / requirements

  1. Inspect the KO02 rule and total percentages or amounts.

Solution

  1. Correct approved distribution to the intended total, 100% in this scenario
  2. Repeat KO88 after reviewing prior settlement.

Validation / configuration

Reconcile actual and settled costs and explain or clear residual balance.

Classification

L2: Functional analysis.
