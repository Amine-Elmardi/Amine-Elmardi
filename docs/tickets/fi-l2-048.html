FI-L2-048 · L2

Scheduled payment job does not run

Problem

The hourly or daily F110 job misses its scheduled execution.

Error message / number

Exact error text and number not provided.

Root cause

Job failure due to lock or authorization, or incorrect scheduling variant.

Affected modules

FI-AP / Basis

Transactions

SM37, F110

Diagnosis / requirements

  1. Inspect SM37 status and log
  2. Check schedule and variant.

Solution

  1. Coordinate correction of confirmed cause
  2. Reschedule or restart only after checking whether payment already ran.

Validation / configuration

Verify job completion and intended schedule.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
