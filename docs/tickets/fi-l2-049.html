FI-L2-049 · L2

Standard cost estimate fails due to BOM or routing

Problem

CK11N cannot calculate the required standard cost.

Error message / number

Exact error text and number not provided.

Root cause

BOM or routing is missing or not released for the costing plant.

Affected modules

CO-PC / PP

Transactions

CK11N, CS03, CA03

Diagnosis / requirements

  1. Identify material and plant
  2. Display BOM in CS03 and routing in CA03.

Solution

  1. Coordinate completion or release with PP
  2. Repeat CK11N after approved changes.

Validation / configuration

Check successful costing and its result.

Classification

L2: Functional analysis.
