FI-L2-050 · L2

Statistical key figures missing from allocation

Problem

Allocation results are absent or incorrect for the period.

Error message / number

Exact error text and number not provided.

Root cause

Statistical key figure values used as tracing factors were not posted.

Affected modules

CO-OM

Transactions

KB31N, KSB1

Diagnosis / requirements

  1. Identify period and key figures
  2. Compare stored values with approved quantities.

Solution

  1. Post confirmed missing values in KB31N
  2. Repeat the relevant allocation or report after review.

Validation / configuration

Check values and allocation results.

Classification

L2: Functional analysis.
