FI-L2-051 · L2

Voided cheque leaves supplier item cleared

Problem

The cheque is voided but the supplier item remains incorrectly cleared.

Error message / number

Exact error text and number not provided.

Root cause

Void processing did not reverse the underlying payment document.

Affected modules

FI-BL / FI-AP

Transactions

FCH8, FCH9

Diagnosis / requirements

  1. Inspect cheque status, payment document and clearing status.

Solution

  1. Coordinate approved void/payment reversal with correct reason via applicable FCH8/FCH9 procedure.

Validation / configuration

Verify reversal and reopening of supplier item without duplicate void processing.

Classification

L2: Functional analysis.
