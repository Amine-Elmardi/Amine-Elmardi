FI-L2-052 · L2

Annulation intersociétés rejetée par validation

Problème

L’annulation pour une combinaison de sociétés est interdite.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Une règle métier limite volontairement la combinaison.

Modules concernés

FI / MM / SD

Transactions

OB28, FB08, FBU8

Diagnostic / besoins

  1. Examiner message et activation OB28
  2. Confirmer l’exigence de contrôle.

Solution

  1. Utiliser uniquement la procédure alternative approuvée avec FI
  2. Ne pas contourner la validation.

Validation / paramétrage

Vérifier pièces liées et respect du contrôle.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
