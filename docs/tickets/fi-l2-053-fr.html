FI-L2-053 · L2

Réception impossible sur poste de commande

Problème

Un poste ne peut pas être réceptionné dans MIGO.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Indicateur de réception absent ou quantité déjà entièrement reçue.

Modules concernés

FI / MM

Transactions

ME23N, ME22N, MIGO

Diagnostic / besoins

  1. Examiner livraison et historique ME23N.

Solution

  1. Corriger l’indicateur erroné dans ME22N après accord
  2. Expliquer si la réception est inapplicable ou complète.

Validation / paramétrage

Vérifier l’éligibilité sans double réception.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
