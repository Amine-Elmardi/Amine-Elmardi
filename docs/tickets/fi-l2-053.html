FI-L2-053 · L2

Goods receipt unavailable for purchase order item

Problem

A purchase order item cannot be received in MIGO.

Error message / number

Exact error text and number not provided.

Root cause

Goods receipt indicator is unset or the ordered quantity has already been received.

Affected modules

FI / MM

Transactions

ME23N, ME22N, MIGO

Diagnosis / requirements

  1. Inspect delivery tab and PO history in ME23N.

Solution

  1. Correct an erroneous GR indicator in ME22N after approval
  2. Explain when receipt is not applicable or already complete.

Validation / configuration

Verify receipt eligibility and avoid duplicate receipt.

Classification

L2: Functional analysis.
