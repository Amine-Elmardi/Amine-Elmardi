FI-L2-055 · L2

MRP does not generate planned orders

Problem

Requirements exist but expected planning proposals are absent.

Error message / number

Exact error text and number not provided.

Root cause

MRP type ND or a planning restriction prevents planning.

Affected modules

MM / PP / FI Integration

Transactions

MM02, MD01, MD04

Diagnosis / requirements

  1. Inspect MRP1 material settings and requirements in MD04.

Solution

  1. Correct approved MRP type or planning parameters in MM02
  2. Run applicable MRP processing.

Validation / configuration

Check planned order generation in MD04.

Classification

L2: Functional analysis.
