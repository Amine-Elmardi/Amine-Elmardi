FI-L2-056 · L2

Commande impossible à imprimer ou envoyer

Problème

La sortie de commande attendue manque.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Condition de sortie ou données de communication fournisseur absentes.

Modules concernés

MM / FI Integration

Transactions

MN04, ME9F, ME23N

Diagnostic / besoins

  1. Examiner sortie et adresse fournisseur
  2. Contrôler condition.

Solution

  1. Maintenir la condition approuvée dans MN04 ou corriger les données vérifiées
  2. Réémettre via ME9F.

Validation / paramétrage

Vérifier sortie et destinataire.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
