FI-L2-056 · L2

Purchase order cannot be printed or emailed

Problem

Expected purchasing output is missing.

Error message / number

Exact error text and number not provided.

Root cause

Output condition record or supplier communication data is absent.

Affected modules

MM / FI Integration

Transactions

MN04, ME9F, ME23N

Diagnosis / requirements

  1. Check PO output and supplier email settings
  2. Review condition record.

Solution

  1. Maintain approved missing record in MN04 or correct verified communication data
  2. Reissue via ME9F.

Validation / configuration

Confirm intended output and recipient.

Classification

L2: Functional analysis.
