FI-L2-057 · L2

Test UAT de sortie de commande en échec

Problème

Un test d’impression ne génère pas la sortie attendue.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La condition de sortie manque dans le mandant de test.

Modules concernés

MM / FI Integration / UAT

Transactions

ME21N, MN04

Diagnostic / besoins

  1. Examiner données et sortie dans le mandant UAT.

Solution

  1. Maintenir la condition de test approuvée dans MN04
  2. Répéter création et test de sortie.

Validation / paramétrage

Documenter le résultat et obtenir la recette si réussi.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
