FI-L2-057 · L2

Purchase order output UAT fails

Problem

A purchase order printing test cannot generate the expected output.

Error message / number

Exact error text and number not provided.

Root cause

The required output condition record is missing in the test client.

Affected modules

MM / FI Integration / UAT

Transactions

ME21N, MN04

Diagnosis / requirements

  1. Check test data and output configuration in the UAT client.

Solution

  1. Maintain approved test condition in MN04
  2. Repeat order creation and output test.

Validation / configuration

Record actual result and obtain test acceptance if successful.
