FI-L2-058 · L2

Prix de commande non repris de la fiche info-achats

Problème

Une fiche valide existe mais le prix attendu manque.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le scénario évoque blocage du répertoire ou indicateurs de source.

Modules concernés

MM / FI Integration

Transactions

ME01, ME12, ME21N

Diagnostic / besoins

  1. Examiner ME01 et ME12
  2. Confirmer sélection de source et détermination du prix.

Solution

  1. Lever uniquement un blocage erroné confirmé après accord
  2. Retester la proposition de prix.

Validation / paramétrage

Vérifier prix et source. Confirmer le lien causal dans le système.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
