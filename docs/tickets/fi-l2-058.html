FI-L2-058 · L2

Purchase order price not adopted from info record

Problem

A valid info record exists but the expected price is not proposed.

Error message / number

Exact error text and number not provided.

Root cause

The scenario identifies source-list blocking or source selection flags as possible causes.

Affected modules

MM / FI Integration

Transactions

ME01, ME12, ME21N

Diagnosis / requirements

  1. Review source list in ME01 and info record in ME12
  2. Confirm applicable source selection and pricing behavior.

Solution

  1. Remove a confirmed erroneous block only after approval
  2. Retest purchase order price proposal.

Validation / configuration

Verify price and source. The causal link to source-list flags requires system confirmation.

Classification

L2: Functional analysis.
