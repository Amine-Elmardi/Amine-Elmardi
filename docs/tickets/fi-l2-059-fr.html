FI-L2-059 · L2

Rapport de versement TDS incomplet

Problème

Certaines écritures de retenue manquent dans le rapport.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le code est exclu du mapping de versement ou d’établissement.

Modules concernés

FI-WHT / Reporting

Transactions

J1INCHLN, J1INMIS

Diagnostic / besoins

  1. Identifier pièces manquantes
  2. Comparer établissement et code de section.

Solution

  1. Coordonner la correction du mapping confirmé
  2. Relancer le rapport.

Validation / paramétrage

Rapprocher les postes des écritures de la période.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
