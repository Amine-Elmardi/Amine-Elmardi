FI-L2-059 · L2

TDS remittance report omits line items

Problem

The period report excludes some withholding tax postings.

Error message / number

Exact error text and number not provided.

Root cause

Their tax code is excluded from remittance key or business place mapping.

Affected modules

FI-WHT / Reporting

Transactions

J1INCHLN, J1INMIS

Diagnosis / requirements

  1. Identify omitted documents
  2. Compare business place and section code.

Solution

  1. Coordinate correction of confirmed mapping defects
  2. Rerun the remittance report.

Validation / configuration

Reconcile included items with the intended period postings.

Classification

L2: Functional analysis.
