FI-L2-060 · L2

Withholding tax absent on supplier invoice

Problem

Invoice posting produces no expected withholding tax.

Error message / number

Exact error text and number not provided.

Root cause

Extended withholding tax is inactive or supplier tax type/code is missing.

Affected modules

FI-AP / WHT

Transactions

OBWW, XK02, FB60

Diagnosis / requirements

  1. Check company code activation and supplier tax assignments.

Solution

  1. Maintain approved supplier type/code in XK02
  2. Escalate missing company code activation.

Validation / configuration

Test calculation in FB60.

Classification

L2: Functional analysis.
