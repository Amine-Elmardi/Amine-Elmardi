FI-L2-061 · L2

Withholding tax calculated at invoice and payment

Problem

The same tax category is charged twice.

Error message / number

Exact error text and number not provided.

Root cause

Both invoice-stage and payment-stage WHT types are assigned incorrectly.

Affected modules

FI-WHT / FI-AP

Transactions

XK02, OBWW

Diagnosis / requirements

  1. Review supplier tax types and required calculation stage.

Solution

  1. Deactivate the redundant assignment only after tax approval in the applicable supplier maintenance.

Validation / configuration

Test invoice and payment sequence for single intended deduction.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
