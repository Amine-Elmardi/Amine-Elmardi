FI-L2-062 · L2

Retenue non contrepassée avec la facture fournisseur

Problème

L’annulation laisse des écritures de retenue non résolues.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La pièce originale était lettrée avant annulation.

Modules concernés

FI-WHT / FI-AP

Transactions

FBRA, FB08

Diagnostic / besoins

  1. Examiner facture, lettrage et postes fiscaux.

Solution

  1. Coordonner la réinitialisation approuvée via FBRA
  2. Contrepasser la facture via FB08 selon le cas.

Validation / paramétrage

Rapprocher les écritures de base et de retenue.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
