FI-L2-062 · L2

Withholding tax not reversed with supplier invoice

Problem

Invoice reversal leaves withholding postings unresolved.

Error message / number

Exact error text and number not provided.

Root cause

The original document was cleared before reversal.

Affected modules

FI-WHT / FI-AP

Transactions

FBRA, FB08

Diagnosis / requirements

  1. Inspect original invoice, clearing and tax line items.

Solution

  1. Coordinate approved clearing reset in FBRA
  2. Reverse the invoice via applicable FB08 procedure.

Validation / configuration

Reconcile base and withholding reversal entries.

Classification

L2: Functional analysis.
