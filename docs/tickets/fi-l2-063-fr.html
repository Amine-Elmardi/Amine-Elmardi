FI-L2-063 · L2

Récapitulatif annuel de retenue incomplet

Problème

FI ne peut préparer le récapitulatif annuel complet pour déclaration.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Des données d’établissement ou de section manquent dans certaines pièces.

Modules concernés

FI-WHT / Closing

Transactions

J1INMIS, S_ALR_87012106

Diagnostic / besoins

  1. Identifier les pièces omises et vérifier les affectations requises.

Solution

  1. Coordonner la correction autorisée des données manquantes
  2. Régénérer le récapitulatif annuel.

Validation / paramétrage

Rapprocher les totaux et obtenir la revue fiscale avant déclaration.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
