FI-L2-064 · L2

Balance sheet audit trail required for external audit

Problem

Auditors request account balances with traceable document-level details.

Error message / number

Exact error text and number not provided.

Root cause

No consolidated extract with the required supporting information exists.

Affected modules

FI-GL / Audit

Transactions

S_ALR_87012326, FBL3N

Diagnosis / requirements

  1. Confirm audit period, account scope and required document detail.

Solution

  1. Extract the relevant balances and line items using the applicable audit trail report and FBL3N
  2. Compile supporting documentation for authorized audit access.

Validation / configuration

Reconcile extract totals with the closing balances.

Classification

L2: Functional analysis.
