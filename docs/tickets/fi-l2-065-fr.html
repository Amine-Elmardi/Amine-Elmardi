FI-L2-065 · L2

Dernier amortissement bloquant le changement d’exercice

Problème

Le changement d’exercice des immobilisations ne peut avancer dans le processus décrit.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le dernier traitement AFAB est incomplet en raison d’erreurs sur certaines immobilisations.

Modules concernés

FI-AA / Closing

Transactions

AFAB, AJRW

Diagnostic / besoins

  1. Examiner le journal et identifier les immobilisations
  2. Confirmer les prérequis de la version installée.

Solution

  1. Coordonner les corrections confirmées
  2. Terminer le traitement approuvé et le changement d’exercice applicable.

Validation / paramétrage

Vérifier les résultats des deux traitements.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
