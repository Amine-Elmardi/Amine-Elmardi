FI-L2-065 · L2

Final depreciation run blocks asset year change

Problem

The asset-accounting year change cannot proceed in the described closing sequence.

Error message / number

Exact error text and number not provided.

Root cause

The final AFAB run remains incomplete because specific assets have errors.

Affected modules

FI-AA / Closing

Transactions

AFAB, AJRW

Diagnosis / requirements

  1. Review the final depreciation run log and identify the affected assets
  2. Confirm closing prerequisites for the installed release.

Solution

  1. Coordinate correction of confirmed asset errors
  2. Complete the approved final depreciation run and applicable year-change procedure.

Validation / configuration

Check successful depreciation and year-change results.

Classification

L2: Functional analysis.
