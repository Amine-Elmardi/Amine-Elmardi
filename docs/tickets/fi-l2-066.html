FI-L2-066 · L2

Month-end valuation and regrouping pending

Problem

Foreign currency valuation and open-item regrouping have not been completed for closing.

Error message / number

Exact error text and number not provided.

Root cause

The corresponding programs were not executed for the period.

Affected modules

FI-GL / FI-AR / FI-AP

Transactions

FAGL_FC_VAL, F101

Diagnosis / requirements

  1. Confirm closing date and execution status of both processes
  2. Review the intended selection.

Solution

  1. Run the approved valuation in FAGL_FC_VAL and regrouping in F101
  2. Review the applicable batch-input results before posting.

Validation / configuration

Reconcile the resulting valuation and regrouping entries and document completion.

Classification

L2: Functional analysis.
