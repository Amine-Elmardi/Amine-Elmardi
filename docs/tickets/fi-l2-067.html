FI-L2-067 · L2

Open commitments require year-end carry-forward

Problem

Open purchase requisitions or orders need their commitments carried into the new fiscal year.

Error message / number

Exact error text and number not provided.

Root cause

Outstanding budget commitments require continuity across the year boundary.

Affected modules

CO-OM / FM / MM

Transactions

KO7F, FMJ2

Diagnosis / requirements

  1. Identify open purchasing documents and assigned cost centers or orders
  2. Confirm the applicable commitment carry-forward process.

Solution

  1. Execute the approved carry-forward using the program applicable to the object and release
  2. Review KO7F and FMJ2 applicability before use.

Validation / configuration

Reconcile commitment values between the old and new fiscal year.

Classification

L2: Functional analysis.
