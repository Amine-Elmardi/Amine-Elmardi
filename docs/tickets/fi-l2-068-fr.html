FI-L2-068 · L2

Soldes d’ouverture différents de la clôture précédente

Problème

Les comptes du nouvel exercice ne reprennent pas les montants attendus.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le report a été omis ou exécuté avant les ajustements de l’exercice précédent.

Modules concernés

FI-GL / Closing

Transactions

FAGLGVTR, F.16

Diagnostic / besoins

  1. Comparer soldes de clôture et d’ouverture
  2. Examiner historique et ajustements.

Solution

  1. Confirmer les ajustements avec FI
  2. Relancer le report approuvé via FAGLGVTR ou F.16 selon le cas.

Validation / paramétrage

Rapprocher les soldes reportés des montants définitifs.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
