FI-L2-068 · L2

Opening balances differ from prior-year closing

Problem

G/L balances in the new fiscal year do not reflect expected carry-forward amounts.

Error message / number

Exact error text and number not provided.

Root cause

The carry-forward run was omitted or occurred before prior-year adjustments were completed.

Affected modules

FI-GL / Closing

Transactions

FAGLGVTR, F.16

Diagnosis / requirements

  1. Compare prior-year closing and new-year opening balances
  2. Check run history and adjustment status.

Solution

  1. Confirm all relevant adjustments with finance
  2. Repeat the approved carry-forward using the applicable FAGLGVTR or F.16 procedure.

Validation / configuration

Reconcile carried-forward balances to the final prior-year amounts.

Classification

L2: Functional analysis.
