FI-L2-069 · L2

Périodes indisponibles pour le nouvel exercice

Problème

Les écritures du nouvel exercice sont rejetées.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La variante de périodes manque de nouveaux intervalles ou la variante d’exercice est incomplète.

Modules concernés

FI-GL / Closing

Transactions

OB52, OB29

Diagnostic / besoins

  1. Identifier société, exercice, types de compte et variante
  2. Examiner OB52 et OB29.

Solution

  1. Faire étendre les intervalles autorisés dans OB52
  2. Soumettre tout défaut de configuration d’exercice confirmé à approbation distincte.

Validation / paramétrage

Tester l’écriture et vérifier que les périodes non autorisées restent fermées.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
