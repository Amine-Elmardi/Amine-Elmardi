FI-L2-069 · L2

Posting periods unavailable in new fiscal year

Problem

New-year accounting postings are rejected because the intended periods are unavailable.

Error message / number

Exact error text and number not provided.

Root cause

The posting period variant lacks new intervals or the fiscal year variant is incomplete.

Affected modules

FI-GL / Closing

Transactions

OB52, OB29

Diagnosis / requirements

  1. Identify company code, fiscal year, account types and variant
  2. Review OB52 and fiscal year settings in OB29.

Solution

  1. Have the responsible team extend authorized period intervals in OB52
  2. Refer any confirmed fiscal year configuration defect for separate approval.

Validation / configuration

Test the new-year posting and verify that unauthorized periods remain closed.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
