FI-L2-070 · L2

Recurring entries do not cover the new fiscal year

Problem

Recurring postings are not prepared for the upcoming year.

Error message / number

Exact error text and number not provided.

Root cause

The validity end date of the recurring documents does not cover the new fiscal year.

Affected modules

FI-GL / Closing

Transactions

FBD1, F.14

Diagnosis / requirements

  1. Review existing recurring document validity and the agreed future schedule.

Solution

  1. Extend approved validity through applicable recurring document maintenance
  2. Schedule the recurring posting program F.14.

Validation / configuration

Verify that intended dates are covered and no duplicate schedule exists.

Classification

L2: Functional analysis.
