FI-L2-071 · L2

Extourne prévue des provisions de charges manquante

Problème

Les provisions restent non contrepassées au début de la nouvelle période.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La date d’extourne est enregistrée mais le traitement n’a pas été exécuté.

Modules concernés

FI-GL / Closing

Transactions

F.81, FBS1

Diagnostic / besoins

  1. Identifier les pièces
  2. Examiner dates, motifs et statut d’extourne.

Solution

  1. Exécuter l’extourne de masse autorisée via F.81 pour la période prévue.

Validation / paramétrage

Vérifier les pièces et rapprocher les soldes de provisions.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
