FI-L2-071 · L2

Scheduled reversal of expense provisions missing

Problem

Expense provision postings remain unreversed at the start of the new period.

Error message / number

Exact error text and number not provided.

Root cause

The reversal date was recorded but the scheduled reversal was not executed.

Affected modules

FI-GL / Closing

Transactions

F.81, FBS1

Diagnosis / requirements

  1. Identify the relevant provision documents
  2. Check reversal dates, reasons and existing reversal status.

Solution

  1. Execute the authorized mass reversal through F.81 for the intended period.

Validation / configuration

Verify reversal documents and reconcile the affected provision balances.

Classification

L2: Functional analysis.
