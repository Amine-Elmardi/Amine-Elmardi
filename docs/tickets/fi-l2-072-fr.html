FI-L2-072 · L2

Cas de test UAT manquant pour nouvelle fonctionnalité FI/CO

Problème

Un changement nécessite des preuves de test avant recette.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Aucun cas ne définit entrées, actions et résultats attendus.

Modules concernés

FI/CO / UAT

Transactions

N/A – Documentation

Diagnostic / besoins

  1. Convenir fonctionnalité et données avec le métier
  2. Identifier les étapes de transaction.

Solution

  1. Préparer le cas avec étapes, données, résultats attendus et réels
  2. Soumettre à validation métier.

Validation / paramétrage

Vérifier preuves et recette avant mise en production.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
