FI-L2-072 · L2

UAT test case missing for new FI/CO functionality

Problem

A new configuration change needs formal test evidence before acceptance.

Error message / number

Exact error text and number not provided.

Root cause

No test case defines inputs, actions and expected outcomes.

Affected modules

FI/CO / UAT

Transactions

N/A – Documentation

Diagnosis / requirements

  1. Agree the functionality and required test data with the business
  2. Identify the relevant transaction steps.

Solution

  1. Prepare the test case with steps, test data, expected and actual results
  2. Submit it for business sign-off.

Validation / configuration

Verify that test evidence and acceptance are recorded before release.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
