FI-L2-073 · L2

Year-end closing checklist before period lock

Problem

Finance needs a consolidated review before closing the fiscal period.

Error message / number

Exact error text and number not provided.

Root cause

Closing activities across the subledgers and general ledger are not consolidated.

Affected modules

FI-GL / FI-AR / FI-AP / FI-AA

Transactions

OB52, F.19, F.5D, AJRW

Diagnosis / requirements

  1. Identify outstanding recurring entries, provisions, foreign currency valuation, regrouping and asset year change
  2. Agree closing responsibilities.

Solution

  1. Compile the checklist with the relevant steps and circulate for approval
  2. Coordinate the period lock only after the required sign-offs.

Validation / configuration

Confirm the checklist is complete and record approvals.

Classification

L2: Functional analysis.
