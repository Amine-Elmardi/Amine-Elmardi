FI-L3-001 · L3

Debitorenposition verlangt fehlendes Segment oder Profitcenter

Problem

Debitorenbuchungspositionen scheitern an einer Pflichteingabe.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Die Belegaufteilung verlangt ein Merkmal, das aus dem Vertriebsbeleg fehlt.

Betroffene Module

FI-AR / SD

Transaktionen

GSP_VZ3, VA02

Analyse / Anforderungen

  1. Kontierung von Auftrag/Faktura und Aufteilungsvariante prüfen

Lösung

  1. Genehmigte Ableitung im Ursprungsbeleg korrigieren
  2. Falls fachlich begründet, Aufteilungsregel mit zuständiger Stelle anpassen

Erfolgskontrolle / Customizing

FI-Überleitung und erwartetes Segment/Profitcenter testen.

Einordnung

L3: Customizing / Erweiterung.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
