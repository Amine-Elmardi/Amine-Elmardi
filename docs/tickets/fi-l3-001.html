FI-L3-001 · L3

AR line item requires missing segment or profit center

Problem

Customer accounting lines fail a required-entry check for segment or profit center.

Error message / number

Exact error text and number not provided.

Root cause

Document splitting requires a characteristic not supplied by the sales source document.

Affected modules

FI-AR / SD

Transactions

GSP_VZ3, VA02

Diagnosis / requirements

  1. Inspect sales order/billing account assignment and splitting transaction variant

Solution

  1. Correct the approved source-document derivation
  2. If business requirements justify it, adjust the splitting rule with the responsible team

Validation / configuration

Retest transfer to FI and verify the expected segment and profit center.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
