FI-L3-002 · L3

Lettrage automatique ne regroupe pas les postes compensables

Problème

Des postes ouverts de solde net nul restent non lettrés.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La règle manque de critères de regroupement comme référence ou affectation.

Modules concernés

FI-GL

Transactions

OB74, F.13

Diagnostic / besoins

  1. Comparer les critères des postes
  2. Examiner la règle OB74 pour le périmètre concerné

Solution

  1. Maintenir les critères approuvés dans OB74
  2. Relancer F.13 après contrôle de la sélection

Validation / paramétrage

Vérifier les postes lettrés et l’absence d’impact sur les autres.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
