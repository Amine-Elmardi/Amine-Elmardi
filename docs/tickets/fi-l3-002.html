FI-L3-002 · L3

Automatic clearing does not group offsetting open items

Problem

Open items with net zero remain uncleared after an automatic run.

Error message / number

Exact error text and number not provided.

Root cause

The clearing rule lacks required grouping fields such as reference or assignment.

Affected modules

FI-GL

Transactions

OB74, F.13

Diagnosis / requirements

  1. Compare open-item grouping criteria
  2. Review the rule for the relevant account scope in OB74

Solution

  1. Maintain approved grouping criteria in OB74
  2. Repeat automatic clearing through F.13 after checking the selection

Validation / configuration

Verify matched items are cleared and unrelated items remain unaffected.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
