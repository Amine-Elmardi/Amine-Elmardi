FI-L3-003 · L3

Automatic cost or profit center substitution

Problem

Finance requires a derived cost center or profit center during journal entry.

Error message / number

Exact error text and number not provided.

Root cause

No suitable substitution exists at the relevant header or item call-up point.

Affected modules

FI-GL / CO

Transactions

GGB1, OBBH, FB50, F-02

Diagnosis / requirements

  1. Define prerequisites, target field and company code
  2. Review existing substitution rules

Solution

  1. Create the approved logic in GGB1
  2. Activate it for the relevant call-up point in OBBH

Validation / configuration

Test representative postings with FB50 or F-02.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
