FI-L3-004 · L3

Fakturabeleg wird nicht an Buchhaltung übergeleitet

Problem

Ein SD-Fakturabeleg bleibt ohne FI-Freigabe.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Die Erlöskontenfindung fehlt für Kontierungsgruppe, Kondition und Kontenplan.

Betroffene Module

FI-AR / SD

Transaktionen

VKOA, VF02, VFX3

Analyse / Anforderungen

  1. Fehlerhaften Fakturabeleg über VF02/VFX3 bestimmen
  2. Relevante VKOA-Kombination mit SD prüfen

Lösung

  1. Genehmigte fehlende Erlöskontenfindung pflegen
  2. Fakturabeleg erneut an FI überleiten

Erfolgskontrolle / Customizing

Erzeugten FI-Beleg und erwartetes Erlöskonto prüfen.

Einordnung

L3: Customizing / Erweiterung.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
