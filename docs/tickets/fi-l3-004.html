FI-L3-004 · L3

Billing document cannot be transferred to accounting

Problem

An SD billing document remains unreleased to FI.

Error message / number

Exact error text and number not provided.

Root cause

Revenue account determination is missing for the relevant account assignment group, condition and chart.

Affected modules

FI-AR / SD

Transactions

VKOA, VF02, VFX3

Diagnosis / requirements

  1. Identify failed billing document via VF02/VFX3
  2. Review the relevant VKOA combination with SD

Solution

  1. Maintain the approved missing revenue account determination
  2. Release the billing document again

Validation / configuration

Confirm the accounting document is created with the expected revenue account.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
