FI-L3-005 · L3

Billing revenue account key missing from pricing procedure

Problem

Billing fails to create an accounting document because account determination cannot resolve the revenue account.

Error message / number

Exact error text and number not provided.

Root cause

The pricing condition lacks its account key.

Affected modules

FI-AR / SD

Transactions

V/08, VKOA

Diagnosis / requirements

  1. Review the condition and account key in V/08
  2. Compare the required VKOA assignment

Solution

  1. Maintain the approved account key and missing determination entry with SD/FI

Validation / configuration

Retest billing and confirm the revenue G/L account.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
