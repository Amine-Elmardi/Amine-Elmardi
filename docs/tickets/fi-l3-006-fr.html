FI-L3-006 · L3

Écriture intersociétés sans comptes de liaison

Problème

Une écriture entre deux sociétés échoue lors de la détermination des comptes.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

L’affectation des comptes de liaison manque pour la paire de sociétés.

Modules concernés

FI-GL

Transactions

OBYA, F-02

Diagnostic / besoins

  1. Identifier les deux sociétés et examiner OBYA

Solution

  1. Maintenir les comptes approuvés pour la paire dans OBYA

Validation / paramétrage

Tester dans F-02 et contrôler les deux écritures.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
