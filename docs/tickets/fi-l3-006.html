FI-L3-006 · L3

Cross-company posting missing clearing accounts

Problem

A transaction involving two company codes fails during clearing-account determination.

Error message / number

Exact error text and number not provided.

Root cause

The account assignment for the company code pair is missing.

Affected modules

FI-GL

Transactions

OBYA, F-02

Diagnosis / requirements

  1. Identify both company codes and examine the OBYA assignment

Solution

  1. Maintain the approved clearing accounts for the relevant pair in OBYA

Validation / configuration

Test a cross-company posting in F-02 and check both accounting legs.

Classification

L3: Configuration / enhancement.
