FI-L3-008 · L3

Acompte client non affecté au compte spécial

Problème

Un acompte apparaît sur le compte collectif standard plutôt que dans le traitement spécial attendu.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La correspondance indicateur-compte collectif est incorrecte.

Modules concernés

FI-AR

Transactions

OBXR, F-29

Diagnostic / besoins

  1. Identifier indicateur et compte collectif
  2. Examiner OBXR

Solution

  1. Corriger l’affectation approuvée dans OBXR
  2. Tester un acompte dans F-29

Validation / paramétrage

Vérifier le traitement spécial et le compte. Distinguer demande et paiement réel avant le test.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
