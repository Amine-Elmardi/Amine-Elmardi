FI-L3-008 · L3

Customer down payment not mapped to special G/L account

Problem

A down payment appears under the standard reconciliation account rather than the expected special G/L treatment.

Error message / number

Exact error text and number not provided.

Root cause

The indicator-to-reconciliation-account mapping is incorrect.

Affected modules

FI-AR

Transactions

OBXR, F-29

Diagnosis / requirements

  1. Identify the special G/L indicator and reconciliation account
  2. Review the assignment in OBXR

Solution

  1. Correct the approved mapping in OBXR
  2. Perform a representative down payment test in F-29

Validation / configuration

Verify special G/L treatment and the intended account. Clarify request versus actual payment before testing.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
