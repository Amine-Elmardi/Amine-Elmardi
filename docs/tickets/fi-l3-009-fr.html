FI-L3-009 · L3

La ventilation ne dérive pas le segment ou centre de profit

Problème

Certains postes restent sans caractéristique requise.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La variante d’opération exclut une catégorie de poste.

Modules concernés

FI-GL / CO

Transactions

GSP_VZ3, GSP_LD

Diagnostic / besoins

  1. Identifier variante et catégorie
  2. Examiner la méthode de ventilation dans SPRO

Solution

  1. Ajouter la catégorie manquante à la règle approuvée
  2. Retraiter les écritures en échec après test

Validation / paramétrage

Contrôler la dérivation sur une pièce représentative.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
