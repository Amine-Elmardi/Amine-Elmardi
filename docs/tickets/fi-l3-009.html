FI-L3-009 · L3

Document splitting fails to derive segment or profit center

Problem

Some journal lines remain without the required splitting characteristic.

Error message / number

Exact error text and number not provided.

Root cause

The relevant business transaction variant excludes an item category.

Affected modules

FI-GL / CO

Transactions

GSP_VZ3, GSP_LD

Diagnosis / requirements

  1. Identify affected transaction variant and item category
  2. Review the assigned splitting method in SPRO

Solution

  1. Add the missing item category to the approved splitting rule
  2. Reprocess the affected failed postings after testing

Validation / configuration

Check segment and profit center derivation in the representative document.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
