FI-L3-011 · L3

Numéro de compte général hors intervalle

Problème

La création du compte ne reprend pas l’intervalle attendu.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le numéro est hors plage du groupe de comptes ou l’affectation est incomplète.

Modules concernés

FI-GL

Transactions

OBD4, FS00, OBY7

Diagnostic / besoins

  1. Examiner plan et groupe dans OBD4
  2. Contrôler l’intervalle attribué

Solution

  1. Faire corriger l’intervalle après approbation si nécessaire
  2. Créer le compte dans le bon groupe via FS00

Validation / paramétrage

Vérifier la création dans la plage autorisée. OBY7 est une référence complémentaire.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
