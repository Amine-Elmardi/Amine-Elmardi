FI-L3-011 · L3

G/L account number outside assigned range

Problem

Creation of a new G/L account fails to use the expected numbering interval.

Error message / number

Exact error text and number not provided.

Root cause

The number is outside the account group interval or the assignment is incomplete.

Affected modules

FI-GL

Transactions

OBD4, FS00, OBY7

Diagnosis / requirements

  1. Review the chart and account group in OBD4
  2. Check the assigned number interval

Solution

  1. If exhausted or incorrect, arrange an approved interval correction
  2. Create the account in the correct group via FS00

Validation / configuration

Verify account creation within the authorized range; OBY7 is an additional reference in the material.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
