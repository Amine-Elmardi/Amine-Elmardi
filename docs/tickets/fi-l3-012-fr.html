FI-L3-012 · L3

Création de banque société rejetée sur la clé bancaire

Problème

Les champs banque ou compte rejettent la nouvelle configuration.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La banque manque au répertoire ou le format national est invalide.

Modules concernés

FI-BL

Transactions

FI01, FI12, OT59, OBYR

Diagnostic / besoins

  1. Confirmer pays et format
  2. Vérifier l’existence dans le répertoire

Solution

  1. Créer la clé dans FI01
  2. Configurer les identifiants approuvés via l’approche FI12/OT59 décrite et lier le compte général

Validation / paramétrage

Tester un paiement. Confirmer les transactions selon la version SAP.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
