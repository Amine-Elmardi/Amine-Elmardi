FI-L3-012 · L3

House bank creation fails on bank key

Problem

The bank key or account fields reject a new house bank configuration.

Error message / number

Exact error text and number not provided.

Root cause

The bank directory entry is absent or the country-specific key format is invalid.

Affected modules

FI-BL

Transactions

FI01, FI12, OT59, OBYR

Diagnosis / requirements

  1. Confirm bank country and key format
  2. Check whether the bank exists in the directory

Solution

  1. Create the required bank key in FI01
  2. Configure approved house bank and account IDs via the described FI12/OT59 approach and link the G/L account

Validation / configuration

Test with a sample payment run; the listed transaction references require release-specific confirmation.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
