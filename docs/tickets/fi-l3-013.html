FI-L3-013 · L3

Mandatory balancing profit center prevents posting

Problem

A line item requires a profit center that is not populated.

Error message / number

Exact error text and number not provided.

Root cause

Document splitting and field-status requirements make the characteristic mandatory.

Affected modules

FI-GL / CO

Transactions

GSP_LD, OBC4, GGB1

Diagnosis / requirements

  1. Review splitting characteristics and the field status group in OBC4
  2. Determine the expected derivation

Solution

  1. If configuration is incorrect, arrange the approved field-status correction
  2. Use the agreed substitution or default assignment for derivation

Validation / configuration

Test the posting and confirm the intended profit center and balancing behavior.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
