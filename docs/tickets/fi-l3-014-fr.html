FI-L3-014 · L3

Détermination manquante du coût des ventes dans le flux intégré

Problème

L’écriture attendue du coût des ventes manque dans le processus décrit.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

L’affectation GBB pour la combinaison de valorisation manque.

Modules concernés

FI-GL / MM / SD

Transactions

OBYC, VF02

Diagnostic / besoins

  1. Examiner flux et classe de valorisation avec MM
  2. Contrôler GBB dans OBYC

Solution

  1. Maintenir le compte manquant approuvé avec MM/FI
  2. Tester le processus intégré

Validation / paramétrage

Contrôler les écritures. Confirmer l’étape exacte; le cas évoque la facturation.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
