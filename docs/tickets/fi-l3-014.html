FI-L3-014 · L3

Missing COGS account determination in integrated sales process

Problem

Expected cost-of-goods-sold accounting is absent during the sales process described in the scenario.

Error message / number

Exact error text and number not provided.

Root cause

The GBB account determination entry for the relevant valuation combination is missing.

Affected modules

FI-GL / MM / SD

Transactions

OBYC, VF02

Diagnosis / requirements

  1. Inspect the affected process and valuation class with MM
  2. Review GBB in OBYC

Solution

  1. Maintain the approved missing account assignment with MM/FI
  2. Test the integrated process

Validation / configuration

Check the resulting accounting entries. The exact posting stage must be confirmed; the learning scenario refers to billing.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
