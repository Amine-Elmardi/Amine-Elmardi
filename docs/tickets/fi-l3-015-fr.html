FI-L3-015 · L3

Nouvelle procédure de relance avec niveaux supplémentaires

Problème

Le recouvrement souhaite de nouvelles tranches, frais ou niveaux.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La procédure actuelle ne couvre pas la structure souhaitée.

Modules concernés

FI-AR

Transactions

FBMP, F150

Diagnostic / besoins

  1. Convenir niveaux, frais et textes
  2. Identifier les clients concernés

Solution

  1. Configurer la procédure approuvée dans FBMP
  2. L’affecter aux fiches clients

Validation / paramétrage

Tester F150 et valider les relances avant utilisation.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
