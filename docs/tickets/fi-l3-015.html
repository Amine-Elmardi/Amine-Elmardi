FI-L3-015 · L3

New dunning procedure with additional levels

Problem

Collections requests new ageing buckets, fees or dunning levels for a customer segment.

Error message / number

Exact error text and number not provided.

Root cause

The existing procedure does not cover the requested structure.

Affected modules

FI-AR

Transactions

FBMP, F150

Diagnosis / requirements

  1. Agree levels, charges and texts with collections
  2. Identify customer scope

Solution

  1. Configure the approved new procedure in FBMP
  2. Assign it to relevant customer masters

Validation / configuration

Test a dunning run in F150 and validate notices before use.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
