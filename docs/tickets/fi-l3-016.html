FI-L3-016 · L3

New financial statement version for statutory reporting

Problem

The requested statutory report layout differs from the existing financial statement version.

Error message / number

Exact error text and number not provided.

Root cause

The existing hierarchy does not match the finance requirements.

Affected modules

FI-GL

Transactions

OB58

Diagnosis / requirements

  1. Obtain the approved hierarchy and account mapping
  2. Review the current structure

Solution

  1. Create the new financial statement version in OB58
  2. Assign G/L accounts to each required node

Validation / configuration

Run consistency checks and obtain finance acceptance before reporting.

Classification

L3: Configuration / enhancement.
