FI-L3-017 · L3

Nouveau calcul d’intérêts sur créances échues

Problème

Le métier demande un taux défini sur les soldes clients échus.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Aucun indicateur ne correspond au taux demandé.

Modules concernés

FI-AR

Transactions

OB46, OB83, F.2B

Diagnostic / besoins

  1. Confirmer taux, date d’effet et clients éligibles

Solution

  1. Configurer indicateur et taux approuvés dans OB46/OB83
  2. Affecter aux clients concernés

Validation / paramétrage

Valider le calcul via le traitement F.2B cité.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
