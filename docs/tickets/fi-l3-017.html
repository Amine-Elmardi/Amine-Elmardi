FI-L3-017 · L3

New interest calculation for overdue receivables

Problem

Business requires a defined interest rate on overdue customer balances.

Error message / number

Exact error text and number not provided.

Root cause

No interest indicator matches the requested rate.

Affected modules

FI-AR

Transactions

OB46, OB83, F.2B

Diagnosis / requirements

  1. Confirm rate, effective date and eligible customers

Solution

  1. Configure the approved interest indicator and rate in OB46/OB83
  2. Assign it to the relevant customer master

Validation / configuration

Validate the calculation with the documented F.2B run.

Classification

L3: Configuration / enhancement.
