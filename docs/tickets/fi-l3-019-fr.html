FI-L3-019 · L3

Migration du compte collectif d’un groupe de clients

Problème

Après restructuration du plan, un groupe doit utiliser un nouveau compte collectif.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Les clients restent affectés à l’ancien compte.

Modules concernés

FI-AR / FI-GL

Transactions

OBD2, FS00, RFSEPA01

Diagnostic / besoins

  1. Définir clients, anciens/nouveaux comptes et postes ouverts
  2. Examiner les besoins de migration avec FI

Solution

  1. Coordonner les modifications approuvées et la procédure spécialisée citée RFSEPA01
  2. Confirmer son applicabilité avant exécution

Validation / paramétrage

Rapprocher soldes clients et généraux avant/après migration. Aucun transfert direct non vérifié recommandé.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
