FI-L3-019 · L3

Reconciliation account migration for a customer group

Problem

Finance requires a group of customers to use a different reconciliation account after chart restructuring.

Error message / number

Exact error text and number not provided.

Root cause

The existing customer assignments still point to the former account.

Affected modules

FI-AR / FI-GL

Transactions

OBD2, FS00, RFSEPA01

Diagnosis / requirements

  1. Define affected customers, old/new account and open-item scope
  2. Review the account and migration requirements with FI

Solution

  1. Coordinate approved master-data changes and the specialized transfer procedure referenced as RFSEPA01
  2. Confirm the program's applicability before execution

Validation / configuration

Reconcile customer and G/L balances before and after migration; no unverified direct account transfer is recommended.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
