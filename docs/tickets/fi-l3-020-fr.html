FI-L3-020 · L3

Erreur de détermination de compte dans MIRO

Problème

Le contrôle de facture logistique rejette une facture lors de l’imputation automatique.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Une affectation EM/EF ou différence de prix manque pour la combinaison de valorisation.

Modules concernés

FI-AP / MM

Transactions

OBYC, MIRO, MIGO

Diagnostic / besoins

  1. Identifier opération et classe avec MM
  2. Examiner WRX, PRD et GBB dans OBYC selon le cas.

Solution

  1. Maintenir l’affectation manquante approuvée
  2. Relancer la facture après test.

Validation / paramétrage

Vérifier comptes FI et pièce de facture.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
