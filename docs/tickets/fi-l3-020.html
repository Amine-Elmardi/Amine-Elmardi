FI-L3-020 · L3

Account determination error in MIRO

Problem

Logistics invoice verification rejects a supplier invoice during automatic accounting.

Error message / number

Exact error text and number not provided.

Root cause

An account assignment for GR/IR or price differences is missing for the valuation combination.

Affected modules

FI-AP / MM

Transactions

OBYC, MIRO, MIGO

Diagnosis / requirements

  1. Identify the affected transaction and valuation class with MM
  2. Review WRX, PRD and GBB in OBYC as applicable.

Solution

  1. Maintain the approved missing determination entry
  2. Repeat invoice posting after testing.

Validation / configuration

Check resulting FI accounts and invoice document.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
