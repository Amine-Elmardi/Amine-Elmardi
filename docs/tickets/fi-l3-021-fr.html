FI-L3-021 · L3

Détermination du compte d’acquisition manquante

Problème

Une acquisition ne produit pas l’écriture générale attendue.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le compte d’acquisition manque dans AO90 pour la clé et le plan.

Modules concernés

FI-AA / FI-GL

Transactions

AO90, F-90, ABZON

Diagnostic / besoins

  1. Identifier catégorie, clé de détermination et plan.

Solution

  1. Maintenir le compte approuvé manquant dans AO90
  2. Retester l’acquisition via la transaction appropriée.

Validation / paramétrage

Contrôler les écritures immobilisation et compte général.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
