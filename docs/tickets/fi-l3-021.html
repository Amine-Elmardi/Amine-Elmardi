FI-L3-021 · L3

Asset acquisition account determination fails

Problem

An acquisition does not produce the expected G/L posting.

Error message / number

Exact error text and number not provided.

Root cause

The acquisition account is missing in AO90 for the asset class determination key and chart.

Affected modules

FI-AA / FI-GL

Transactions

AO90, F-90, ABZON

Diagnosis / requirements

  1. Identify asset class, account determination key and chart of accounts.

Solution

  1. Maintain the approved missing acquisition account in AO90
  2. Repeat the acquisition test using the appropriate transaction.

Validation / configuration

Verify the resulting asset and G/L postings.

Classification

L3: Configuration / enhancement.
