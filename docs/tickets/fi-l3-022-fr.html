FI-L3-022 · L3

Résultat de sortie d’immobilisation incorrect

Problème

La vente ou sortie calcule un gain ou une perte inattendus.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le type de mouvement de sortie ou l’affectation du produit est incorrect.

Modules concernés

FI-AA / FI-GL

Transactions

ABAON, ABAVN, AO90, AO74, OAYA

Diagnostic / besoins

  1. Examiner type de sortie et traitement des amortissements cumulés
  2. Contrôler AO74/OAYA et les comptes.

Solution

  1. Corriger la détermination approuvée du résultat ou le défaut confirmé
  2. Retraiter une sortie représentative après test.

Validation / paramétrage

Comparer valeurs et écritures aux attentes de FI.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
