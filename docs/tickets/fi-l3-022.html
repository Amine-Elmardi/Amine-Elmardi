FI-L3-022 · L3

Incorrect gain or loss on asset retirement

Problem

Sale or retirement calculates an unexpected gain or loss.

Error message / number

Exact error text and number not provided.

Root cause

The retirement transaction type or proceeds account assignment is incorrect.

Affected modules

FI-AA / FI-GL

Transactions

ABAON, ABAVN, AO90, AO74, OAYA

Diagnosis / requirements

  1. Inspect retirement transaction type and accumulated depreciation treatment
  2. Review AO74/OAYA and account assignments.

Solution

  1. Correct the approved gain/loss account determination or confirmed configuration defect
  2. Reprocess a representative retirement after testing.

Validation / configuration

Compare retirement values and accounting entries with finance expectations.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
