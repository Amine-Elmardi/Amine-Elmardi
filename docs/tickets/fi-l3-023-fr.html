FI-L3-023 · L3

Modification en masse des clés d’amortissement

Problème

Toute une catégorie doit adopter une méthode révisée.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La nouvelle politique exige de modifier de nombreuses fiches.

Modules concernés

FI-AA

Transactions

AR01, AR31, MASS

Diagnostic / besoins

  1. Confirmer sélection et clé cible approuvée
  2. Examiner la procédure de masse applicable.

Solution

  1. Préparer la modification ou substitution autorisée via l’approche citée appropriée
  2. Appliquer après test uniquement à la sélection vérifiée.

Validation / paramétrage

Comparer paramètres et amortissements;Confirmer les transactions selon la version SAP.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
