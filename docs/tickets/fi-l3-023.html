FI-L3-023 · L3

Mass change of depreciation keys

Problem

An entire asset class needs a revised depreciation method.

Error message / number

Exact error text and number not provided.

Root cause

The new policy requires changes across many existing asset masters.

Affected modules

FI-AA

Transactions

AR01, AR31, MASS

Diagnosis / requirements

  1. Confirm affected asset selection and approved target depreciation key
  2. Review the applicable mass-maintenance procedure.

Solution

  1. Prepare the authorized mass change or substitution using the suitable referenced approach
  2. Apply only to the verified selection after testing.

Validation / configuration

Compare affected asset settings and depreciation results; confirm transaction suitability for the SAP release.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
