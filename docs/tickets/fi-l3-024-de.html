FI-L3-024 · L3

Neue Anlagenklasse erforderlich

Problem

FI benötigt eine Klasse für eine neue Anlagenkategorie, etwa Leasingausstattung.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Keine bestehende Klasse erfüllt die Anforderungen.

Betroffene Module

FI-AA

Transaktionen

AS08, OAOA, AO90

Analyse / Anforderungen

  1. Anlagenklassenanforderungen, Bildaufbau und Kontenfindung bestimmen.

Lösung

  1. Genehmigte Klasse über passenden AS08/OAOA-Ansatz anlegen
  2. Mit in AO90 gepflegtem Kontenfindungsschlüssel verknüpfen.

Erfolgskontrolle / Customizing

Klasseneinstellungen und Kontenzuordnung vor Nutzung prüfen.

Einordnung

L3: Customizing / Erweiterung.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
