FI-L3-024 · L3

Nouvelle catégorie d’immobilisations requise

Problème

FI demande une catégorie pour de nouveaux actifs, par exemple équipements loués.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Aucune catégorie existante ne répond au besoin.

Modules concernés

FI-AA

Transactions

AS08, OAOA, AO90

Diagnostic / besoins

  1. Définir exigences, présentation et détermination des comptes.

Solution

  1. Créer la catégorie approuvée via AS08/OAOA selon le cas
  2. Lier la clé de détermination maintenue dans AO90.

Validation / paramétrage

Vérifier les paramètres et comptes avant utilisation.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
