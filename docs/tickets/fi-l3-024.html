FI-L3-024 · L3

New asset class required

Problem

Finance needs a class for a new fixed-asset category such as leased equipment.

Error message / number

Exact error text and number not provided.

Root cause

No existing asset class meets the category requirements.

Affected modules

FI-AA

Transactions

AS08, OAOA, AO90

Diagnosis / requirements

  1. Define asset class requirements, screen layout and account determination.

Solution

  1. Create the approved class using the applicable AS08/OAOA approach
  2. Link the account determination key mapped in AO90.

Validation / configuration

Verify class settings and account mapping before use.

Classification

L3: Configuration / enhancement.
