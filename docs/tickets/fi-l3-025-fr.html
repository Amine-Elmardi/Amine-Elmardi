FI-L3-025 · L3

Nouveau tableau d’amortissement pour valorisation parallèle

Problème

FI demande une valorisation fiscale ou groupe supplémentaire.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le plan d’amortissement ne contient pas de tableau adapté.

Modules concernés

FI-AA

Transactions

OADB, AS92, OAYC

Diagnostic / besoins

  1. Définir valorisation et conditions avec FI
  2. Examiner le plan existant.

Solution

  1. Configurer le tableau approuvé dans OADB
  2. Établir les valeurs initiales via la procédure de reprise applicable après vérification.

Validation / paramétrage

Rapprocher valeurs initiales et valider la valorisation parallèle avant production.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
