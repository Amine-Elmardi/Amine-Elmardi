FI-L3-026 · L3

Neues Layout für Mahnung oder Zahlungsavis

Problem

Der Fachbereich benötigt Logo, Zusatzfelder oder ein geändertes Layout.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Das bisherige Standardformular enthält die geforderten Inhalte nicht.

Betroffene Module

FI-AP / FI-AR / ABAP Forms

Transaktionen

FBMP, NACE, SMARTFORMS

Analyse / Anforderungen

  1. Felder, Layout und Ausgabeprozess fachlich abstimmen.

Lösung

  1. Smart-Form- oder SAPscript-Änderungen mit ABAP koordinieren
  2. Genehmigte Formularzuordnung im betreffenden Prozess anpassen.

Erfolgskontrolle / Customizing

Testausgabe erstellen und fachliche Abnahme einholen.

Einordnung

L3: Customizing / Erweiterung.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
