FI-L3-026 · L3

Nouvelle présentation de relance ou avis de paiement

Problème

Le métier demande logo, champs supplémentaires ou nouvelle mise en page.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le formulaire standard ne contient pas les éléments requis.

Modules concernés

FI-AP / FI-AR / ABAP Forms

Transactions

FBMP, NACE, SMARTFORMS

Diagnostic / besoins

  1. Confirmer champs, présentation et processus de sortie.

Solution

  1. Coordonner les modifications Smart Form ou SAPscript avec ABAP
  2. Actualiser l’affectation approuvée du formulaire.

Validation / paramétrage

Générer une sortie test et obtenir la validation métier.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
