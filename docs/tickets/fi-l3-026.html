FI-L3-026 · L3

New layout required for dunning or payment advice

Problem

Business requests a logo, additional fields or a revised form layout.

Error message / number

Exact error text and number not provided.

Root cause

The current standard form lacks the required content.

Affected modules

FI-AP / FI-AR / ABAP Forms

Transactions

FBMP, NACE, SMARTFORMS

Diagnosis / requirements

  1. Confirm requested fields, layout and output process with business users.

Solution

  1. Coordinate Smart Form or SAPscript changes with ABAP
  2. Update the approved form assignment in the relevant process configuration.

Validation / configuration

Generate a test output and obtain business acceptance.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
