FI-L3-027 · L3

Neuer Zahlweg im Customizing

Problem

Das Unternehmen benötigt einen neuen Zahlweg, etwa Scheck oder NEFT.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Der Zahlweg fehlt auf Länder- oder Buchungskreisebene.

Betroffene Module

FI-AP / FI-BL

Transaktionen

FBZP, F110

Analyse / Anforderungen

  1. Land, Buchungskreis und benötigtes Zahlungsträgerformat klären.

Lösung

  1. Genehmigten Zahlweg auf beiden Ebenen in FBZP einrichten
  2. Passendes DMEE- oder klassisches Format zuordnen.

Erfolgskontrolle / Customizing

Zahlweg mit F110 testen.

Einordnung

L3: Customizing / Erweiterung.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
