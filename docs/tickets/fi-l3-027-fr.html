FI-L3-027 · L3

Configuration d’un nouveau mode de paiement

Problème

Le métier demande un nouveau mode, par exemple chèque ou NEFT.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le mode manque au niveau pays ou société.

Modules concernés

FI-AP / FI-BL

Transactions

FBZP, F110

Diagnostic / besoins

  1. Confirmer pays, société et format de support de paiement.

Solution

  1. Configurer le mode approuvé aux deux niveaux dans FBZP
  2. Affecter le format DMEE ou classique approprié.

Validation / paramétrage

Tester un paiement via F110.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
