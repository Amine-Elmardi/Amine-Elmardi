FI-L3-029 · L3

IDoc de facture fournisseur ou commande absent ou en erreur

Problème

L’IDoc attendu manque ou échoue à la validation.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Profil partenaire, condition de sortie ou mapping incomplet.

Modules concernés

FI-AP / MM / ALE

Transactions

WE02, WE05, WE20, BD87

Diagnostic / besoins

  1. Vérifier l’existence dans WE02/WE05
  2. Examiner type, statut et profil WE20.

Solution

  1. Corriger le défaut confirmé avec l’équipe responsable
  2. Retraiter l’IDoc existant en erreur via BD87 si applicable.

Validation / paramétrage

Vérifier le traitement sans doublon.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
