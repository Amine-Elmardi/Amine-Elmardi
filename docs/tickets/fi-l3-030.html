FI-L3-030 · L3

Supplier liability account absent from balance sheet node

Problem

A newly created vendor reconciliation account needs to appear under liabilities.

Error message / number

Exact error text and number not provided.

Root cause

The financial statement version has no appropriate mapping for the account.

Affected modules

FI-AP / FI-GL

Transactions

OB58

Diagnosis / requirements

  1. Identify the account and liability node in the reporting structure.

Solution

  1. Assign the account to the approved node in OB58.

Validation / configuration

Run the financial statement version balance check.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
