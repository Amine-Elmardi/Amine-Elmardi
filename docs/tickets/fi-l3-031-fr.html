FI-L3-031 · L3

Code fiscal manquant pour une facture fournisseur

Problème

La facture exige un code absent de la procédure applicable.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le code ou son affectation nationale manque.

Modules concernés

FI-AP / Tax

Transactions

FTXP, OBCL, OB40

Diagnostic / besoins

  1. Confirmer traitement et procédure fiscale avec FI.

Solution

  1. Créer le code et taux approuvés dans FTXP
  2. Maintenir l’affectation comptable dans OB40.

Validation / paramétrage

Valider une facture fournisseur de test.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
