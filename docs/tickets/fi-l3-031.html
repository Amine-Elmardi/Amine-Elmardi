FI-L3-031 · L3

Tax code missing for supplier invoice

Problem

A supplier invoice requires a tax code not available in the applicable procedure.

Error message / number

Exact error text and number not provided.

Root cause

The code or its country-specific assignment is absent.

Affected modules

FI-AP / Tax

Transactions

FTXP, OBCL, OB40

Diagnosis / requirements

  1. Confirm the required tax treatment and procedure with finance.

Solution

  1. Create the approved code and rate in FTXP
  2. Maintain the related G/L assignment in OB40.

Validation / configuration

Validate a sample supplier invoice.

Classification

L3: Configuration / enhancement.
