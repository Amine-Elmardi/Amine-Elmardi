FI-L3-032 · L3

Affectation du compte spécial fournisseur manquante

Problème

Une opération spéciale telle qu’un acompte fournisseur ne détermine pas son compte.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La correspondance indicateur et compte collectif manque.

Modules concernés

FI-AP

Transactions

OBYR, F-48

Diagnostic / besoins

  1. Identifier indicateur et compte collectif normal
  2. Examiner OBYR.

Solution

  1. Maintenir le compte alternatif approuvé dans OBYR.

Validation / paramétrage

Tester l’acompte via F-48 et vérifier le compte.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
