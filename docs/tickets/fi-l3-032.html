FI-L3-032 · L3

Vendor special G/L account assignment missing

Problem

A new special G/L process such as a supplier down payment cannot determine its account.

Error message / number

Exact error text and number not provided.

Root cause

Mapping for the special indicator and reconciliation account is missing.

Affected modules

FI-AP

Transactions

OBYR, F-48

Diagnosis / requirements

  1. Identify the indicator and normal reconciliation account
  2. Review OBYR.

Solution

  1. Maintain the approved alternative account in OBYR.

Validation / configuration

Test the intended down payment with F-48 and verify account determination.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
