FI-L3-033 · L3

Withholding tax rate requires revision

Problem

A revised tax requirement calls for a different withholding tax rate.

Error message / number

Exact error text and number not provided.

Root cause

The maintained rate is outdated.

Affected modules

FI-AP / WHT

Transactions

OBWW, FTXP

Diagnosis / requirements

  1. Confirm the authorized rate, code and effective date with tax specialists.

Solution

  1. Update the withholding tax code configuration using the applicable release-specific settings.

Validation / configuration

Validate the result with a supplier invoice test; confirm applicability of the listed transaction references.

Classification

L3: Configuration / enhancement.
