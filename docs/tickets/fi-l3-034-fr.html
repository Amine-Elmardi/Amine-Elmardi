FI-L3-034 · L3

Compte supplémentaire dans une banque société existante

Problème

La trésorerie nécessite un compte supplémentaire auprès d’une banque configurée.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La banque existe mais identifiant et lien comptable manquent.

Modules concernés

FI-BL / FI-GL

Transactions

FI12, FS00

Diagnostic / besoins

  1. Confirmer banque, identifiant et compte général.

Solution

  1. Ajouter compte approuvé via FI12 selon version
  2. Créer ou lier compte FS00
  3. Adapter la détermination de paiement approuvée si nécessaire.

Validation / paramétrage

Tester affectation et usage du compte.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
