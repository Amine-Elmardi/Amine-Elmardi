FI-L3-034 · L3

Additional account under existing house bank

Problem

Treasury needs another account at a configured bank.

Error message / number

Exact error text and number not provided.

Root cause

House bank exists but the account ID and G/L link are missing.

Affected modules

FI-BL / FI-GL

Transactions

FI12, FS00

Diagnosis / requirements

  1. Confirm existing house bank, new account ID and G/L assignment.

Solution

  1. Add approved account via applicable FI12 approach
  2. Create or link G/L account in FS00
  3. Adjust approved payment determination if required.

Validation / configuration

Test assignment and use of the new account.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
