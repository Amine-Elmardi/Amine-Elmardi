FI-L3-035 · L3

Cycle de répartition avec montants incorrects

Problème

La répartition diffère du résultat attendu.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Les règles émetteur/destinataire ou clés de répartition sont obsolètes.

Modules concernés

CO-OM

Transactions

KSU5, KSV5, S_ALR_87013340

Diagnostic / besoins

  1. Identifier cycle, segment et période
  2. Comparer aux pourcentages approuvés.

Solution

  1. Corriger le segment approuvé
  2. Relancer après contrôle du traitement précédent.

Validation / paramétrage

Rapprocher les montants émetteurs et destinataires.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
