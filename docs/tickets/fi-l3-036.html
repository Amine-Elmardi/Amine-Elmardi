FI-L3-036 · L3

Automatic payment selects wrong house bank

Problem

F110 selects a different bank than requested.

Error message / number

Exact error text and number not provided.

Root cause

Bank ranking is missing or prioritizes another bank for the method and currency.

Affected modules

FI-BL / FI-AP

Transactions

FBZP, F110

Diagnosis / requirements

  1. Review method, currency and ranking in FBZP
  2. Compare with approved treasury requirements.

Solution

  1. Correct approved ranking
  2. Repeat payment proposal.

Validation / configuration

Check selected bank before executing payment.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
