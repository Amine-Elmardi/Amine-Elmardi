FI-L3-037 · L3

Relevé comptabilisé sans lettrage automatique

Problème

Les écritures existent mais les postes correspondants restent ouverts.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

L’algorithme n’utilise pas les critères de pièce ou référence requis.

Modules concernés

FI-BL / FI-AR / FI-AP

Transactions

OT83, FEBA_BANK_STATEMENT

Diagnostic / besoins

  1. Examiner type EBS, règle et algorithme.

Solution

  1. Adapter l’algorithme approuvé dans le paramétrage EBS
  2. Retraiter après contrôle des écritures précédentes.

Validation / paramétrage

Vérifier le lettrage sans doublons.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
