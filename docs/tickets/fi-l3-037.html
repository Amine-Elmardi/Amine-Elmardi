FI-L3-037 · L3

Bank statement posts without automatic clearing

Problem

Statement postings exist but corresponding open items remain uncleared.

Error message / number

Exact error text and number not provided.

Root cause

The matching algorithm does not use the required document or reference criteria.

Affected modules

FI-BL / FI-AR / FI-AP

Transactions

OT83, FEBA_BANK_STATEMENT

Diagnosis / requirements

  1. Review EBS transaction type, posting rule and matching algorithm.

Solution

  1. Adjust the approved algorithm in EBS configuration
  2. Reprocess affected items after checking prior postings.

Validation / configuration

Verify matched items clear without duplicate postings.

Classification

L3: Configuration / enhancement.
