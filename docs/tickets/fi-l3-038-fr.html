FI-L3-038 · L3

Import de relevé électronique en erreur sur mapping

Problème

Le chargement MT940 ou BAI2 échoue.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Les codes externes ne correspondent pas aux règles ou types d’opération.

Modules concernés

FI-BL

Transactions

FF_5, OT83, FEBAN

Diagnostic / besoins

  1. Examiner relevé rejeté et codes
  2. Contrôler mapping OT83.

Solution

  1. Corriger le mapping approuvé
  2. Retraiter via FF_5/FEBAN après contrôle des écritures existantes.

Validation / paramétrage

Vérifier postes et écritures sans doublon.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
