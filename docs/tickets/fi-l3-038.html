FI-L3-038 · L3

Electronic bank statement import fails on mapping

Problem

An MT940 or BAI2 statement upload fails.

Error message / number

Exact error text and number not provided.

Root cause

External transaction codes do not match posting rules or transaction type assignments.

Affected modules

FI-BL

Transactions

FF_5, OT83, FEBAN

Diagnosis / requirements

  1. Inspect rejected statement and codes
  2. Review mapping in OT83.

Solution

  1. Correct approved mapping to posting rules
  2. Reprocess via applicable FF_5/FEBAN route after checking existing postings.

Validation / configuration

Verify imported items and postings without duplicates.

Classification

L3: Configuration / enhancement.
