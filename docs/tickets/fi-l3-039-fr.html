FI-L3-039 · L3

Nouvelle banque société pour compte ouvert

Problème

La trésorerie nécessite un compte pour paiements et rapprochement.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La banque et le compte manquent dans la structure société.

Modules concernés

FI-BL / FI-AP

Transactions

FI01, FI12, FBZP

Diagnostic / besoins

  1. Confirmer clé, identifiants et compte général
  2. Vérifier la fiche bancaire.

Solution

  1. Créer la clé via FI01 si nécessaire
  2. Configurer banque et compte via FI12 selon version
  3. Lier comptes généraux et actualiser FBZP approuvé.

Validation / paramétrage

Tester affectations et traitement des paiements.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
