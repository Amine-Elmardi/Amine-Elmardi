FI-L3-039 · L3

New house bank for an opened bank account

Problem

Treasury requires a new account for payments and reconciliation.

Error message / number

Exact error text and number not provided.

Root cause

The new bank and account are missing from house bank setup.

Affected modules

FI-BL / FI-AP

Transactions

FI01, FI12, FBZP

Diagnosis / requirements

  1. Confirm bank key, account identifiers and G/L assignment
  2. Check bank master existence.

Solution

  1. Create bank key if required via FI01
  2. Configure house bank and account via applicable FI12 route
  3. Link G/L accounts and update approved FBZP settings.

Validation / configuration

Test account assignments and payment processing.

Classification

L3: Configuration / enhancement.
