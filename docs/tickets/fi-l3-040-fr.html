FI-L3-040 · L3

Nouvelles conditions de paiement pour groupe de partenaires

Problème

Un délai négocié nécessite une nouvelle condition.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le catalogue existant ne couvre pas le délai demandé.

Modules concernés

FI-AP / FI-AR

Transactions

OBB8, XK02, XD02

Diagnostic / besoins

  1. Confirmer date de base, limites de jour et groupe approuvés.

Solution

  1. Créer les conditions approuvées dans OBB8
  2. Affecter aux fiches fournisseurs/clients via maintenance applicable.

Validation / paramétrage

Vérifier affectations et échéance attendue.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
