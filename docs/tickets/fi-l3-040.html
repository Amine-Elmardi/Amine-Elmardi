FI-L3-040 · L3

New payment terms for partner category

Problem

A negotiated credit period requires a new payment term.

Error message / number

Exact error text and number not provided.

Root cause

The existing catalogue does not cover the required payment period.

Affected modules

FI-AP / FI-AR

Transactions

OBB8, XK02, XD02

Diagnosis / requirements

  1. Confirm approved baseline date, day limits and partner group.

Solution

  1. Create approved payment terms in OBB8
  2. Assign to relevant supplier/customer masters via applicable maintenance.

Validation / configuration

Verify partner assignments and expected due date.

Classification

L3: Configuration / enhancement.
