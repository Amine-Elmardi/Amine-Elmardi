FI-L3-042 · L3

Payment terms produce unexpected due date

Problem

Invoice maturity differs from the agreed calculation, for example 23 rather than 60 days.

Error message / number

Exact error text and number not provided.

Root cause

Day limit, additional months or fixed-day parameters do not match requirements.

Affected modules

FI-AP / FI-AR

Transactions

OBB8, FBL1N

Diagnosis / requirements

  1. Compare baseline, expected due date and OBB8 settings.

Solution

  1. Correct approved payment term parameters in OBB8
  2. Test representative invoices.

Validation / configuration

Compare due dates in the line item report with agreed logic.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
