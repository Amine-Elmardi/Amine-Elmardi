FI-L3-043 · L3

Production overhead uses incorrect percentage

Problem

Overhead calculation produces an unexpected percentage.

Error message / number

Exact error text and number not provided.

Root cause

The costing sheet rate is outdated or its validity expired.

Affected modules

CO-PC

Transactions

KZS2, CK11N

Diagnosis / requirements

  1. Identify costing sheet, rate and validity
  2. Confirm revised percentage.

Solution

  1. Update the approved overhead rate and validity
  2. Recalculate overhead for affected orders.

Validation / configuration

Compare calculation against the approved rate.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
