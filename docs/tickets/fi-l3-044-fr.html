FI-L3-044 · L3

Compte de compensation à solde nul manquant

Problème

La pièce n’est pas équilibrée par centre de profit.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le compte de compensation à solde nul manque dans la ventilation.

Modules concernés

CO-PCA / FI-GL

Transactions

GSP_LD (transaction), GLPCT (related reference)

Diagnostic / besoins

  1. Identifier opération concernée
  2. Examiner ventilation et affectation du compte.

Solution

  1. Configurer le compte approuvé
  2. Tester puis retraiter les écritures en échec.

Validation / paramétrage

Vérifier l’équilibrage par centre de profit.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
