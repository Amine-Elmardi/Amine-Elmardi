FI-L3-044 · L3

Profit center zero-balance clearing account missing

Problem

The document fails balancing by profit center.

Error message / number

Exact error text and number not provided.

Root cause

A zero-balance clearing G/L account is absent from document splitting settings.

Affected modules

CO-PCA / FI-GL

Transactions

GSP_LD (transaction), GLPCT (related reference)

Diagnosis / requirements

  1. Identify the relevant business transaction
  2. Review splitting and clearing account assignment.

Solution

  1. Configure the approved zero-balance account
  2. Test and reprocess failed postings after review.

Validation / configuration

Verify document balancing by profit center.

Classification

L3: Configuration / enhancement.
