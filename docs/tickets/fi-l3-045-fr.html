FI-L3-045 · L3

Rapport de rentabilité à zéro pour une caractéristique

Problème

CO-PA ne présente pas les données attendues pour une caractéristique.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le scénario attribue le manque à une règle de dérivation absente.

Modules concernés

CO-PA / SD

Transactions

KEDR, KE4S, KE30

Diagnostic / besoins

  1. Identifier caractéristique et factures
  2. Examiner la dérivation KEDR.

Solution

  1. Corriger la règle approuvée
  2. Retraiter les factures via KE4S si applicable après test.

Validation / paramétrage

Contrôler caractéristique et valeurs dans KE30.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
