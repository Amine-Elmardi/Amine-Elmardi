FI-L3-045 · L3

Profitability report shows zero for characteristic

Problem

CO-PA does not show the expected data for a characteristic.

Error message / number

Exact error text and number not provided.

Root cause

The scenario attributes this to a missing derivation rule in the operating concern.

Affected modules

CO-PA / SD

Transactions

KEDR, KE4S, KE30

Diagnosis / requirements

  1. Identify characteristic and affected billing documents
  2. Review derivation in KEDR.

Solution

  1. Correct the approved rule
  2. Reprocess billing documents via applicable KE4S procedure after testing.

Validation / configuration

Check characteristic and values in KE30.

Classification

L3: Configuration / enhancement.
