FI-L3-046 · L3

Type de facture non lié au type de pièce FI

Problème

Une facture commerciale ne produit pas sa pièce FI.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Affectation du type de facture ou détermination des produits incomplète.

Modules concernés

FI / SD

Transactions

VOFA, VKOA, VFX3

Diagnostic / besoins

  1. Examiner VOFA et combinaison VKOA en erreur.

Solution

  1. Corriger l’affectation approuvée confirmée
  2. Libérer via VFX3 selon le cas.

Validation / paramétrage

Vérifier type de pièce FI et compte de produit.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
