FI-L3-048 · L3

Goods receipt fails automatic account determination

Problem

MIGO rejects a material receipt during accounting.

Error message / number

Exact error text and number not provided.

Root cause

The relevant OBYC key for movement and valuation class lacks an account.

Affected modules

FI / MM

Transactions

OBYC, MIGO

Diagnosis / requirements

  1. Identify movement, valuation class and applicable BSX or GBB key with MM.

Solution

  1. Maintain approved missing G/L mapping in OBYC
  2. Repeat goods movement after testing.

Validation / configuration

Check resulting material and accounting documents.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
