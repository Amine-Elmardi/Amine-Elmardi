FI-L3-049 · L3

GST incorrectly included in withholding base

Problem

Withholding tax is calculated on a tax-inclusive amount although the approved base excludes GST.

Error message / number

Exact error text and number not provided.

Root cause

Base configuration does not exclude the relevant GST condition.

Affected modules

FI-WHT / Tax

Transactions

OBWW, FTXP

Diagnosis / requirements

  1. Compare invoice base and GST amounts with tax requirements.

Solution

  1. Correct approved WHT base configuration to exclude the applicable GST amount.

Validation / configuration

Test invoice and compare taxable base and deduction.

Classification

L3: Configuration / enhancement.
