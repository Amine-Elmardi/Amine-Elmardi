FI-L3-050 · L3

IDoc absent ou en erreur dans les flux achats et ventes

Problème

Une commande ou facture ne produit pas d’IDoc traité avec succès.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Profil, condition de sortie ou données de segment obligatoires incomplets.

Modules concernés

FI / MM / SD / ALE

Transactions

WE02, WE05, WE19, BD87, WE20, NACE, MN04

Diagnostic / besoins

  1. Déterminer si l’IDoc existe
  2. Examiner statut WE02/WE05 et paramètres partenaire/sortie.

Solution

  1. Corriger le défaut confirmé
  2. Utiliser WE19 pour test contrôlé et BD87 pour IDocs existants applicables.

Validation / paramétrage

Vérifier le traitement sans doublon.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
