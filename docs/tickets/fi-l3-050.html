FI-L3-050 · L3

Missing or failed IDoc across purchasing and sales

Problem

A purchase order, invoice or sales order interface produces no successful IDoc.

Error message / number

Exact error text and number not provided.

Root cause

Partner profile, output condition or mandatory segment data is incomplete.

Affected modules

FI / MM / SD / ALE

Transactions

WE02, WE05, WE19, BD87, WE20, NACE, MN04

Diagnosis / requirements

  1. Determine whether IDoc exists
  2. Inspect status in WE02/WE05 and partner/output settings.

Solution

  1. Correct confirmed profile, output or segment defect
  2. Use WE19 for controlled testing and BD87 for applicable existing failed IDocs.

Validation / configuration

Confirm successful interface processing without duplicates.

Classification

L3: Configuration / enhancement.
