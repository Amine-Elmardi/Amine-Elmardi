FI-L3-051 · L3

Compte général manquant pour pièce FI issue de MM

Problème

Une opération article intégrée ne détermine pas son compte.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La classe de valorisation n’a pas de mapping OBYC correspondant.

Modules concernés

FI / MM

Transactions

OBYC, MM03

Diagnostic / besoins

  1. Examiner classe dans MM03 et détermination applicable.

Solution

  1. Coordonner le compte approuvé manquant dans OBYC avec MM
  2. Retenter après test.

Validation / paramétrage

Vérifier le compte attendu dans la pièce.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
