FI-L3-051 · L3

MM-triggered FI document missing G/L account

Problem

An integrated material transaction cannot determine its account.

Error message / number

Exact error text and number not provided.

Root cause

The material valuation class has no corresponding OBYC mapping.

Affected modules

FI / MM

Transactions

OBYC, MM03

Diagnosis / requirements

  1. Inspect valuation class in MM03 and relevant account determination.

Solution

  1. Coordinate approved missing account entry in OBYC with MM
  2. Retry the transaction after testing.

Validation / configuration

Verify expected account in the resulting document.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
