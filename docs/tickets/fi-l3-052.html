FI-L3-052 · L3

New withholding code for statutory section

Problem

An applicable tax section has no corresponding code.

Error message / number

Exact error text and number not provided.

Root cause

The required type/code and posting treatment are not configured.

Affected modules

FI-WHT

Transactions

OBWO, OBWW

Diagnosis / requirements

  1. Confirm approved section, rate and posting indicator.

Solution

  1. Create the required type and code in applicable configuration
  2. Assign to relevant supplier records.

Validation / configuration

Verify assignment and test tax calculation.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
