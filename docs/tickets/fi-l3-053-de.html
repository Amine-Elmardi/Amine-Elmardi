FI-L3-053 · L3

Preiskondition ohne Erlöskontoschlüssel

Problem

Erlösbuchung scheitert bei einer bestimmten Preiskondition.

Fehlermeldung / Nummer

Genauer Meldungstext und Meldungsnummer nicht angegeben.

Ursache

Der Kondition fehlt der Kontoschlüssel und die entsprechende Kontenfindung.

Betroffene Module

FI / SD

Transaktionen

V/08, VKOA

Analyse / Anforderungen

  1. Kondition im Kalkulationsschema V/08 bestimmen
  2. Relevante VKOA-Kombination prüfen.

Lösung

  1. Genehmigten Kontoschlüssel zuordnen und passenden Erlöskonteneintrag pflegen.

Erfolgskontrolle / Customizing

Integrierte Fakturabuchung testen.

Einordnung

L3: Customizing / Erweiterung.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit Freigabe.
