FI-L3-053 · L3

Condition de prix sans clé de compte de produit

Problème

L’écriture de produit échoue pour une condition particulière.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

La clé et la détermination correspondante manquent.

Modules concernés

FI / SD

Transactions

V/08, VKOA

Diagnostic / besoins

  1. Identifier condition dans V/08
  2. Examiner combinaison VKOA.

Solution

  1. Affecter la clé approuvée et maintenir le compte correspondant.

Validation / paramétrage

Tester la comptabilisation intégrée.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
