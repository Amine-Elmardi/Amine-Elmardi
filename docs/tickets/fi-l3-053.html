FI-L3-053 · L3

Pricing condition has no revenue account key

Problem

Revenue posting fails for a particular pricing condition.

Error message / number

Exact error text and number not provided.

Root cause

The condition lacks an assigned account key and corresponding determination.

Affected modules

FI / SD

Transactions

V/08, VKOA

Diagnosis / requirements

  1. Identify condition in pricing procedure V/08
  2. Review relevant VKOA combination.

Solution

  1. Assign approved account key and maintain corresponding revenue account entry.

Validation / configuration

Test the integrated billing posting.

Classification

L3: Configuration / enhancement.
