FI-L3-055 · L3

Certificat TDS nécessitant des champs supplémentaires

Problème

Le certificat doit inclure TAN, versement ou signataire.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le formulaire actuel ne contient pas les champs requis.

Modules concernés

FI-WHT / ABAP

Transactions

J1INCERT, SMARTFORMS

Diagnostic / besoins

  1. Convenir des champs et identifier le formulaire.

Solution

  1. Coordonner les modifications approuvées Smart Form ou SAPscript avec ABAP.

Validation / paramétrage

Générer et contrôler un certificat test.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
