FI-L3-056 · L3

Taux TDS obsolète après révision réglementaire

Problème

Une facture utilise encore l’ancien taux.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le code de retenue conserve les anciens taux ou dates.

Modules concernés

FI-WHT

Transactions

OBWW, FTXP

Diagnostic / besoins

  1. Confirmer taux et période avec les fiscalistes.

Solution

  1. Actualiser taux et validité approuvés dans le paramétrage applicable.

Validation / paramétrage

Tester une facture à la date d’effet; confirmer les transactions.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
