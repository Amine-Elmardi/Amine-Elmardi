FI-L3-057 · L3

Seuil d’exonération de retenue non appliqué

Problème

Un fournisseur ne bénéficie pas de l’exonération attendue.

Message / numéro d’erreur

Texte exact et numéro du message non indiqués.

Cause racine

Le minimum ou seuil est mal renseigné.

Modules concernés

FI-WHT

Transactions

OBWW, OB WT (reference to confirm)

Diagnostic / besoins

  1. Confirmer seuil et traitement cumulatif avec les fiscalistes.

Solution

  1. Corriger le seuil approuvé dans les paramètres type/code applicables.

Validation / paramétrage

Tester des écritures cumulées sous et au-dessus du seuil.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
