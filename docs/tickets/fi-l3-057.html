FI-L3-057 · L3

Withholding exemption threshold not applied

Problem

A supplier does not receive the expected threshold exemption.

Error message / number

Exact error text and number not provided.

Root cause

Minimum base or exemption limit is maintained incorrectly.

Affected modules

FI-WHT

Transactions

OBWW, OB WT (reference to confirm)

Diagnosis / requirements

  1. Confirm applicable threshold and cumulative treatment with tax specialists.

Solution

  1. Correct approved threshold in the relevant WHT type/code settings.

Validation / configuration

Test cumulative postings below and above the threshold.

Classification

L3: Configuration / enhancement.
