FI-L3-058 · L3

Bank details and remarks missing from correspondence form

Problem

The dunning notice or payment advice lacks requested bank details or remarks.

Error message / number

Exact error text and number not provided.

Root cause

The existing form layout does not contain these fields.

Affected modules

FI-AR / FI-AP / ABAP Forms

Transactions

FBMP, SMARTFORMS, NACE

Diagnosis / requirements

  1. Agree required fields and identify the active form assignment.

Solution

  1. Coordinate approved Smart Form layout change with ABAP
  2. Update the relevant dunning or output form assignment.

Validation / configuration

Generate a test document and validate requested fields and layout.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
