FI-L3-059 · L3

Customer or supplier statement print output missing

Problem

A requested account statement does not produce print output.

Error message / number

Exact error text and number not provided.

Root cause

The correspondence type is not assigned to the company code or a print-program variant is missing.

Affected modules

FI-AR / FI-AP / Correspondence

Transactions

OB78, F.27, F.61

Diagnosis / requirements

  1. Identify company code, correspondence type and request
  2. Review print-program settings.

Solution

  1. Maintain the approved correspondence assignment and required variant
  2. Reissue through the applicable correspondence process.

Validation / configuration

Verify the statement is generated for the intended account.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
