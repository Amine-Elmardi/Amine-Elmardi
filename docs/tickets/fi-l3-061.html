FI-L3-061 · L3

Management reporting requires a new financial statement hierarchy

Problem

Finance needs different groupings and subgroups for management reporting.

Error message / number

Exact error text and number not provided.

Root cause

The current financial statement version does not support the requested hierarchy.

Affected modules

FI-GL / Reporting

Transactions

OB58

Diagnosis / requirements

  1. Obtain the approved node hierarchy and account mapping.

Solution

  1. Create the new version in OB58
  2. Assign G/L accounts to corresponding nodes.

Validation / configuration

Run the consistency check and verify the requested reporting structure.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
