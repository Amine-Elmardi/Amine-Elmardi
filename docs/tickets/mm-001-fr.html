MM-L2-035 · L2

Les conditions de prix enregistrées ne sont pas reprises dans la commande

Problème

Lors de la création ou de la modification d’une commande d’achat, la condition attendue manque alors qu’un enregistrement de condition existe déjà. Le problème ne se limite donc pas à un prix absent.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document attribue l’incident à l’absence du groupe de schéma fournisseur dans les données de l’organisation d’achats, une affectation nécessaire à la détermination du prix.

Modules concernés

MM – Achats / données de base fournisseur

Transactions

XK02, ME22N, MEK3, MEK1

Diagnostic

Ouvrir le fournisseur dans XK02 et examiner les données de l’organisation d’achats. Vérifier si le groupe de schéma fournisseur est vide dans la section de prix. Contrôler la condition attendue dans MEK3.

Solution

Renseigner le groupe de schéma correct dans XK02 et enregistrer. Rouvrir la commande dans ME22N et effectuer l’actualisation des prix décrite dans la source. Vérifier que la condition attendue est reprise.

Validation / paramétrage

Comparer la condition de la commande avec MEK3. Aucun changement SPRO n’est nécessaire dans le scénario décrit.

Classification

L2 : le diagnostic relie les conditions d’achat aux données de base fournisseur.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
