MM-L2-035 · L2

Purchase order does not pick up maintained pricing conditions

Problem

The buyer creates or changes a purchase order, but the expected pricing condition is absent even though a condition record has been maintained. The issue is therefore not simply the absence of a price record.

Error message / number

Not specified in the source.

Root cause

The document attributes the incident to a missing vendor schema group in purchasing organization data. The vendor master assignment required for pricing has not been maintained.

Affected modules

MM – Purchasing / vendor master data

Transactions

XK02, ME22N, MEK3, MEK1

Diagnosis

Open the vendor in XK02 and inspect purchasing organization data. In the pricing section, check whether the vendor schema group is blank. Compare the expected condition record in MEK3.

Solution

Maintain the correct vendor schema group in XK02 and save. Reopen the affected order in ME22N and use the pricing update described in the source. Check that the expected condition is now retrieved.

Validation / configuration

Confirm the condition in the purchase order against MEK3. No SPRO change is required in the documented scenario.

Classification

L2: the case requires diagnosis across purchasing conditions and vendor master data.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
