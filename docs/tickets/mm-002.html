MM-002 · L2

MM period change fails for a company code

Problem

During month-end processing MMPV reports that the period is already closed or cannot be opened for a company code.

Error message / number

period already open — Message number not specified.

Root cause

The source identifies an omitted period-closing activity or an incorrect period entry.

Affected modules

MM

Transactions

MMPV, MMRV

Diagnosis / requirements

  1. Identify the company code and intended period and year
  2. Use MMRV to establish the current period, especially if the reported message is period already open

Solution

  1. Have the responsible period-management team review the intended change in MMPV
  2. The source describes closing the previous period and opening the correct period, but the exact procedure must be confirmed before execution
  3. Repeat only for affected company codes

Validation / configuration

Verify the intended period in MMRV. No SPRO change is prescribed. L2 reflects company-code-wide impact.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 7, #002. Document-based educational scenario; not independently verified. Production changes require authorization.
