MM-L1-007 · L1

Échec du chargement des prix en raison du format décimal

Problème

Lors du chargement des prix d’une commande, le fichier utilise un séparateur décimal différent du format SAP de l’utilisateur. Le chargement échoue.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le format décimal défini dans SU3 ne correspond pas à celui du fichier.

Modules concernés

MM – Achats / paramètres utilisateur

Transactions

SU3

Diagnostic

Ouvrir SU3 et consulter le format décimal dans les valeurs par défaut. Comparer les séparateurs décimaux et de milliers avec le fichier.

Solution

Choisir le format correspondant au fichier, enregistrer les paramètres et relancer le chargement. Pour les chargements en masse, le document mentionne aussi LSMW ou un programme spécifique utilisant un format cohérent.

Validation / paramétrage

Vérifier que les prix sont acceptés après la modification. Aucun changement SPRO n’est nécessaire.

Classification

L1 : un paramètre utilisateur suffit dans le cas décrit.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
