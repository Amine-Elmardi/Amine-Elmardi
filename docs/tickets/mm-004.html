MM-004 · L1

Price upload fails because of decimal notation

Problem

A buyer attempts to upload purchase order prices. The file uses a decimal separator different from the user's SAP format, and the upload fails.

Error message / number

Not specified in the source.

Root cause

The user's decimal notation in SU3 differs from the notation used in the upload file.

Affected modules

MM – Purchasing / user settings

Transactions

SU3

Diagnosis

Open SU3 and inspect Decimal Notation under Defaults. Compare the decimal and thousands separators with the input file.

Solution

Select the notation matching the file, save the user settings and retry the upload. The document also mentions LSMW or a custom program for bulk uploads with consistent formatting.

Validation / configuration

Check whether the upload accepts the prices after the setting change. No SPRO configuration change is needed.

Classification

L1: a user-level setting is sufficient in the documented case.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 8, #004. Document-based educational scenario; not independently verified.
