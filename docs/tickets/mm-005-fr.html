MM-L2-020 · L2

Taux de change incorrect dans une commande d’achat

Problème

Le service achats signale une conversion de devise incorrecte dans une commande. Le ticket arrive chez MM alors que la gestion des taux relève de FI.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document attribue la gestion des taux de change dans OB08 à FI.

Modules concernés

MM / FI

Transactions

ME23N, OB08, ME22N

Diagnostic

Examiner la commande et comparer DMBTR et WRBTR selon la source. Relever le numéro de commande et la devise pour FI.

Solution

Transmettre le ticket à FI. FI actualise le taux dans OB08. Rouvrir la commande dans ME22N et actualiser le taux.

Validation / paramétrage

Confirmer les valeurs corrigées avec l’utilisateur. OB08 relève de FI.

Classification

L2 : analyse du document d’achat et coordination avec FI.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
