MM-L2-020 · L2

Incorrect exchange rate in a purchase order

Problem

The purchaser reports incorrect currency conversion in a purchase order. The incident reaches MM, although the exchange rate is maintained by FI.

Error message / number

Not specified in the source.

Root cause

The document identifies exchange-rate maintenance in OB08 as an FI responsibility.

Affected modules

MM / FI

Transactions

ME23N, OB08, ME22N

Diagnosis

Inspect the order and compare DMBTR and WRBTR as described in the source. Record the order number and currency for the FI team.

Solution

Forward the incident to FI. FI updates the exchange rate in OB08. Reopen the purchase order in ME22N and refresh the rate.

Validation / configuration

Confirm the corrected purchase order values with the user. OB08 is the responsibility of FI.

Classification

L2: analysis of the purchasing document and coordination with FI.
