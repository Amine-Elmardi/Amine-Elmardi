MM-006 · L1

Le montant de facture ne se recalcule pas avec la quantité

Problème

L’utilisateur attend une adaptation du montant lorsque la quantité saisie dans MIRO change.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source attribue ce comportement aux valeurs personnelles de proposition de quantité.

Modules concernés

MM

Transactions

SU3, MIRO, MIR7, OMR6

Diagnostic / besoins

  1. Examiner SU3 et la disponibilité de la proposition décrite
  2. Comparer MIR7 ou MIRO avec la quantité réceptionnée attendue

Solution

  1. Le document propose l’option Propose GR Qty dans SU3
  2. Il décrit aussi Édition → Recalculer dans MIRO
  3. Si le problème persiste, transmettre le contrôle OMR6 cité au support fonctionnel

Validation / paramétrage

Vérifier la proposition de quantité et de montant. La disponibilité des options n’est pas vérifiée indépendamment. L1 couvre les paramètres utilisateur, pas les tolérances.

Classification

L1: Correction opérationnelle individuelle.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 9, #006. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
