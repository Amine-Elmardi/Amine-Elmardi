MM-L1-002 · L1

Invoice price does not recalculate with quantity

Problem

An invoice user expects the amount to change when the quantity entered in MIRO changes.

Error message / number

Not specified in the source.

Root cause

The source attributes the behavior to personal defaults for quantity proposal.

Affected modules

MM

Transactions

SU3, MIRO, MIR7, OMR6

Diagnosis / requirements

  1. Review the user defaults in SU3 and whether the described quantity proposal is available
  2. Compare behavior in MIR7 or MIRO with the expected goods receipt quantity

Solution

  1. The document proposes enabling the Propose GR Qty option in SU3
  2. Alternatively it describes Edit → Recalculate in MIRO
  3. If the issue persists, refer the documented OMR6 tolerance review to functional support

Validation / configuration

Check whether the expected quantity and amount are proposed. The availability of the named options is not independently verified. L1 covers user settings, not tolerance changes.

Classification

L1: Individual operational correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
