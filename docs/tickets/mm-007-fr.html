MM-007 · L3

Champs fournisseur masqués par le groupe de comptes

Problème

Un utilisateur ne peut pas saisir, par exemple, les coordonnées bancaires ou les conditions de paiement, car les champs correspondants sont masqués dans la fiche fournisseur.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document identifie la sélection des zones du groupe de comptes fournisseur comme cause.

Modules concernés

MM – Données de base fournisseur / FI – Comptabilité fournisseurs

Transactions

OBD3, XK02, XK03

Diagnostic

Identifier le groupe de comptes du fournisseur et examiner le statut des zones dans OBD3. Déterminer si les champs nécessaires sont supprimés de l’affichage.

Solution

La correction décrite consiste à rendre les champs concernés facultatifs ou obligatoires dans OBD3, puis à enregistrer. Il s’agit d’un changement de paramétrage, et non d’une simple correction de fiche fournisseur. Coordonner ce changement structurel avec l’équipe des données de base.

Validation / paramétrage

Ouvrir le fournisseur dans XK02 et vérifier que les champs sont modifiables. Paramétrage indiqué : SPRO → Comptabilité financière → Comptabilité fournisseurs → Comptes fournisseurs → Définir les groupes de comptes.

Classification

L3 : la solution modifie le paramétrage du groupe de comptes ; la source classe ce cas en L1.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 10, #007. Cas pédagogique fondé sur le document ; non vérifié indépendamment.
