MM-L3-034 · L3

Vendor master fields are hidden by account group settings

Problem

A user cannot enter information such as bank details or payment terms because the corresponding fields are hidden or suppressed in the vendor master.

Error message / number

Not specified in the source.

Root cause

The document identifies the field selection settings of the assigned vendor account group as the cause.

Affected modules

MM – Vendor master data / FI – Accounts Payable

Transactions

OBD3, XK02, XK03

Diagnosis

Identify the vendor's account group and inspect its field status in OBD3. Determine whether the required fields are suppressed.

Solution

The documented correction is to change the relevant field status to optional or required in OBD3 and save. This is a configuration change rather than a simple vendor-record correction; coordinate the structural change with the master data team.

Validation / configuration

Open the vendor in XK02 and verify that the fields are editable. Configuration area: SPRO → Financial Accounting → Accounts Payable → Vendor Accounts → Define Account Groups.

Classification

L3: the documented solution changes account group configuration; the source labels this case L1.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
