MM-008 · L2

La sortie de commande n’est pas générée

Problème

Après création ou modification de la commande, l’impression ou l’envoi par e-mail attendu ne se déclenche pas.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source indique des enregistrements de condition manquants ou un type de message absent du schéma.

Modules concernés

MM

Transactions

ME22N, MN04, ME9F, MN05

Diagnostic

  1. Examiner les messages dans ME22N.
  2. Vérifier la présence de NEU ou du type spécifique prévu.

Solution

  1. Maintenir la condition manquante dans MN04.
  2. Affecter la sortie à la fonction partenaire fournisseur LF.
  3. Relancer le traitement dans ME9F.

Validation / paramétrage

Contrôler le statut dans NAST. La source renvoie à SPRO → MM → Achats → Messages → Détermination des messages.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 10, #008. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
