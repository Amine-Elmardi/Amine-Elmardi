MM-L2-037 · L2

Purchase order output is not generated

Problem

After creating or changing a purchase order, no expected print or email output is generated.

Error message / number

Not specified in the source.

Root cause

The source attributes the problem to missing output condition records or an output type absent from the message schema.

Affected modules

MM

Transactions

ME22N, MN04, ME9F, MN05

Diagnosis

  1. Inspect the Messages tab in ME22N.
  2. Check whether NEU or the relevant custom output type exists.

Solution

  1. If the condition record is missing, maintain it in MN04.
  2. Assign the output to the vendor partner function LF.
  3. Retrigger processing in ME9F.

Validation / configuration

Inspect the output status in NAST. The source refers to SPRO → MM → Purchasing → Messages → Output Determination.

Classification

L2: Functional analysis and coordinated correction.
