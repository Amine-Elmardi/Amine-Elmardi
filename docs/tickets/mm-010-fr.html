MM-010 · L2

Article indisponible dans une nouvelle division

Problème

Un article existant ne peut pas être utilisé comme prévu pour les achats ou les opérations de magasin dans une nouvelle division.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Les vues organisationnelles requises n’ont pas été étendues à cette division.

Modules concernés

MM – Fiche article / Achats / Gestion des stocks

Transactions

MM01, MM02, MM03

Diagnostic

Identifier l’article et la division cible. Déterminer les vues nécessaires : achats, MRP 1/2, données générales de division et stockage.

Solution

Ouvrir MM01 avec le numéro d’article existant. Sélectionner la division cible et les vues nécessaires. Renseigner les champs obligatoires, notamment le type MRP, le type d’approvisionnement et le magasin selon le besoin, puis enregistrer.

Validation / paramétrage

Vérifier les vues de division dans MM03 et informer le demandeur. Aucun changement SPRO n’est décrit.

Classification

L2 : extension des données de base organisationnelles sur plusieurs vues.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 11, #010. Cas pédagogique fondé sur le document ; non vérifié indépendamment.
