MM-L2-030 · L2

Material unavailable in a new plant

Problem

A material already exists but cannot be used for purchasing or warehouse activities in a new plant.

Error message / number

Not specified in the source.

Root cause

The required organizational views have not been extended to that plant.

Affected modules

MM – Material master / Purchasing / Inventory Management

Transactions

MM01, MM02, MM03

Diagnosis

Identify the material and target plant. Determine which views are required: purchasing, MRP 1/2, general plant data and storage.

Solution

Open MM01 with the existing material number. Select the target plant and required views. Complete the mandatory fields, such as MRP type, procurement type and storage location, as applicable, then save.

Validation / configuration

Use MM03 to verify that the plant views exist and inform the requesting user. No SPRO change is described.

Classification

L2: extension of organizational master data across several views.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
