MM-L2-039 · L2

Purchase requisition release strategy is not triggered

Problem

A purchase requisition remains outside the approval process. The source describes the status Not Subject to Release.

Error message / number

Not Subject to Release — Message number not specified.

Root cause

Its value or characteristics do not match the release conditions, for example the threshold or document type.

Affected modules

MM

Transactions

ME53N, ME54N, OMGS

Diagnosis

  1. Display the requisition in ME53N and inspect release information.
  2. Compare plant, purchasing organization and value with the conditions in OMGS.
  3. Review classification using ME54N as described in the document.

Solution

  1. If the value changes, the source describes a reevaluation of the strategy.
  2. Use the release configuration simulation to test the matching conditions.

Validation / configuration

Check the release result. The source references the classified release procedure in SPRO, but does not prescribe changing the strategy for this case.

Classification

L2: Functional analysis and coordinated correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
