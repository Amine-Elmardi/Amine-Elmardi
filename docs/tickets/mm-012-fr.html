MM-L1-006 · L1

Mouvement 101 indisponible pour une entrée sur commande

Problème

Dans MIGO, l’utilisateur ne peut pas sélectionner le mouvement 101 ou rencontre une erreur lors de l’entrée de marchandises sur commande.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source indique que le code d’entrée de marchandises du poste de commande est inactif. Elle mentionne aussi une influence possible du contrôle des factures basé sur les entrées.

Modules concernés

MM – Achats / Gestion des stocks

Transactions

ME22N, MIGO, MB03

Diagnostic

Ouvrir la commande concernée dans ME22N. Dans les détails du poste, consulter l’onglet Livraison et vérifier si le code d’entrée de marchandises est actif.

Solution

Activer le code et enregistrer la commande. Dans MIGO, choisir une entrée de marchandises avec référence à une commande et saisir son numéro. Vérifier la disponibilité du mouvement 101.

Validation / paramétrage

Après comptabilisation, contrôler le document article dans MB03. La source prévoit une correction au niveau du poste sans modification SPRO.

Classification

L1 : correction d’un indicateur dans un poste de commande.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
