MM-L1-006 · L1

Movement type 101 unavailable for purchase order receipt

Problem

The user cannot select movement type 101 or receives an error when attempting a goods receipt against a purchase order in MIGO.

Error message / number

Not specified in the source.

Root cause

The source identifies an inactive goods receipt indicator in the purchase order item. It also mentions a possible influence of GR-based invoice verification.

Affected modules

MM – Purchasing / Inventory Management

Transactions

ME22N, MIGO, MB03

Diagnosis

Open the affected purchase order in ME22N. In the item details, inspect the Delivery tab and check whether the goods receipt indicator is active.

Solution

Activate the goods receipt indicator and save the purchase order. Open MIGO, select goods receipt with purchase order reference, and enter the purchase order number. Check whether movement type 101 is available.

Validation / configuration

After posting, confirm the material document in MB03. The document specifies an item-level correction without SPRO changes.

Classification

L1: correction of an individual purchase order indicator.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
