MM-L2-040 · L2

Purchasing info record price is not proposed

Problem

A purchasing info record exists, but when a buyer creates a purchase order the expected price is not proposed.

Error message / number

Not specified in the source.

Root cause

The record may belong to a different organizational combination, or its validity period may have expired.

Affected modules

MM – Purchasing / Purchasing master data

Transactions

ME13, ME12, ME21N

Diagnosis

  1. Display the info record in ME13.
  2. Compare the material, supplier, purchasing organization and plant with the purchase order.
  3. Check validity dates and the net price. If several records exist, the source recommends examining priority in configuration.
  4. In ME21N check which source is being used.

Solution

  1. If the price is outdated, maintain the info record in ME12.
  2. Check the price proposal again when creating the purchase order.

Validation / configuration

Verify that the intended record and its valid price are used. The source refers to the SPRO purchasing info record conditions area; it does not specify a concrete configuration change for this incident.

Classification

L2: diagnosis of organizational assignment, validity and purchasing price data.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
