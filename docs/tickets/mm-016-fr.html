MM-016 · L2

Facture bloquée en raison d’un écart de prix

Problème

La facture est comptabilisée mais reste bloquée pour paiement en raison d’un écart de prix.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le prix facturé dépasse la tolérance paramétrée, notamment la clé PP.

Modules concernés

MM / FI

Transactions

MIRO, MIR6, MRBR, OMR6

Diagnostic

  1. Identifier la facture bloquée dans MIR6.
  2. Analyser l’écart dans MIRO.

Solution

  1. Si l’écart est acceptable, la source indique la libération via MRBR.
  2. Si une modification de tolérance est nécessaire, la source cite OMR6 et les clés PP ou BD. Il s’agit d’une décision de paramétrage distincte.
  3. Obtenir l’accord métier avant la libération après un tel ajustement.

Validation / paramétrage

Contrôler le statut de libération. La source renvoie à SPRO → MM → Contrôle des factures logistiques → Blocage → Limites de tolérance.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 14, #016. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
