MM-L2-023 · L2

Invoice blocked for price variance

Problem

The invoice has been posted but remains blocked for payment because of a price difference.

Error message / number

Not specified in the source.

Root cause

The documented invoice price exceeds the configured tolerance, particularly key PP.

Affected modules

MM / FI

Transactions

MIRO, MIR6, MRBR, OMR6

Diagnosis

  1. Locate the blocked invoice in MIR6.
  2. Inspect the price difference in MIRO.

Solution

  1. If the variance is acceptable, use MRBR to release the invoice as described in the source.
  2. If a tolerance change is required, the source refers to OMR6 and keys PP or BD. Treat that as a separate configuration decision.
  3. Obtain business approval before the release following such an adjustment.

Validation / configuration

Confirm release status. The source references SPRO → MM → Logistics Invoice Verification → Invoice Block → Set Tolerance Limits.

Classification

L2: Functional analysis and coordinated correction.
