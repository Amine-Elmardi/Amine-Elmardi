MM-L2-028 · L2

Article exclu du calcul MRP

Problème

Après le calcul des besoins, aucun ordre planifié ni demande d’achat n’est généré pour l’article.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le type MRP dans la vue MRP 1 est vide ou défini sur ND.

Modules concernés

MM / PP

Transactions

MM02, MD01, MD02, MD04

Diagnostic

  1. Examiner la vue MRP 1 dans MM02.
  2. Déterminer le mode de planification requis selon le besoin métier.

Solution

  1. Renseigner PD ou VB selon ce besoin, ainsi que taille de lot, point de commande et stock de sécurité selon le cas.
  2. Enregistrer et lancer MD01 ou MD02 selon la source.
  3. Examiner MD04 et convertir les ordres planifiés confirmés si nécessaire.

Validation / paramétrage

Vérifier que l’article est pris en compte. La source renvoie à SPRO → PP → MRP → Planification → Définition des types MRP.

Classification

L2: Analyse fonctionnelle et correction coordonnée.
