MM-017 · L2

Material excluded from the MRP run

Problem

After a planning run, no planned orders or requisitions are generated for the material.

Error message / number

Not specified in the source.

Root cause

The MRP type is blank or set to ND in the MRP 1 view.

Affected modules

MM / PP

Transactions

MM02, MD01, MD02, MD04

Diagnosis

  1. Inspect the MRP 1 view in MM02.
  2. Determine the required planning method with reference to the business requirement.

Solution

  1. Maintain PD or VB according to that requirement, with lot size, reorder point and safety stock as applicable.
  2. Save and run MD01 or MD02 as described in the source.
  3. Review the results in MD04 and convert confirmed planned orders if appropriate.

Validation / configuration

Confirm that the material is included in planning. The source references SPRO → PP → MRP → Planning → Define MRP Types.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 14–15, #017. Document-based educational scenario; not independently verified. No production changes without appropriate authorization.
