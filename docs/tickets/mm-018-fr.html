MM-018 · L3

Type d’imputation indisponible dans la commande

Problème

Lors de la création de la commande, l’acheteur ne peut pas sélectionner le type d’imputation requis, par exemple centre de coûts ou projet.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Dans le scénario décrit, le type n’est pas paramétré ou autorisé pour le type de document.

Modules concernés

MM

Transactions

ME21N, OME9

Diagnostic

  1. Identifier le type requis dans ME21N.
  2. Examiner le paramétrage d’imputation dans SPRO ainsi que les réglages OME9 cités par la source.

Solution

  1. Vérifier la disponibilité du type requis, par exemple K ou P.
  2. Si le paramétrage manque, le maintenir selon le document.

Validation / paramétrage

Tester une commande exemple dans ME21N. Cas de paramétrage : SPRO → MM → Achats → Imputation → Types d’imputation.

Classification

L3: Paramétrage ou évolution.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 15, #018. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
