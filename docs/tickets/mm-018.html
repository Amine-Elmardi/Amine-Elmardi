MM-L3-001 · L3

Account assignment category unavailable in purchase order

Problem

The buyer cannot select the required account assignment category, for example cost center or project, during order creation.

Error message / number

Not specified in the source.

Root cause

The category is not configured or allowed for the document type in the documented scenario.

Affected modules

MM

Transactions

ME21N, OME9

Diagnosis

  1. Identify the required category in ME21N.
  2. Check the account assignment configuration in SPRO and the settings in OME9 mentioned by the source.

Solution

  1. Verify that the required category, such as K or P, is available.
  2. If missing, maintain the required configuration as described by the document.

Validation / configuration

Test creation of a sample purchase order in ME21N. This is a configuration case: SPRO → MM → Purchasing → Account Assignment → Maintain Account Assignment Categories.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
