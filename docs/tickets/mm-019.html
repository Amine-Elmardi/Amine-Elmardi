MM-L2-046 · L2

Stock quantity is negative during goods issue

Problem

A goods issue fails in MIGO because the available system quantity is below the quantity requested for issue.

Error message / number

Stock quantity is negative — Message number not specified.

Root cause

The source identifies insufficient recorded stock and the possibility of a missing receipt or a stock inconsistency.

Affected modules

MM / Basis

Transactions

MMBE, MB51, MIGO, MB1C, OMJ1

Diagnosis / requirements

  1. Inspect material, plant and storage location in MMBE
  2. Review material documents in MB51 and determine whether an actual receipt is missing

Solution

  1. Post a missing receipt only if supporting documents establish it
  2. If a system inconsistency remains, refer to Basis as described in the source, which mentions MB1C and 501 as an unverified correction proposal
  3. Do not create stock merely to bypass the error

Validation / configuration

Reconcile stock and verify the intended issue. The document names OMJ1 for negative-stock settings as a separate configuration topic.

Classification

L2: Functional analysis and coordinated correction.
