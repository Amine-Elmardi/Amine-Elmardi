MM-L2-012 · L2

Fully invoiced purchase order cannot be changed

Problem

The buyer wants to change quantity or delivery date but the fully invoiced item does not allow the requested modification.

Error message / number

Not specified in the source.

Root cause

The document attributes the restriction to the invoice quantity having reached the ordered quantity.

Affected modules

MM / FI

Transactions

ME22N, ME23N, MR8M, MIGO (122), MIRO

Diagnosis / requirements

  1. Inspect item status and compare ordered, received and invoiced quantities in ME22N/ME23N
  2. Review posted invoice and receipt with FI

Solution

  1. If a justified correction requires invoice reversal, coordinate MR8M with FI as described
  2. The source also proposes a MIGO movement 122 when a receipt exists, but its applicability and the correction sequence must be confirmed before execution
  3. After approved corrections, change the order in ME22N and post the corrected invoice in MIRO

Validation / configuration

Verify the corrected order and invoice history and document reversal reasons. No SPRO change is described.

Classification

L2: Functional analysis and coordinated correction.
