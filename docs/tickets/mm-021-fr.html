MM-L2-014 · L2

Échec de la réception sur commande de sous-traitance

Problème

L’article élaboré ne peut pas être réceptionné sur une commande de sous-traitance.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Selon la source, les composants de nomenclature doivent être disponibles chez le sous-traitant pour leur consommation.

Modules concernés

MM

Transactions

MIGO, MB1B (541/542/543), ME21N, MMBE, MB52, CS01/CS02

Diagnostic

  1. Vérifier le transfert 541 dans MB1B.
  2. Contrôler les quantités des composants dans MIGO. La source cite aussi CS01/CS02 pour la nomenclature.

Solution

  1. Dans MIGO, sélectionner la réception avec référence à la commande de sous-traitance.
  2. Utiliser le mouvement 101 pour l’article principal selon la source.
  3. Comptabiliser
  4. la source décrit la consommation automatique avec 543.

Validation / paramétrage

Vérifier réception et consommation dans MMBE et le stock spécial dans MB52. Aucun changement SPRO décrit.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
