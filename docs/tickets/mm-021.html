MM-L2-014 · L2

Goods receipt for subcontracting order fails

Problem

The finished material cannot be received against a subcontracting purchase order.

Error message / number

Not specified in the source.

Root cause

The source identifies the requirement that the BOM components be available at the subcontractor for component consumption.

Affected modules

MM

Transactions

MIGO, MB1B (541/542/543), ME21N, MMBE, MB52, CS01/CS02

Diagnosis

  1. Check whether component transfer 541 was posted in MB1B.
  2. Inspect the component quantities in the MIGO component overview. The source also names CS01/CS02 for the subcontracting BOM.

Solution

  1. In MIGO select receipt with the subcontracting PO reference.
  2. Use 101 for the parent material as described.
  3. Post the document
  4. the source describes automatic component consumption with 543.

Validation / configuration

Verify receipt and consumption in MMBE and check subcontractor special stock in MB52. No SPRO change is described.

Classification

L2: Functional analysis and coordinated correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
