MM-L2-008 · L2

Affectation client et domaine commercial perturbant la sous-traitance

Problème

Un processus de sous-traitance intersociétés échoue en raison de données client ou domaine commercial incorrectes chez le fournisseur.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit un lien client-fournisseur ou une affectation commerciale incohérente.

Modules concernés

MM / SD

Transactions

XK02, XK03, VD03, ME21N, MIGO, OB56, VKOA

Diagnostic / besoins

  1. Examiner le client lié dans XK03
  2. Afficher le client dans VD03 et vérifier organisation commerciale, canal et secteur
  3. Examiner OB56 et VKOA cités avec l’équipe d’intégration

Solution

  1. Si le numéro client est incorrect, corriger la fiche fournisseur dans XK02
  2. Reprendre le cycle complet après correction approuvée

Validation / paramétrage

Vérifier le lien attendu et le bon déroulement. La source renvoie au paramétrage intersociétés sans imposer sa modification.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
