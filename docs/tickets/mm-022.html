MM-022 · L2

Customer and sales-area assignment disrupts subcontracting

Problem

An intercompany subcontracting process fails because the vendor is linked to incorrect customer or sales-area data.

Error message / number

Not specified in the source.

Root cause

The source describes an inconsistent customer-vendor link or sales organization assignment.

Affected modules

MM / SD

Transactions

XK02, XK03, VD03, ME21N, MIGO, OB56, VKOA

Diagnosis / requirements

  1. Inspect the customer reference in XK03
  2. Display the linked customer in VD03 and verify sales organization, distribution channel and division
  3. Review the source references OB56 and VKOA with the responsible integration team

Solution

  1. If the vendor customer number is incorrect, correct the master record in XK02
  2. Repeat the subcontracting process end to end after approved correction

Validation / configuration

Confirm the intended supplier-customer link and successful processing. The source refers to intercompany assignment configuration, not a mandatory change.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 17, #022. Document-based educational scenario; not independently verified. Production changes require authorization.
