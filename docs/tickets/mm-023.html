MM-L2-033 · L2

No source of supply found

Problem

Automatic source determination fails during purchasing or conversion of an MRP-generated purchase requisition. The source records the message: No source of supply found.

Error message / number

No source of supply found — Message number not specified.

Root cause

The source list is missing for the material and plant, while the material master requires a source list.

Affected modules

MM – Purchasing / Material master

Transactions

ME01, ME03, ME04, ME57, ME59, MM03

Diagnosis

Open MM03, Purchasing view, and verify whether the source list requirement is active. Identify the material and plant concerned.

Solution

Create the source list in ME01 for the material and plant. Enter the vendor, purchasing organization and validity dates; set a fixed source if needed. Save and rerun source assignment in ME57 or automatic PO creation in ME59.

Validation / configuration

Check source-list changes in ME04. The document also references the plant-level source list requirement in OME5 (SPRO).

Classification

L2: functional source-determination analysis and master data maintenance.
