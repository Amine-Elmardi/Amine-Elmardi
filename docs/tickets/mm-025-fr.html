MM-L2-032 · L2

Prix moyen mobile différent de la valorisation attendue

Problème

Après réceptions et factures, le prix moyen mobile de l’article s’écarte fortement de la valeur attendue.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source évoque des prix variables ou des écarts mal traités dans le Material Ledger.

Modules concernés

MM / CO / FI

Transactions

MR21, MB51, MIR4, CKMLCR, CKMLCP

Diagnostic / besoins

  1. Examiner le prix via l’approche MR21 ou CKMLCR citée
  2. Contrôler réceptions MB51 et factures MIR4
  3. Déterminer si une saisie de prix ou quantité erronée explique l’écart

Solution

  1. Pour une erreur confirmée, le document propose une correction approuvée via MR21
  2. Si Material Ledger est actif, coordonner le calcul réel CKMLCP décrit avec l’équipe responsable
  3. Documenter la cause et obtenir l’accord métier avant modification du prix

Validation / paramétrage

Examiner la valorisation avec FI et CO. La source renvoie au paramétrage du calcul réel dans SPRO.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
