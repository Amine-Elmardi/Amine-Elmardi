MM-L2-032 · L2

Moving average price differs from expected valuation

Problem

Following goods receipts and invoice postings, the material moving average price deviates substantially from the expected value.

Error message / number

Not specified in the source.

Root cause

The source describes fluctuating receipt and invoice prices or improperly processed variances in the material ledger.

Affected modules

MM / CO / FI

Transactions

MR21, MB51, MIR4, CKMLCR, CKMLCP

Diagnosis / requirements

  1. Review the price information using the cited MR21 or CKMLCR approach
  2. Examine receipts in MB51 and invoices in MIR4
  3. Determine whether incorrect price or quantity entries explain the deviation

Solution

  1. For a confirmed pricing entry error, the document proposes an approved price correction in MR21
  2. Where material ledger is active, coordinate the documented CKMLCP actual costing process with the responsible team
  3. Document the cause and obtain business sign-off before price changes

Validation / configuration

Review resulting valuation with FI and CO. The document refers to actual costing configuration in SPRO.

Classification

L2: Functional analysis and coordinated correction.
