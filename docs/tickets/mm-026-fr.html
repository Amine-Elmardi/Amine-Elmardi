MM-L2-044 · L2

Le deuxième approbateur ne peut pas valider la commande

Problème

La première validation a eu lieu, mais le second approbateur reçoit le message cité Release already performed.

Message / numéro d’erreur

Release already performed — Numéro de message non indiqué.

Cause racine

La source évoque des codes en conflit ou une stratégie non paramétrée pour plusieurs niveaux.

Modules concernés

MM

Transactions

ME28, ME29N, ME23N, OMGS, OOCU, SU01

Diagnostic

  1. Examiner le statut dans ME28 ou ME29N.
  2. Vérifier les codes nécessaires dans OMGS.

Solution

  1. Si l’affectation erronée est confirmée, la source décrit l’annulation de la validation dans ME28 lorsque permise.
  2. Faire corriger les affectations par l’équipe responsable via OOCU ou SU01 selon le document.
  3. Reprendre les validations dans l’ordre prévu.

Validation / paramétrage

Contrôler le statut final d’en-tête dans ME23N. La modification de la stratégie relève d’un paramétrage distinct.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
