MM-026 · L2

Second approver cannot release the purchase order

Problem

The first release has occurred but a second approver receives the reported message Release already performed.

Error message / number

Release already performed — Message number not specified.

Root cause

The source points to conflicting release codes or a strategy not configured for multiple approval levels.

Affected modules

MM

Transactions

ME28, ME29N, ME23N, OMGS, OOCU, SU01

Diagnosis

  1. Inspect the status in ME28 or ME29N.
  2. Review the required release codes in OMGS.

Solution

  1. If incorrect assignment is confirmed, the source describes resetting the release in ME28 where permitted.
  2. Have the responsible team correct code assignments using the documented OOCU or SU01 route.
  3. Perform releases in the required sequence.

Validation / configuration

Verify the final header status in ME23N. Changes to the strategy itself are a separate configuration matter.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 19, #026. Document-based educational scenario; not independently verified. No production changes without appropriate authorization.
