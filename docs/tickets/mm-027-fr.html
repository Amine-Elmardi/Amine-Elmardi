MM-L2-034 · L2

Impossible de comptabiliser les écarts d’inventaire

Problème

Après le comptage, la comptabilisation des écarts échoue pour une raison de période ou d’autorisation.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source distingue une période MM fermée ou une autorisation manquante pour le mouvement 701.

Modules concernés

MM / Basis

Transactions

MI01, MI04, MI07, MI03, MMRV, MMPV, MB51, SU53

Diagnostic

  1. Contrôler la période dans MMRV.
  2. Après l’erreur, examiner SU53 pour MI07 et le mouvement 701.

Solution

  1. Si la période est fermée, la source renvoie à son ouverture dans MMPV par l’équipe responsable.
  2. Si l’autorisation manque, demander une correction du rôle à Basis.
  3. Reprendre l’inventaire selon la séquence MI01, MI04 et MI07 décrite, selon le cas.

Validation / paramétrage

Contrôler le statut dans MI03 et les mouvements 701/702 dans MB51. La source cite OMSY pour les périodes.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
