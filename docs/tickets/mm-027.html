MM-L2-034 · L2

Physical inventory differences cannot be posted

Problem

After inventory counting, the difference posting fails because of a posting-period or authorization problem.

Error message / number

Not specified in the source.

Root cause

The source identifies two branches: a closed MM posting period or missing authorization for movement 701.

Affected modules

MM / Basis

Transactions

MI01, MI04, MI07, MI03, MMRV, MMPV, MB51, SU53

Diagnosis

  1. Check the period using MMRV.
  2. After the error, inspect SU53 for MI07 and movement 701 authorization.

Solution

  1. If the period is closed, the source refers to opening it through MMPV by the responsible team.
  2. If authorization is missing, request a role correction from Basis.
  3. Reprocess the inventory via the documented MI01, MI04 and MI07 sequence as applicable.

Validation / configuration

Check the document status in MI03 and movements 701/702 in MB51. The source references OMSY for posting-period configuration.

Classification

L2: Functional analysis and coordinated correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
