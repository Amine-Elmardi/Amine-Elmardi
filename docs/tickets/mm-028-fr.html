MM-L2-007 · L2

Valeur cible du contrat d’achat épuisée

Problème

Le service achats ne peut plus créer de commande sur un contrat existant, car sa valeur cible est épuisée.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source indique que la valeur déjà commandée a atteint la limite disponible du contrat.

Modules concernés

MM – Achats / Contrats

Transactions

ME33K, ME32K, ME21N, ME3M, ME2K

Diagnostic

  1. Afficher le contrat dans ME33K.
  2. Comparer la valeur cible à la valeur déjà commandée.
  3. Demander au service achats si une augmentation est autorisée.

Solution

  1. Après approbation, modifier la valeur cible dans ME32K.
  2. Comme alternative, la source propose de créer un nouveau contrat ou poste de contrat.
  3. Créer la commande dans ME21N en référence au contrat actualisé.

Validation / paramétrage

Suivre l’utilisation du contrat dans ME3M ou ME2K. L’action documentée concerne les données contractuelles, sans paramétrage SPRO.

Classification

L2 : analyse de l’utilisation du contrat et correction approuvée du document d’achat.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
