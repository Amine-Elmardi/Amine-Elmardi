MM-L2-007 · L2

Contract target value exhausted

Problem

A buyer cannot create another release order referencing an existing purchasing contract because its target value has been consumed.

Error message / number

Not specified in the source.

Root cause

The source identifies an exhausted contract target value; the amount already ordered has reached the available limit.

Affected modules

MM – Purchasing / Contracts

Transactions

ME33K, ME32K, ME21N, ME3M, ME2K

Diagnosis

  1. Display the contract in ME33K.
  2. Compare the target value with the value already ordered.
  3. Ask the procurement team whether an increase is permitted.

Solution

  1. If approved, update the target value in ME32K.
  2. Alternatively, the source describes creating a new contract or contract item.
  3. Create the release order in ME21N with reference to the updated contract.

Validation / configuration

Monitor contract utilization using ME3M or ME2K. The documented action concerns contract data, not SPRO configuration.

Classification

L2: contract utilization analysis and an approved purchasing document correction.
