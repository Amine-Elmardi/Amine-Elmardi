MM-L3-036 · L3

Ordre de transfert non généré après réception

Problème

La réception est comptabilisée dans MIGO mais l’ordre automatique de mise en stock manque.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source cite une création automatique inactive pour le mouvement WM ou une affectation de magasin manquante.

Modules concernés

MM / WM

Transactions

LT0A, LT12, LS26, MIGO, OMLP

Diagnostic / besoins

  1. Vérifier affectation division et magasin dans OMLP
  2. Examiner stock WM dans LS26
  3. Contrôler l’indicateur de création automatique dans les mouvements WM décrits

Solution

  1. Si le paramétrage est incomplet, faire corriger l’indicateur après approbation
  2. Pour la réception individuelle, la source décrit LT0A avec référence au besoin de transfert
  3. Confirmer le transfert réalisé dans LT12

Validation / paramétrage

Contrôler le stock cible dans LS26 et tester la création automatique. L3 en raison du paramétrage.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
