MM-L3-036 · L3

Warehouse transfer order not generated after goods receipt

Problem

A receipt is posted in MIGO but the automatic transfer order for warehouse putaway is absent.

Error message / number

Not specified in the source.

Root cause

The source identifies missing automatic transfer-order activation for the WM movement type or a missing warehouse assignment.

Affected modules

MM / WM

Transactions

LT0A, LT12, LS26, MIGO, OMLP

Diagnosis / requirements

  1. Check plant and storage-location assignment in OMLP
  2. Inspect warehouse stock using LS26
  3. Review the automatic transfer order indicator in the documented WM movement-type settings

Solution

  1. If configuration is incomplete, arrange the approved correction of the automatic creation flag
  2. For the individual receipt, the source describes creating a transfer order via LT0A with transfer requirement reference
  3. Confirm the completed transfer in LT12

Validation / configuration

Verify target stock in LS26 and test automatic creation. L3 reflects the configuration branch.

Classification

L3: Configuration or enhancement.
