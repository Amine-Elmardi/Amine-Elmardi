MM-030 · L2

La répartition des quotas sélectionne un fournisseur inattendu

Problème

Malgré une répartition maintenue, la détermination de source choisit un fournisseur différent de celui attendu.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source indique une validité expirée ou une allocation nulle pour certains fournisseurs.

Modules concernés

MM

Transactions

MEQ1, MEQ3, ME57, ME21N

Diagnostic

  1. Examiner la répartition article/division dans MEQ1.
  2. Vérifier les dates de validité et les quotas attribués.

Solution

  1. Actualiser les dates expirées si nécessaire.
  2. Maintenir les valeurs prévues et enregistrer.
  3. Relancer l’affectation dans ME57 ou la conversion de demande décrite.

Validation / paramétrage

Contrôler le fournisseur sélectionné dans ME21N. La source renvoie aux réglages de répartition dans SPRO.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 21, #030. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
