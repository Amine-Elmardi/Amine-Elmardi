MM-030 · L2

Quota arrangement selects an unexpected supplier

Problem

Source determination chooses a different supplier from the one expected by the buyer despite a maintained quota arrangement.

Error message / number

Not specified in the source.

Root cause

The source describes expired validity dates or a zero allocation for certain suppliers.

Affected modules

MM

Transactions

MEQ1, MEQ3, ME57, ME21N

Diagnosis

  1. Inspect the material and plant quota arrangement in MEQ1.
  2. Check validity dates and the allocation values for the suppliers.

Solution

  1. Update expired dates if necessary.
  2. Maintain the intended quota values and save.
  3. Repeat source assignment in ME57 or the referenced requisition conversion.

Validation / configuration

Check the selected supplier in ME21N. The source references quota arrangement settings in SPRO.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 21, #030. Document-based educational scenario; not independently verified. No production changes without appropriate authorization.
