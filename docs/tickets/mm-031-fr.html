MM-031 · L2

Le compte EM/EF conserve des postes ouverts

Problème

Les entrées de marchandises et de factures sont comptabilisées, mais des postes restent ouverts sur le compte de rapprochement.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source évoque un écart de quantité ou une référence de commande ou de poste incorrecte dans FI.

Modules concernés

MM / FI

Transactions

MR11, MR8M, FS10N, FAGLL03, MIR4

Diagnostic

  1. Examiner les postes dans FS10N ou FAGLL03.
  2. Sélectionner la commande dans MR11 et identifier les postes concernés.
  3. Vérifier la référence de facture et l’écart de quantité.

Solution

  1. Si la référence erronée est confirmée, la source décrit l’annulation dans MR8M et la nouvelle comptabilisation.
  2. Relancer MR11 après correction.
  3. Pour les cas récurrents, le document propose un traitement MR11 de fin de mois.

Validation / paramétrage

Examiner les postes restants. La source cite OBYC et la clé WRX pour l’affectation du compte.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 22, #031. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
