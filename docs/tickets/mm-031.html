MM-031 · L2

GR/IR clearing account retains open items

Problem

Goods receipt and invoice receipt are posted, yet open items remain on the clearing account.

Error message / number

Not specified in the source.

Root cause

The source identifies a discrepancy in quantities or an incorrect purchase order or item reference in the FI posting.

Affected modules

MM / FI

Transactions

MR11, MR8M, FS10N, FAGLL03, MIR4

Diagnosis

  1. Review open items using FS10N or FAGLL03.
  2. In MR11 select the order and identify the affected line items.
  3. Check the invoice reference and quantity difference.

Solution

  1. For a confirmed wrong invoice reference, the source describes cancellation with MR8M and reposting.
  2. After correction rerun MR11.
  3. For recurring cases the document suggests scheduling MR11 at month-end.

Validation / configuration

Review remaining items. OBYC transaction key WRX is the account-assignment reference in the source.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 22, #031. Document-based educational scenario; not independently verified. No production changes without appropriate authorization.
