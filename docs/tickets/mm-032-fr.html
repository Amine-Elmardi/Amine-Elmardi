MM-L2-027 · L2

Article non approvisionnable

Problème

Une commande ne peut pas être créée pour un article existant dans la division cible.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La vue Achats manque ou le statut article est restrictif.

Modules concernés

MM

Transactions

MM01, MM02, MM03, ME21N

Diagnostic / besoins

  1. Afficher article et division dans MM03
  2. Vérifier la vue Achats, le blocage et le statut inter-divisions

Solution

  1. Étendre la vue manquante avec MM01
  2. Si le statut empêche l’achat, le corriger dans MM02 uniquement si le métier autorise l’achat

Validation / paramétrage

Tester une nouvelle commande dans ME21N. La source renvoie au paramétrage des statuts dans SPRO.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
