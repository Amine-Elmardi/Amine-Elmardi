MM-032 · L2

Material cannot be procured

Problem

A purchase order cannot be created for an existing material at the intended plant.

Error message / number

Not specified in the source.

Root cause

The purchasing view is missing or a restrictive material status is active.

Affected modules

MM

Transactions

MM01, MM02, MM03, ME21N

Diagnosis / requirements

  1. Display material and plant in MM03
  2. Check the purchasing view, purchasing block and cross-plant status

Solution

  1. Extend the missing view with MM01
  2. If the material status prevents procurement, correct it in MM02 only when procurement is permitted

Validation / configuration

Test a new PO in ME21N. The source references material status settings in SPRO.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 22, #032. Document-based educational scenario; not independently verified. Production changes require appropriate authorization.
