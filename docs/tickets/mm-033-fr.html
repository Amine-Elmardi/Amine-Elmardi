MM-L3-027 · L3

Livraison sortante absente pour une commande de transfert

Problème

Une commande de transfert entre divisions ne peut pas se poursuivre sans livraison sortante.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source cite un paramétrage incomplet ou des données de point d’expédition et d’itinéraire manquantes.

Modules concernés

MM / Logistics

Transactions

ME21N, ME23N, VL10B, OMGN, OVXC

Diagnostic / besoins

  1. Vérifier les données dans ME23N
  2. Tenter la création dans VL10B
  3. En cas d’échec examiner OMGN et OVXC

Solution

  1. Corriger les affectations ou données d’itinéraire manquantes selon le document
  2. Relancer VL10B

Validation / paramétrage

Contrôler la livraison. La source renvoie au paramétrage des commandes de transfert dans SPRO.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
