MM-L3-027 · L3

Outbound delivery missing for stock transport order

Problem

An existing inter-plant transport order cannot proceed because no outbound delivery is generated.

Error message / number

Not specified in the source.

Root cause

The source identifies incomplete STO delivery settings or missing shipping point and route data.

Affected modules

MM / Logistics

Transactions

ME21N, ME23N, VL10B, OMGN, OVXC

Diagnosis / requirements

  1. Check shipping data in ME23N
  2. Attempt delivery creation with VL10B
  3. If it fails, examine plant shipping settings in OMGN and assignment in OVXC

Solution

  1. Correct the missing shipping point assignment or route master data according to the documented scenario
  2. Retry VL10B

Validation / configuration

Confirm delivery creation. The source locates the settings under Set Up Stock Transfer Orders in SPRO.

Classification

L3: Configuration or enhancement.
