MM-L2-036 · L2

Le prix net reste nul après mise à jour de la fiche info-achats

Problème

Le prix actuel a été renseigné dans la fiche, mais une nouvelle commande affiche toujours un prix net nul.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le schéma de calcul ou le type de condition ne correspond pas à la combinaison fournisseur/organisation d’achats selon la source.

Modules concernés

MM

Transactions

ME13, ME21N, XK02

Diagnostic

  1. Examiner le prix et le type de condition dans ME13, par exemple PB00.
  2. Consulter les conditions du poste et le schéma dans ME21N.
  3. Vérifier dans le paramétrage de prix SPRO que la condition figure dans le schéma.

Solution

  1. Si l’affectation du schéma fournisseur est incorrecte, corriger les données d’organisation d’achats dans XK02 selon la source.
  2. Recréer la commande et examiner la détermination du prix.

Validation / paramétrage

Contrôler la reprise du prix attendu. La source renvoie au paramétrage du schéma, mais décrit la correction de l’affectation fournisseur.

Classification

L2: Analyse fonctionnelle et correction coordonnée.
