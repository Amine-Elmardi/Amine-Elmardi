MM-034 · L2

Purchase order net price remains zero after info record update

Problem

The latest price has been maintained in the info record but a newly created purchase order still displays zero net price.

Error message / number

Not specified in the source.

Root cause

The calculation schema or condition type does not correspond to the vendor and purchasing organization combination described in the source.

Affected modules

MM

Transactions

ME13, ME21N, XK02

Diagnosis

  1. In ME13 inspect price and condition type, for example PB00.
  2. In ME21N review the item conditions and schema.
  3. Check whether the condition belongs to the calculation schema in the SPRO pricing area.

Solution

  1. If the vendor schema assignment is incorrect, correct the purchasing organization data in XK02 as documented.
  2. Create the purchase order again and inspect pricing.

Validation / configuration

Verify the expected price is retrieved. The source references pricing schema configuration but the documented correction is the vendor schema assignment.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 23, #034. Document-based educational scenario; not independently verified. No production changes without appropriate authorization.
