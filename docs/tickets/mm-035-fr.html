MM-L2-013 · L2

Sortie de marchandises sur réservation impossible

Problème

Une réservation existe, mais le magasin ne peut pas comptabiliser la sortie correspondante dans MIGO.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La date de besoin peut être expirée, la réservation entièrement prélevée ou la référence incorrecte.

Modules concernés

MM

Transactions

MB21, MB22, MB23, MIGO (201), MMBE

Diagnostic

  1. Afficher la réservation dans MB23 et contrôler quantité ouverte et date de besoin.
  2. Vérifier la référence et le mouvement indiqué dans le document.

Solution

  1. Dans MIGO choisir la sortie avec référence à la réservation.
  2. Si nécessaire, faire prolonger la date comme décrit dans la source.
  3. Si tout a été prélevé, informer le demandeur qu’une nouvelle réservation est nécessaire.
  4. La source utilise le mouvement 201 comme exemple.

Validation / paramétrage

Après sortie, contrôler la diminution du stock dans MMBE. Aucun changement SPRO prévu.

Classification
