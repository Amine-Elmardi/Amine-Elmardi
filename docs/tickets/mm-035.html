MM-L2-013 · L2

Goods issue against reservation is not possible

Problem

A reservation exists, but warehouse staff cannot post the corresponding goods issue in MIGO.

Error message / number

Not specified in the source.

Root cause

The reservation may have an expired requirement date, be fully withdrawn, or be referenced incorrectly.

Affected modules

MM

Transactions

MB21, MB22, MB23, MIGO (201), MMBE

Diagnosis

  1. Display the reservation in MB23 and inspect open quantity and requirement date.
  2. Check the reservation reference and movement type described in the source.

Solution

  1. Use Goods Issue with Reservation reference in MIGO.
  2. If needed, arrange the date extension described in the source.
  3. If fully withdrawn, inform the requester that a new reservation is needed.
  4. The source uses movement 201 in its example.

Validation / configuration

After the goods issue, verify the stock decrease in MMBE. No SPRO change is prescribed.

Classification

L2: Functional analysis and coordinated correction.
