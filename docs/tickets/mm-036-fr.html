MM-036 · L2

Les appels du programme de livraisons ne sont pas transmis

Problème

Les appels prévisionnels ou JIT ne sont pas générés ou envoyés malgré un programme existant.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source indique une création d’appels ou une détermination des messages incomplète.

Modules concernés

MM

Transactions

ME33L, ME38, ME84, MN07, ME9L

Diagnostic / besoins

  1. Examiner la documentation dans ME33L
  2. Générer un appel dans ME84 et consulter ME9L ou ME38
  3. Distinguer appel absent et sortie absente

Solution

  1. Maintenir la condition manquante dans MN07 pour le type prévu, par exemple LPET
  2. Affecter le fournisseur comme partenaire
  3. Relancer via ME84

Validation / paramétrage

Contrôler ME38. La source cite le profil de création des appels dans SPRO.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 24, #036. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
