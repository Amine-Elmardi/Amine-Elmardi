MM-L2-043 · L2

Scheduling agreement releases are not transmitted

Problem

Forecast or JIT schedules are not generated or sent despite an existing agreement.

Error message / number

Not specified in the source.

Root cause

The source identifies missing release setup or output determination.

Affected modules

MM

Transactions

ME33L, ME38, ME84, MN07, ME9L

Diagnosis / requirements

  1. Inspect release documentation in ME33L
  2. Generate a release in ME84 and inspect ME9L or ME38
  3. Distinguish a missing release from missing output

Solution

  1. Maintain the missing output condition in MN07 for the intended type such as LPET
  2. Assign the supplier as partner
  3. Retransmit using ME84

Validation / configuration

Confirm in ME38. The source references the release creation profile in SPRO.

Classification

L2: Functional analysis and coordinated correction.
