MM-L2-010 · L2

La facture ERS n’est pas générée

Problème

Après réception, le document de facture automatique attendu n’est pas généré pour un fournisseur ERS.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Selon la source, l’indicateur ERS manque dans le poste ou la fiche fournisseur.

Modules concernés

MM

Transactions

XK03, XK02, ME22N, MRRL, MIR5, MIR4, MIRO

Diagnostic

  1. Examiner le réglage de décompte automatique dans les données achats via XK03.
  2. Contrôler l’indicateur ERS dans l’onglet Facture de ME22N.

Solution

  1. Maintenir les indicateurs nécessaires selon la source.
  2. Exécuter MRRL avec la sélection de commande, fournisseur ou division concernée.
  3. Si l’échec persiste, la source conseille d’examiner les réglages MIRO et les codes de taxe.

Validation / paramétrage

Suivre les documents générés dans MIR5. Les réglages décrits concernent la fiche fournisseur et le poste.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
