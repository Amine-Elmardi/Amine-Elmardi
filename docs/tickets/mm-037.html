MM-037 · L2

Evaluated receipt settlement invoice is not generated

Problem

An ERS-enabled supplier does not receive the expected automatic invoice document after goods receipt.

Error message / number

Not specified in the source.

Root cause

The source identifies a missing ERS indicator in the purchase order item or supplier master.

Affected modules

MM

Transactions

XK03, XK02, ME22N, MRRL, MIR5, MIR4, MIRO

Diagnosis

  1. Inspect the automatic evaluated receipt settlement setting in the vendor purchasing data using XK03.
  2. Check the ERS indicator in the invoice tab of ME22N.

Solution

  1. Ensure the required indicators are maintained as described by the source.
  2. Run MRRL with the affected order, supplier or plant selection.
  3. If still unsuccessful, the source recommends inspecting MIRO settings and tax codes.

Validation / configuration

Monitor generated invoice documents in MIR5. The documented settings concern vendor master and order item.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 25, #037. Document-based educational scenario; not independently verified. No production changes without appropriate authorization.
