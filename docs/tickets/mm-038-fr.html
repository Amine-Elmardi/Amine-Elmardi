MM-L2-051 · L2

Retour fournisseur mal reflété dans les rapports

Problème

Les marchandises ont été retournées mais les achats ne retrouvent pas la référence attendue dans les rapports.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document évoque une référence de commande initiale manquante ou un processus de commande de retour distinct.

Modules concernés

MM / FI

Transactions

MIGO (122), ME21N, VL02N, MB51, MMBE, ME23N

Diagnostic / besoins

  1. Examiner commande initiale et mouvements dans ME23N et MB51
  2. Clarifier si le processus utilise un retour direct ou une commande de retour

Solution

  1. Pour le retour direct, la source décrit MIGO avec référence initiale et mouvement 122
  2. Pour la commande de retour, elle décrit l’indicateur ME21N et la livraison via VL02N
  3. Coordonner la demande d’avoir ou de débit correspondante

Validation / paramétrage

Contrôler historique et stock dans ME23N et MMBE. La source cite le paramétrage des postes de retour. Ne pas doubler un retour déjà comptabilisé.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
