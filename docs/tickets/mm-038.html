MM-038 · L2

Supplier return does not appear correctly in tracking reports

Problem

Goods have been returned but the buyer cannot see the intended return reference in reporting.

Error message / number

Not specified in the source.

Root cause

The document attributes the tracking issue to missing original purchase order reference or the need for a dedicated returns-order process.

Affected modules

MM / FI

Transactions

MIGO (122), ME21N, VL02N, MB51, MMBE, ME23N

Diagnosis / requirements

  1. Inspect the original order and movement history in ME23N and MB51
  2. Clarify whether the organization uses a direct return or separate returns order

Solution

  1. For a direct return, the source describes MIGO return delivery with original PO reference and movement 122
  2. For the separate returns-order method it describes the returns indicator in ME21N and outbound processing in VL02N
  3. Coordinate the corresponding credit or debit memo request

Validation / configuration

Verify return history and stock in ME23N and MMBE. The document references returns-item configuration. Do not duplicate an already posted return.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 25, #038. Document-based educational scenario; not independently verified. Production changes require authorization.
