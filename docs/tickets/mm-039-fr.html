MM-L2-004 · L2

Modifier le type article de ROH à HALB

Problème

Un changement de processus nécessite de transformer la classification d’une matière première existante en produit semi-fini.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source évoque une classification initiale erronée ou une évolution de fabrication.

Modules concernés

MM

Transactions

MMAM, MM02, MM03, MI10

Diagnostic / besoins

  1. Confirmer type cible et justification métier
  2. Vérifier les prérequis documentés : absence de stock et commandes ouvertes, EM/EF soldé
  3. Examiner les incohérences avant modification

Solution

  1. Utiliser MMAM avec cible HALB uniquement après confirmation des prérequis
  2. Résoudre les incohérences avec l’équipe responsable, MI10 étant cité comme référence de correction de stock non vérifiée
  3. Sinon créer un nouvel article du bon type et retirer l’ancien

Validation / paramétrage

Contrôler le type résultant. La source renvoie aux attributs des types article dans SPRO. Ne pas ajuster le stock uniquement pour permettre la modification.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
