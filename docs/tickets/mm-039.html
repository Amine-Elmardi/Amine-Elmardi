MM-039 · L2

Change material type from raw material to semi-finished product

Problem

A business process change requires an existing ROH material to become HALB.

Error message / number

Not specified in the source.

Root cause

The source attributes the request to an original classification error or a changed manufacturing process.

Affected modules

MM

Transactions

MMAM, MM02, MM03, MI10

Diagnosis / requirements

  1. Confirm the target material type and business justification
  2. Check the documented prerequisites of no stock, no open orders and cleared GR/IR
  3. Review possible inconsistencies before a change

Solution

  1. Use MMAM with target HALB only after the prerequisites are confirmed
  2. If inconsistencies exist, resolve the underlying items through the responsible team, with MI10 named in the source as an unverified stock-correction reference
  3. Alternatively create a new material with the correct type and retire the old one

Validation / configuration

Verify the resulting type in the material master. The source refers to material-type attributes in SPRO. No stock adjustment solely to enable a type change.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 26, #039. Document-based educational scenario; not independently verified. Production changes require authorization.
