MM-040 · L2

Échec de la création automatique de commandes

Problème

ME59N ne convertit pas les demandes malgré les sources existantes.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document cite des indicateurs automatiques manquants, des restrictions fournisseur ou des postes incomplets.

Modules concernés

MM

Transactions

ME51N, ME52N, ME13, ME59N, XK03

Diagnostic / besoins

  1. Examiner les indicateurs cités dans ME51N/ME52N et ME13
  2. Contrôler les blocages dans XK03
  3. Exécuter ME59N avec la sélection pertinente et consulter le journal

Solution

  1. Corriger l’anomalie identifiée, par exemple l’imputation manquante
  2. Relancer ME59N pour les postes corrigés

Validation / paramétrage

Vérifier la conversion. La source cite OME0 pour les paramètres automatiques.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 26, #040. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
