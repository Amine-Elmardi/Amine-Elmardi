MM-L2-001 · L2

Automatic purchase order creation fails

Problem

ME59N does not convert requisitions into orders despite existing source records.

Error message / number

Not specified in the source.

Root cause

The document names missing automatic-order indicators, supplier restrictions or incomplete item data.

Affected modules

MM

Transactions

ME51N, ME52N, ME13, ME59N, XK03

Diagnosis / requirements

  1. Inspect the indicators mentioned in ME51N/ME52N and ME13
  2. Check supplier restrictions in XK03
  3. Run ME59N for the relevant selection and read the log

Solution

  1. Correct the identified issue such as missing account assignment
  2. Repeat ME59N for the corrected items

Validation / configuration

Verify that the intended requisitions are converted. The source references OME0 for automatic PO parameters.

Classification

L2: Functional analysis and coordinated correction.
