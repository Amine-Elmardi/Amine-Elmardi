MM-L3-009 · L3

Le certificat d’analyse nécessite des champs supplémentaires

Problème

L’assurance qualité demande d’ajouter des champs à un formulaire spécifique de certificat d’analyse.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Un changement de processus exige des résultats ou des données fournisseur absents du modèle actuel.

Modules concernés

MM / QA / ABAP

Transactions

SE71, Smartforms, WE20, WE21, WE60, WE57

Diagnostic

  1. Recueillir les besoins exacts avec la qualité.
  2. Identifier les sources citées : fiches article, lot, fournisseur ou tables spécifiques.

Solution

  1. Coordonner l’évolution avec ABAP via SE71 ou Smartforms selon le cas.
  2. Ajouter colonnes ou fenêtres de texte et relier les champs au programme ou module de fonction.
  3. En cas d’envoi IDoc, examiner les réglages WE20 et WE21.

Validation / paramétrage

Tester en développement, obtenir la validation qualité et transporter. Le document cite WE57 et les profils partenaires.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
