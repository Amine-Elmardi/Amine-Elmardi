MM-041 · L3

Certificate of analysis requires additional form fields

Problem

Quality staff request additional fields on an existing custom certificate of analysis form.

Error message / number

Not specified in the source.

Root cause

A changed process requires further test results or supplier data that the current template does not contain.

Affected modules

MM / QA / ABAP

Transactions

SE71, Smartforms, WE20, WE21, WE60, WE57

Diagnosis

  1. Collect the exact field requirements with QA.
  2. Identify the documented possible data sources: material, batch, supplier or custom tables.

Solution

  1. Coordinate form changes with ABAP using SE71 or Smartforms as appropriate.
  2. Extend the form with columns or text windows and connect the data to the program or function module.
  3. If the certificate is transmitted through IDoc, review the related settings in WE20 and WE21.

Validation / configuration

Test in development, obtain QA approval and transport to production. The document mentions WE57 and partner profiles.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 27, #041. Document-based educational scenario; not independently verified. No production changes without appropriate authorization.
