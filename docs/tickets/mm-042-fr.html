MM-042 · L3

Ajouter les délais fournisseur à la comparaison des offres

Problème

Les acheteurs souhaitent comparer les délais en plus des prix lors du choix des fournisseurs.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit ME49 comme ne présentant pas les données de délai souhaitées.

Modules concernés

MM / ABAP

Transactions

ME49, ME41, ME47, ME48, SE38, SE18, SE19

Diagnostic / besoins

  1. Définir les champs de délai et leur origine, offre ou fiche info-achats
  2. Examiner la comparaison existante et les besoins d’évolution

Solution

  1. Le document propose un exit ou le BAdI MM_QUOTATION_MD cité via SE18/SE19
  2. Sinon développer un rapport ALV dans SE38 avec EKPO, EKET et EINE cités
  3. Ajouter la comparaison de dates et le classement convenus

Validation / paramétrage

Tester en QA, obtenir la recette, transporter et former les acheteurs. L’extension citée n’est pas vérifiée indépendamment.

Classification

L3: Paramétrage ou évolution.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 27–28, #042. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
