MM-L3-021 · L3

Include supplier lead time in quotation comparison

Problem

Buyers want to compare delivery lead times in addition to prices when selecting suppliers in the RFQ process.

Error message / number

Not specified in the source.

Root cause

The source describes the existing ME49 comparison as not displaying the desired lead-time data.

Affected modules

MM / ABAP

Transactions

ME49, ME41, ME47, ME48, SE38, SE18, SE19

Diagnosis / requirements

  1. Define the required lead-time fields and whether values originate from quotations or info records
  2. Review the existing comparison output and enhancement requirements

Solution

  1. The document proposes an exit or the named MM_QUOTATION_MD BAdI via SE18/SE19
  2. Alternatively develop an ALV report in SE38 using EKPO, EKET and EINE as source references
  3. Add the agreed delivery comparison and ranking logic

Validation / configuration

Test in QA, obtain user acceptance, transport and train buyers. The named enhancement is not independently verified.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
