MM-L3-016 · L3

Orderbuchpflicht auf Werksebene einführen

Problem

In ausgewählten Werken sollen Bestellungen ohne gültiges Orderbuch abgelehnt werden. Es handelt sich um eine neue Prozessanforderung.

Fehlermeldung / Nummer

In der Quelle nicht angegeben.

Ursache

Zur Durchsetzung der Lieferantenstrategie muss die Orderbuchpflicht auf Werksebene aktiviert werden.

Betroffene Module

MM

Transaktionen

OME5, ME01, ME21N

Analyse / Anforderungen

  1. Betroffene Werke bestimmen
  2. Einstellungen in OME5 und vorhandene Orderbücher prüfen

Lösung

  1. Werkskennzeichen in OME5 gemäß Anforderung aktivieren
  2. Orderbücher in ME01 pflegen
  3. Bestellung ohne Orderbuch in ME21N testen

Erfolgskontrolle / Customizing

Ablehnung im Negativtest prüfen und Einkauf schulen. SPRO: Einkauf → Orderbuch → Orderbuchpflicht auf Werksebene.

Einordnung
