MM-043 · L3

Rendre le répertoire des sources obligatoire par division

Problème

Les commandes de certaines divisions doivent être refusées sans répertoire valide. Il s’agit d’une nouvelle exigence.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

L’obligation par division doit être activée pour appliquer la politique fournisseur décrite.

Modules concernés

MM

Transactions

OME5, ME01, ME21N

Diagnostic / besoins

  1. Identifier les divisions concernées
  2. Examiner OME5 et les répertoires existants

Solution

  1. Activer l’indicateur dans OME5 selon le besoin
  2. Maintenir les répertoires dans ME01
  3. Tester une commande sans répertoire dans ME21N

Validation / paramétrage

Vérifier le rejet au test négatif et former les acheteurs. SPRO : Achats → Répertoire des sources → Obligation par division.

Classification

L3: Paramétrage ou évolution.

Source
