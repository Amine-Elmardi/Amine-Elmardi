MM-L3-016 · L3

Enforce a mandatory source list by plant

Problem

Procurement wants orders at selected plants to be rejected without a valid source list. This is a new process requirement.

Error message / number

Not specified in the source.

Root cause

The plant-level requirement must be activated to enforce preferred-supplier compliance described in the source.

Affected modules

MM

Transactions

OME5, ME01, ME21N

Diagnosis / requirements

  1. Identify the plants concerned
  2. Review the source list requirement in OME5 and existing material source lists

Solution

  1. Activate the plant indicator in OME5 according to the requirement
  2. Maintain source lists in ME01
  3. Test a purchase order without a source list in ME21N

Validation / configuration

Confirm rejection in the negative test and train buyers. SPRO: Purchasing → Source List → Plant-Level Requirements.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
