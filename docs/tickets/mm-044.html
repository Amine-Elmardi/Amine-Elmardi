MM-044 · L3

Mandatory quality inspection at goods receipt

Problem

The quality team needs selected materials to be inspected upon receipt, but the desired inspection is not triggered.

Error message / number

Not specified in the source.

Root cause

The source attributes this to missing QM activation or control settings in the material master.

Affected modules

MM / QM

Transactions

MM02, QP01, QA32, MIGO, MMBE

Diagnosis / requirements

  1. Identify relevant materials and plants
  2. Check QM activation and the quality view in MM02

Solution

  1. Activate the documented QM settings in SPRO
  2. Maintain the control key and inspection type 01 in MM02
  3. Create an inspection plan in QP01
  4. Post a test receipt in MIGO and process the lot in QA32

Validation / configuration

Check inspection stock in MMBE following the usage decision. The source describes separate stock destinations for acceptance and rejection.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 28–29, #044. Document-based educational scenario; not independently verified. Production changes require appropriate authorization.
