MM-L3-013 · L3

Custom bulk upload program for contract prices

Problem

Buyers require an Excel-based upload instead of maintaining thousands of contract price entries manually in ME32K.

Error message / number

Not specified in the source.

Root cause

The source identifies the time and error exposure of repetitive manual entry.

Affected modules

MM / ABAP

Transactions

ME32K, SE38, SE93, ME33K

Diagnosis / requirements

  1. Define required contract, item, condition type, price and validity fields
  2. Agree the file template and preview requirements

Solution

  1. Develop the documented SE38 upload approach using CL_GUI_FRONTEND_SERVICES and the named BAPI_CONTRACT_CHANGE
  2. Provide ALV preview and a downloadable error log
  3. Assign the custom transaction through SE93 and test with sample data before user acceptance and transport

Validation / configuration

Check updated contracts in ME33K and provide the template documentation. The source also mentions direct table updates, but gives no safety validation for them, so they are not recommended here.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
