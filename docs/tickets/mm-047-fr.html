MM-L3-006 · L3

Messages automatiques de refus pour offres non retenues

Problème

Après attribution d’une demande de prix, les achats souhaitent notifier les fournisseurs non retenus sans rédiger chaque lettre.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source identifie le paramétrage du message de refus et le statut de rejet comme nécessaires.

Modules concernés

MM

Transactions

ME41, ME47, ME49, MN04, ME9A

Diagnostic / besoins

  1. Examiner le schéma et le type de refus disponible
  2. Vérifier le marquage des offres dans ME47

Solution

  1. Paramétrer ABSA selon la source
  2. Maintenir les conditions dans MN04
  3. Renseigner le motif dans ME47 et traiter la sortie dans ME9A

Validation / paramétrage

Tester la lettre dans le formulaire Smartforms ou SAPscript concerné. Former les acheteurs à la gestion du statut.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
