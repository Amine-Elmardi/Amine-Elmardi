MM-L3-006 · L3

Automatic rejection messages for unsuccessful quotations

Problem

After awarding an RFQ, buyers want to notify unsuccessful suppliers without preparing each letter manually.

Error message / number

Not specified in the source.

Root cause

The source identifies rejection output configuration and quotation rejection status as necessary elements.

Affected modules

MM

Transactions

ME41, ME47, ME49, MN04, ME9A

Diagnosis / requirements

  1. Review quotation output schema and available rejection type
  2. Check how rejected quotations are marked in ME47

Solution

  1. Configure ABSA as described
  2. Maintain associated condition records in MN04
  3. Set rejection reason in ME47 and process output via ME9A

Validation / configuration

Test letter content in the relevant Smartforms or SAPscript form. Train buyers to maintain rejection status.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
