MM-L3-032 · L3

Valorisation séparée des stocks nationaux et importés

Problème

L’entreprise souhaite conserver un numéro article tout en valorisant séparément les stocks nationaux et importés.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document décrit une valorisation séparée avec plusieurs types sous une catégorie.

Modules concernés

MM

Transactions

MM02, MIGO, MMBE, OMW0

Diagnostic / besoins

  1. Définir la séparation requise
  2. Examiner les réglages existants

Solution

  1. Activer la valorisation séparée dans SPRO selon la source
  2. Définir catégorie et types dans OMW0, H et DOM/IMP étant des exemples
  3. Affecter la catégorie dans MM02
  4. Sélectionner le type applicable lors d’une réception de test dans MIGO

Validation / paramétrage

Contrôler stocks et prix séparés dans MMBE selon la source. Il s’agit de paramétrage de valorisation.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
