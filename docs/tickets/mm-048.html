MM-L3-032 · L3

Separate valuation for domestic and imported stock

Problem

The business wants to use one material number while valuing domestic and imported stock separately.

Error message / number

Not specified in the source.

Root cause

The document describes split valuation with several valuation types under one category.

Affected modules

MM

Transactions

MM02, MIGO, MMBE, OMW0

Diagnosis / requirements

  1. Identify required valuation separation
  2. Review existing split valuation settings

Solution

  1. Activate split valuation in the documented SPRO area
  2. Define category and types in OMW0, with H and DOM/IMP as source examples
  3. Assign the category in the accounting view of MM02
  4. Select the relevant type during a test GR in MIGO

Validation / configuration

Check separate stock and price information in MMBE as described. This is valuation configuration rather than an individual receipt correction.

Classification

L3: Configuration or enhancement.
