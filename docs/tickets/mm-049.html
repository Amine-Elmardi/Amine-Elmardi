MM-L3-007 · L3

Automatic supplier evaluation scores do not update

Problem

Purchasing expects price, delivery and quality scores to update, but values remain unchanged.

Error message / number

Not specified in the source.

Root cause

The document identifies incomplete scoring criteria or weights, or a missing scheduled evaluation job.

Affected modules

MM

Transactions

ME61, ME62, ME65, ME6B, OME2, OME3, SM36

Diagnosis / requirements

  1. Review current criteria and weighting keys
  2. Check whether ME65 has been run or scheduled

Solution

  1. Configure criteria and weights totaling 100 as specified
  2. Maintain subcriteria and scoring functions using OME2 and OME3
  3. Run ME65 and schedule periodic execution via SM36

Validation / configuration

Review results in ME61 or ME62 and generate ME6B. The source refers to vendor evaluation settings in SPRO.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
