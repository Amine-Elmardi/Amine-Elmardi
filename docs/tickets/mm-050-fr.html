MM-050 · L3

Workflow de validation des factures préenregistrées

Problème

Le rapprochement à trois éléments doit être validé avant la comptabilisation définitive de la facture.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La comptabilisation directe dans MIRO ne fournit pas le nouveau processus exigé dans le document.

Modules concernés

MM / FI

Transactions

MIR7, MIR6, MIR4, SBWP, SWDD

Diagnostic / besoins

  1. Définir seuil ou catégorie fournisseur
  2. Examiner les réglages de préenregistrement et de workflow

Solution

  1. Configurer le préenregistrement dans SPRO et le workflow dans SWDD selon la source
  2. Préenregistrer dans MIR7
  3. Acheminer la tâche vers l’approbateur dans SBWP
  4. Après validation, FI comptabilise via MIR6 selon le document

Validation / paramétrage

Contrôler MIR4 et le journal du workflow pour la traçabilité. Tester tout le processus.

Classification

L3: Paramétrage ou évolution.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 31–32, #050. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
