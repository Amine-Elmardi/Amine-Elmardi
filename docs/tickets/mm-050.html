MM-L3-004 · L3

Approval workflow for parked invoices

Problem

The business wants three-way matching to be verified through an approval process before invoice posting.

Error message / number

Not specified in the source.

Root cause

Direct MIRO posting does not provide the new approval process described by the document.

Affected modules

MM / FI

Transactions

MIR7, MIR6, MIR4, SBWP, SWDD

Diagnosis / requirements

  1. Define amount threshold or supplier category
  2. Review existing parking and workflow settings

Solution

  1. Configure the documented parking settings in SPRO and approval workflow in SWDD
  2. Park the invoice in MIR7
  3. Route the work item to the approver in SBWP
  4. After approval, FI posts through the documented MIR6 process

Validation / configuration

Check invoice in MIR4 and workflow log for the audit trail. Test the complete approval process.

Classification

L3: Configuration or enhancement.
