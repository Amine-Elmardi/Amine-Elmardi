MM-051 · L1

Article introuvable avec son ancien numéro

Problème

Les utilisateurs connaissent l’identifiant de l’ancien système mais ne trouvent pas l’article SAP correspondant.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

L’ancien numéro manque ou n’est pas visible dans la fiche actuelle.

Modules concernés

MM

Transactions

MM02, MM03, CL20N, LSMW, ME21N, SE38

Diagnostic / besoins

  1. Identifier les anciens et nouveaux numéros
  2. Examiner le champ ancien numéro dans les données de base 2

Solution

  1. Renseigner l’ancien numéro dans MM02
  2. Informer les utilisateurs sur la recherche
  3. Pour les besoins élargis, la source cite LSMW/BDC, CL20N ou un rapport de correspondance SE38

Validation / paramétrage

Contrôler la référence et la recherche dans ME21N si configurée. L1 concerne la maintenance individuelle, pas le développement optionnel.

Classification

L1: Correction opérationnelle individuelle.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 32, #051. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
