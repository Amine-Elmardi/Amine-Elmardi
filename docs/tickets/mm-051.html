MM-L1-003 · L1

Material cannot be found using legacy number

Problem

Users know the identifier from a former system but cannot find the corresponding SAP material.

Error message / number

Not specified in the source.

Root cause

The previous material number is missing or not visible in the current master data.

Affected modules

MM

Transactions

MM02, MM03, CL20N, LSMW, ME21N, SE38

Diagnosis / requirements

  1. Identify old and corresponding SAP identifiers
  2. Check the old material number field in Basic Data 2

Solution

  1. Maintain the old number in MM02
  2. Explain the search method to users
  3. For broader requirements the source names LSMW/BDC, classification through CL20N or a mapping report in SE38

Validation / configuration

Check the reference and search in ME21N if configured. L1 applies to individual maintenance, not the optional development.

Classification

L1: Individual operational correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
