MM-052 · L1

Réception restante clôturée par l’indicateur de livraison finale

Problème

Le fournisseur n’a livré qu’une partie de la commande, mais le solde apparaît clôturé.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

L’indicateur de livraison finale a été activé prématurément dans MIGO.

Modules concernés

MM

Transactions

ME22N, ME23N, MIGO

Diagnostic / besoins

  1. Examiner le poste et l’onglet Livraison dans ME22N
  2. Comparer quantité reçue et quantité restante

Solution

  1. Retirer l’indicateur erroné dans ME22N et enregistrer
  2. Comptabiliser la réception réelle restante dans MIGO

Validation / paramétrage

Contrôler l’historique dans ME23N. Informer le magasin sur l’utilisation de l’indicateur après confirmation des achats. Aucun paramétrage.

Classification

L1: Correction opérationnelle individuelle.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 33, #052. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
