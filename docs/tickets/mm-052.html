MM-L1-011 · L1

Remaining goods receipt closed by final delivery indicator

Problem

A supplier has delivered only part of the order, but the remaining quantity appears closed.

Error message / number

Not specified in the source.

Root cause

The final delivery indicator was set prematurely in MIGO.

Affected modules

MM

Transactions

ME22N, ME23N, MIGO

Diagnosis / requirements

  1. Check the purchase order item and its Delivery tab in ME22N
  2. Compare the received quantity with the outstanding delivery

Solution

  1. Remove the incorrect final delivery indicator in ME22N and save
  2. Post the actual remaining receipt in MIGO

Validation / configuration

Inspect purchase order history in ME23N. Remind warehouse staff to use the indicator only after buyer confirmation. No SPRO change.

Classification

L1: Individual operational correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
