MM-L2-021 · L2

Inventory Management and warehouse bin stock disagree

Problem

The material appears in the stock overview, but the corresponding WM bin quantity does not agree.

Error message / number

Not specified in the source.

Root cause

The document identifies a possible IM posting without its associated WM transfer order.

Affected modules

MM / WM

Transactions

MMBE, LS26, LI01, LI11N, LI20, MB51, LXIDC

Diagnosis / requirements

  1. Compare the same material and storage location in MMBE and LS26
  2. Investigate the relevant movements using MB51 and LS26

Solution

  1. Create a WM inventory document in LI01
  2. Record the actual bin count using LI11N
  3. Post confirmed inventory differences using LI20

Validation / configuration

Reconcile the two stock views and monitor via LXIDC. The source refers to WM physical inventory configuration.

Classification

L2: Functional analysis and coordinated correction.
