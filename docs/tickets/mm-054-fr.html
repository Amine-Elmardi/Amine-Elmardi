MM-L3-030 · L3

Conversion de demande d’achat impossible : adresse de livraison manquante

Problème

La conversion automatique échoue car l’adresse de réception requise est absente.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source identifie l’absence d’adresse dans le paramétrage de la division.

Modules concernés

MM

Transactions

ME57, ME59N, ME21N, ME23N, OX10, OX14

Diagnostic / besoins

  1. Identifier la division de la demande
  2. Contrôler rue, ville, code postal et pays dans OX10
  3. Si nécessaire vérifier l’affectation citée dans OX14

Solution

  1. Maintenir l’adresse de division selon le paramétrage décrit
  2. Relancer la conversion dans ME57 ou ME59N
  3. Pour une adresse spécifique à une commande, la source cite ME21N

Validation / paramétrage

Vérifier l’adresse de la commande générée dans ME23N. Le paramétrage de division est classé L3.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
