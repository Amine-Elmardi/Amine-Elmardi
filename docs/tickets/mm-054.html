MM-L3-030 · L3

Purchase requisition conversion fails due to missing delivery address

Problem

Automatic conversion of a requisition fails because the required receiving address is unavailable.

Error message / number

Not specified in the source.

Root cause

The source identifies missing address data in the plant configuration.

Affected modules

MM

Transactions

ME57, ME59N, ME21N, ME23N, OX10, OX14

Diagnosis / requirements

  1. Identify the plant on the affected requisition
  2. Review the street, city, postal code and country in OX10
  3. Check the plant assignment referenced in OX14 if necessary

Solution

  1. Maintain the required plant address through the documented configuration
  2. Repeat conversion in ME57 or ME59N
  3. If a specific order needs a different address, the source describes maintaining it in ME21N

Validation / configuration

Check the resulting delivery address in ME23N. Plant configuration is classified L3.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
