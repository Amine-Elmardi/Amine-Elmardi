MM-L2-042 · L2

Échec de facture récurrente lié au compte collectif

Problème

Une facture récurrente, par exemple de loyer ou de charges, ne peut être comptabilisée en raison du compte fournisseur.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source associe l’erreur à un compte collectif incompatible avec les paramètres attendus.

Modules concernés

MM / FI

Transactions

FK02, FK03, MIRO, MIR4, FB60, FS00

Diagnostic / besoins

  1. Afficher les données société dans FK03
  2. Relever le compte collectif et le vérifier dans FS00

Solution

  1. Faire corriger l’affectation dans FK02 par FI si elle est erronée
  2. Pour les factures sans commande, le document décrit FB60 plutôt que MIRO
  3. Relancer la comptabilisation prévue

Validation / paramétrage

Pour MIRO, examiner la pièce selon le parcours MIR4 documenté. Coordonner le compte collectif avec FI.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
