MM-L2-042 · L2

Recurring invoice fails because of reconciliation account

Problem

A recurring invoice, for example rent or utilities, cannot be posted due to a supplier account error.

Error message / number

Not specified in the source.

Root cause

The source associates the failure with a reconciliation account inconsistent with the expected posting settings.

Affected modules

MM / FI

Transactions

FK02, FK03, MIRO, MIR4, FB60, FS00

Diagnosis / requirements

  1. Display company-code supplier data in FK03
  2. Record the reconciliation account and inspect it in FS00

Solution

  1. Have FI correct the supplier account in FK02 if the assignment is wrong
  2. For an invoice without purchase order reference, the document describes using FB60 instead of MIRO
  3. Repeat the intended invoice posting

Validation / configuration

Review the accounting document using the documented MIR4 route for MIRO cases. Coordinate the reconciliation account with FI.

Classification

L2: Functional analysis and coordinated correction.
