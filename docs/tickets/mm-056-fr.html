MM-L2-047 · L2

La nomenclature ne se décompose pas dans la commande de sous-traitance

Problème

L’acheteur crée une commande de sous-traitance mais les composants attendus sont absents.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document cite une clé d’approvisionnement spécial manquante ou une nomenclature inactive ou invalide.

Modules concernés

MM / PP

Transactions

MM02, CS03, CS08, ME21N

Diagnostic / besoins

  1. Examiner l’approvisionnement spécial dans MRP 2 via MM02
  2. Afficher nomenclature et validité dans CS03
  3. Vérifier les alternatives dans CS08 si nécessaire

Solution

  1. Maintenir la clé 30 décrite si la sous-traitance est le processus prévu
  2. Créer le poste de catégorie L dans ME21N
  3. Contrôler à nouveau les composants

Validation / paramétrage

Vérifier la présence des composants. La source renvoie aux types d’approvisionnement spécial PP/MRP.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
