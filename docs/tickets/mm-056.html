MM-L2-047 · L2

Subcontracting purchase order does not show BOM components

Problem

The buyer creates a subcontracting order but the component overview does not contain the expected materials.

Error message / number

Not specified in the source.

Root cause

The document identifies a missing special procurement key or an inactive or invalid BOM.

Affected modules

MM / PP

Transactions

MM02, CS03, CS08, ME21N

Diagnosis / requirements

  1. Inspect the special procurement setting in MRP 2 using MM02
  2. Display the BOM and validity in CS03
  3. Review alternative selection in CS08 if needed

Solution

  1. Maintain the subcontracting key 30 as described if it is the intended process
  2. Create the subcontracting item with category L in ME21N
  3. Check component determination again

Validation / configuration

Verify that the required components appear. The source references the special procurement type settings in PP/MRP.

Classification

L2: Functional analysis and coordinated correction.
