MM-L2-003 · L2

Change material price control from V to S

Problem

Controlling requests standard price valuation for materials currently using moving average price.

Error message / number

Not specified in the source.

Root cause

The source describes a transition to standard costing requiring a released cost estimate.

Affected modules

MM / CO

Transactions

CK11N, CK24, MM02, MM03

Diagnosis / requirements

  1. Check current price control in MM03 Accounting 1
  2. Review the source prerequisites concerning open orders and uncleared stock value
  3. Coordinate the change with controlling

Solution

  1. Create the cost estimate using CK11N and mark and release it in CK24
  2. Check the standard price in the accounting view
  3. If prerequisites are satisfied, change the price control in MM02 from V to S
  4. The source mentions revaluation of variances if needed

Validation / configuration

Verify the resulting price control and standard price in MM03. The source refers to CO product cost controlling configuration.

Classification

L2: Functional analysis and coordinated correction.
