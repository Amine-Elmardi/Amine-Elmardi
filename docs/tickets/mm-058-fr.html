MM-L2-016 · L2

Réception comptabilisée dans le mauvais magasin

Problème

La réception est comptabilisée, mais le stock apparaît dans un magasin incorrect.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document attribue l’écart à un mauvais magasin sélectionné lors de la réception.

Modules concernés

MM

Transactions

MIGO (311), MMBE, MB03, OMJJ

Diagnostic / besoins

  1. Examiner MMBE et identifier les magasins source et cible
  2. Confirmer qu’ils appartiennent à la même division pour le scénario 311 décrit

Solution

  1. Effectuer le transfert dans MIGO avec le mouvement 311
  2. Saisir les magasins et la quantité réelle puis comptabiliser

Validation / paramétrage

Contrôler MMBE et la pièce article dans MB03. OMJJ est cité pour une exigence préventive distincte.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
