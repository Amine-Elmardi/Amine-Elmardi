MM-L2-016 · L2

Goods receipt recorded in the wrong storage location

Problem

The goods receipt has already been posted, but the stock appears under the wrong storage location.

Error message / number

Not specified in the source.

Root cause

The document attributes the discrepancy to an incorrect location selected during receipt.

Affected modules

MM

Transactions

MIGO (311), MMBE, MB03, OMJJ

Diagnosis / requirements

  1. Inspect stock in MMBE and identify the incorrect and intended locations
  2. Confirm both locations belong to the same plant for the documented 311 scenario

Solution

  1. Use the transfer posting procedure in MIGO with movement 311
  2. Enter the source and destination storage locations and post the actual quantity

Validation / configuration

Verify the stock in MMBE and material document in MB03. OMJJ is mentioned for a separate preventive configuration requirement.

Classification

L2: Functional analysis and coordinated correction.
