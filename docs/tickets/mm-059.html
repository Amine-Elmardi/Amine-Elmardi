MM-L2-045 · L2

Service entry sheet cannot be created

Problem

A supplier has performed services, but the user cannot record them against the service order.

Error message / number

Not specified in the source.

Root cause

The source identifies incomplete service master data or service lines in the purchase order.

Affected modules

MM

Transactions

ME23N, ME22N, ML81N, ML85, MIRO, AC03

Diagnosis / requirements

  1. Display the order in ME23N and confirm item category D
  2. Inspect the service lines and conditions
  3. Review the referenced service master in AC03 where relevant

Solution

  1. Add missing service lines in ME22N
  2. Create the entry sheet in ML81N referencing the order and record actual service, quantity and value
  3. Release the entry sheet according to the documented process

Validation / configuration

Verify the resulting receipt and subsequent invoice reference in MIRO. The source also lists ML85 and external service configuration.

Classification

L2: Functional analysis and coordinated correction.
