MM-L2-054 · L2

Fournisseur marqué pour suppression

Problème

L’acheteur ne peut pas créer de commande pour un fournisseur encore présent dans un contrat.

Message / numéro d’erreur

Vendor is marked for deletion — Numéro de message non indiqué.

Cause racine

Dans le scénario, un indicateur de suppression est actif au niveau organisation d’achats.

Modules concernés

MM

Transactions

XK03, XK06, XK02, ME21N

Diagnostic / besoins

  1. Afficher le fournisseur dans XK03 et examiner l’indicateur
  2. Clarifier si la suppression est intentionnelle

Solution

  1. Si erronée, obtenir l’accord métier puis retirer l’indicateur selon le parcours XK06 décrit
  2. Si intentionnelle, choisir un autre fournisseur et actualiser répertoire et fiches info-achats
  3. Créer la commande dans ME21N pour le fournisseur actif

Validation / paramétrage

Confirmer l’utilisation du fournisseur autorisé. Aucun changement SPRO décrit.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
