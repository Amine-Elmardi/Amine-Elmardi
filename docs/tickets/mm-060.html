MM-060 · L2

Vendor is marked for deletion

Problem

A buyer cannot create an order for a supplier that still appears in a contract.

Error message / number

Vendor is marked for deletion — Message number not specified.

Root cause

The supplier has a deletion indicator at purchasing organization level in the documented scenario.

Affected modules

MM

Transactions

XK03, XK06, XK02, ME21N

Diagnosis / requirements

  1. Display the supplier in XK03 and inspect the purchasing organization deletion flag
  2. Clarify whether the flag is intentional

Solution

  1. If the flag is wrong, obtain business approval and remove it using the documented XK06 process
  2. If deletion is intended, select another supplier and update the source list and info records
  3. Create the order for the active supplier in ME21N

Validation / configuration

Confirm that the authorized supplier can be used. No SPRO change is described.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 37, #060. Document-based educational scenario; not independently verified. Production changes require authorization.
