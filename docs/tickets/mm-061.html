MM-061 · L3

Protect subcontracting component quantities using a screen variant

Problem

The business wants to prevent manual changes to component quantities on subcontracting orders.

Error message / number

Not specified in the source.

Root cause

Users override component quantities, leading to differences from the BOM and printed document.

Affected modules

MM

Transactions

SHD0, ME21N, ME22N, CS01, CS02

Diagnosis / requirements

  1. Identify the screen field for the component quantity as described in the document
  2. Review the desired user groups and transaction variants

Solution

  1. Create a transaction variant for ME21N/ME22N using SHD0
  2. Set the relevant component field to display only
  3. Save and assign the variant to the intended roles or user groups

Validation / configuration

Test that quantities remain visible but cannot be changed by intended users and check output against BOM quantities. No SPRO change is described.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 37–38, #061. Document-based educational scenario; not independently verified. Production changes require authorization.
