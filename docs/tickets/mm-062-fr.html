MM-062 · L3

Rapport spécifique de correspondance des anciens numéros article

Problème

Après mise en production, les utilisateurs recherchent fréquemment le numéro SAP correspondant à un identifiant historique.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit une renumérotation et l’absence de rapport central de correspondance.

Modules concernés

MM / SD / ABAP

Transactions

SE38, SE93, MM03

Diagnostic / besoins

  1. Recueillir les besoins de recherche et d’affichage
  2. Examiner MARA-BISMT cité dans la source

Solution

  1. Renseigner l’ancienne référence durant la migration
  2. Développer dans SE38 un rapport ALV avec recherche partielle ou complète et sortie numéro, désignation, type, division et unité
  3. Ajouter les filtres prévus et affecter une transaction via SE93

Validation / paramétrage

Valider les résultats par MM03 et former les utilisateurs. Développement spécifique plutôt que maintenance individuelle.

Classification

L3: Paramétrage ou évolution.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 38, #062. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
