MM-062 · L3

Custom report for mapping legacy material numbers

Problem

After go-live, users frequently need the SAP number corresponding to an identifier from the previous system.

Error message / number

Not specified in the source.

Root cause

The source describes renumbered materials and a missing consolidated cross-reference report.

Affected modules

MM / SD / ABAP

Transactions

SE38, SE93, MM03

Diagnosis / requirements

  1. Gather old-number search and output requirements
  2. Review the old material number field MARA-BISMT mentioned in the source

Solution

  1. Populate the old-number reference during migration
  2. Develop an ALV report in SE38 supporting partial or full search, material number, description, type, plant and unit output
  3. Add the specified filters and assign a custom transaction using SE93

Validation / configuration

Validate results against existing material records in MM03 and train users. This is a custom report development, not individual master data maintenance.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 38, #062. Document-based educational scenario; not independently verified. Production changes require authorization.
