MM-063 · L3

Onglet achats spécifique pour les anciens numéros de documents

Problème

Après migration, les utilisateurs veulent consulter les anciens identifiants à côté des numéros SAP.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document indique l’absence de champ de référence dans le processus standard décrit.

Modules concernés

MM / ABAP

Transactions

ME21N, ME22N, SE11, SE38, LSMW

Diagnostic / besoins

  1. Recueillir les besoins de références historiques
  2. Définir les champs cités SAP_DOC_NR, LEGACY_DOC_NR, DOC_TYPE et CREATED_BY

Solution

  1. Créer la table spécifique dans SE11
  2. Ajouter l’onglet décrit dans ME21N/ME22N via ME_GUI_PO_CUST ou extension d’écran
  3. Stocker la référence liée à la commande SAP et créer un rapport de correspondance
  4. Charger l’historique selon l’approche LSMW décrite

Validation / paramétrage

Tester saisie et recherche. Le titre source inclut les demandes d’achat, mais l’implémentation détaillée concerne uniquement les commandes.

Classification

L3: Paramétrage ou évolution.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 38–39, #063. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
