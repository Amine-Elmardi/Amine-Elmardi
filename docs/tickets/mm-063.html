MM-L3-014 · L3

Custom purchasing tab for legacy document numbers

Problem

Users need to see old purchasing document identifiers alongside new SAP document numbers after migration.

Error message / number

Not specified in the source.

Root cause

The document identifies a missing reference field in the standard purchasing process described.

Affected modules

MM / ABAP

Transactions

ME21N, ME22N, SE11, SE38, LSMW

Diagnosis / requirements

  1. Collect legacy reference requirements for purchasing documents
  2. Define the custom storage fields named in the source: SAP_DOC_NR, LEGACY_DOC_NR, DOC_TYPE and CREATED_BY

Solution

  1. Create the custom table using SE11
  2. Add the documented purchasing tab in ME21N/ME22N via ME_GUI_PO_CUST or a screen enhancement
  3. Store the old identifier linked to the SAP order and create a cross-reference report
  4. Load historical data using the documented LSMW approach

Validation / configuration

Test entering and retrieving the legacy reference. The source title includes PR, but the detailed screen implementation describes PO transactions only.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
