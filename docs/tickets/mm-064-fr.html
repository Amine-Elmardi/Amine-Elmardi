MM-064 · L3

Réévaluation article sur des comptes généraux incorrects

Problème

Lors de la réévaluation de fin de période, stock ou écarts de prix sont comptabilisés sur un compte inattendu.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source cite une affectation incorrecte à la classe de valorisation sous BSX ou PRD dans OBYC.

Modules concernés

MM / FI / CO

Transactions

OBYC, MR21, FS10N, FB01, CKMLCP

Diagnostic / besoins

  1. Identifier classe et comptes concernés
  2. Vérifier BSX et PRD dans OBYC
  3. Examiner les comptes dans FS10N

Solution

  1. Coordonner la correction de l’affectation avec FI
  2. La source décrit MR21 après le décompte CKMLCP
  3. Si des corrections historiques sont nécessaires, coordonner les écritures FB01 décrites avec FI
  4. Transporter la correction OBYC approuvée

Validation / paramétrage

Contrôler les écritures dans FS10N. Cas de paramétrage de détermination automatique des comptes.

Classification

L3: Paramétrage ou évolution.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 39, #064. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
