MM-L3-026 · L3

Material revaluation posts to incorrect general ledger accounts

Problem

During period-end revaluation, stock or price differences are posted to an unintended G/L account.

Error message / number

Not specified in the source.

Root cause

The source identifies incorrect account assignment for valuation class under keys BSX or PRD in OBYC.

Affected modules

MM / FI / CO

Transactions

OBYC, MR21, FS10N, FB01, CKMLCP

Diagnosis / requirements

  1. Identify the affected valuation class and G/L postings
  2. Check BSX and PRD assignments in OBYC
  3. Review affected account balances in FS10N

Solution

  1. Coordinate correction of the account mapping with FI
  2. The source describes MR21 revaluation after CKMLCP settlement
  3. If historical postings require correction, coordinate the documented FB01 entries with FI
  4. Transport the approved OBYC correction

Validation / configuration

Verify the resulting postings in FS10N. This is an account determination configuration case.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
