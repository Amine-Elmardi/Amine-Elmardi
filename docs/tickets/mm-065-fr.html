MM-065 · L3

Absence de notification au responsable pour demandes de valeur élevée

Problème

Les demandes dépassant un seuil doivent déclencher une notification de validation avant conversion.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit l’absence de workflow de notification, privant le responsable de visibilité.

Modules concernés

MM / HR / Workflow

Transactions

ME51N, ME52N, SWDD, SWIA, PPOME, SWE2

Diagnostic / besoins

  1. Définir seuil et unités organisationnelles responsables
  2. Examiner le déclencheur de création ou modification

Solution

  1. Concevoir dans SWDD avec PURCHREQ.CREATED ou la modification ME52N décrite
  2. Définir la condition et acheminer vers le responsable via PPOME
  3. Configurer le modèle de courriel et tester avant transport

Validation / paramétrage

Suivre les tâches dans SWIA. La source cite SWE2 pour le couplage d’événements.

Classification

L3: Paramétrage ou évolution.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 39–40, #065. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
