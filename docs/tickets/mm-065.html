MM-L3-018 · L3

High-value requisitions do not notify department heads

Problem

Purchasing wants high-value requisitions to trigger an approval notification before conversion to an order.

Error message / number

Not specified in the source.

Root cause

The source describes an absent notification workflow, leaving department heads without visibility.

Affected modules

MM / HR / Workflow

Transactions

ME51N, ME52N, SWDD, SWIA, PPOME, SWE2

Diagnosis / requirements

  1. Define the value threshold and responsible organizational units
  2. Review the workflow trigger for creation or change

Solution

  1. Design the workflow in SWDD with PURCHREQ.CREATED or the ME52N change trigger described
  2. Set the value condition and route to the department head using PPOME
  3. Configure the email template and test before transport

Validation / configuration

Monitor work items in SWIA. The source names event linkage in SWE2.

Classification

L3: Configuration or enhancement.
