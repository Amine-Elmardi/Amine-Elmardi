MM-L3-035 · L3

La stratégie FIFO n’est pas respectée lors du prélèvement

Problème

Le stock ancien reste en emplacement alors que le stock récent est prélevé.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La stratégie de sortie décrite n’impose pas FIFO pour le type de stockage.

Modules concernés

MM / WM

Transactions

LS26, LS51, MIGO, LT0A

Diagnostic / besoins

  1. Identifier le type de stockage
  2. Examiner stratégie et dates de réception dans LS51

Solution

  1. Définir la stratégie F dans le paramétrage décrit
  2. La source mentionne aussi le tri par date de réception
  3. Tester une sortie

Validation / paramétrage

Contrôler la séquence dans LS26. La source situe le réglage dans SPRO → LE → WM → Types de stockage.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
