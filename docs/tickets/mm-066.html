MM-L3-035 · L3

Warehouse picking does not follow FIFO

Problem

Older stock remains in bins while newer stock is selected for issue.

Error message / number

Not specified in the source.

Root cause

The documented removal strategy does not enforce first-in-first-out for the relevant storage type.

Affected modules

MM / WM

Transactions

LS26, LS51, MIGO, LT0A

Diagnosis / requirements

  1. Identify affected storage type
  2. Review the removal strategy and goods receipt dates in LS51

Solution

  1. Set removal strategy F in the documented WM storage type configuration
  2. The source also mentions sorting by receipt date
  3. Test a goods issue

Validation / configuration

Check the picking sequence in LS26. The source locates the strategy in SPRO → LE → WM → Define Storage Types.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
