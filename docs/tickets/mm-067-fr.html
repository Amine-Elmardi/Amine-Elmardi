MM-L3-002 · L3

Activer le contrôle des factures basé sur la réception pour les commandes ouvertes

Problème

FI souhaite appliquer l’indicateur aux nouvelles commandes et aux commandes ouvertes.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

L’indicateur n’était pas obligatoire à la création mais une nouvelle politique l’exige.

Modules concernés

MM / FI

Transactions

ME11, ME12, ME22N, SE38

Diagnostic / besoins

  1. Identifier les commandes ouvertes et exclure celles déjà facturées selon la source
  2. Examiner les valeurs proposées et les types de document

Solution

  1. Maintenir les valeurs par défaut dans ME11/ME12
  2. Pour les commandes éligibles, utiliser ME22N ou le programme spécifique SE38 décrit
  3. Examiner le réglage SPRO cité et informer la comptabilité fournisseurs

Validation / paramétrage

Tester la chaîne commande, réception et facture. La modification en masse est une évolution contrôlée.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
