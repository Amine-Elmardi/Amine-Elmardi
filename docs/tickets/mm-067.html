MM-L3-002 · L3

Activate goods-receipt-based invoice verification on open orders

Problem

Finance wants the invoice verification indicator applied to new and existing open purchase orders.

Error message / number

Not specified in the source.

Root cause

The indicator was not required at order creation, but a revised policy requires it.

Affected modules

MM / FI

Transactions

ME11, ME12, ME22N, SE38

Diagnosis / requirements

  1. Identify open orders and exclude orders with posted invoices as instructed by the source
  2. Review info record defaults and document type settings

Solution

  1. Maintain GR-based IV defaults in ME11/ME12 for new orders
  2. For eligible existing orders use ME22N or the documented custom mass update in SE38
  3. Review the document-type default described in SPRO and inform accounts payable

Validation / configuration

Test the order, goods receipt and invoice sequence. The mass update is a controlled change, not routine incident resolution.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
