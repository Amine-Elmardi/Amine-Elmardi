MM-L3-025 · L3

Annulation en masse de mouvements erronés

Problème

Une saisie en masse a produit de nombreux documents article erronés, 200 dans l’exemple source.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Les erreurs de saisie rendent les annulations individuelles coûteuses en temps.

Modules concernés

MM / ABAP

Transactions

MB51, MB03, SE38, MIGO, MMBE

Diagnostic / besoins

  1. Extraire les documents concernés via MB51
  2. Confirmer lesquels doivent être annulés

Solution

  1. Utiliser ou développer le programme SE38 décrit avec BAPI_GOODSMVT_CANCEL ou MB_CANCEL_GOODS_MOVEMENT
  2. Consigner succès et échecs par document dans un journal ALV
  3. Exécuter le mode test avant l’exécution productive autorisée

Validation / paramétrage

Rapprocher MMBE et MB51. Analyser l’erreur initiale pour éviter la récurrence.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
