MM-L3-025 · L3

Mass reversal of incorrect goods movements

Problem

A bulk posting produced many incorrect material documents, with 200 documents in the source example.

Error message / number

Not specified in the source.

Root cause

Bulk entry errors make individual cancellations inefficient.

Affected modules

MM / ABAP

Transactions

MB51, MB03, SE38, MIGO, MMBE

Diagnosis / requirements

  1. Extract the affected document numbers with MB51
  2. Confirm which documents require reversal before processing

Solution

  1. Use or develop the SE38 program described with BAPI_GOODSMVT_CANCEL or MB_CANCEL_GOODS_MOVEMENT
  2. Record success and failure for each document in an ALV log
  3. Execute test mode and review results before approved production execution

Validation / configuration

Reconcile stock in MMBE and movements in MB51. Investigate the original entry error to prevent repetition.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
