MM-L3-017 · L3

Le code de taxe GST n’est pas proposé dans la commande

Problème

Après mise en œuvre de GST, le code taxe manque dans les conditions de poste et doit être saisi manuellement.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source évoque une détermination de taxe absente et des valeurs de base manquantes.

Modules concernés

MM / FI

Transactions

XK02, ME11, ME12, ME21N, MIRO, OBZT

Diagnostic / besoins

  1. Examiner les codes dans les données achats fournisseur et fiches info-achats
  2. Identifier la procédure attendue avec FI

Solution

  1. Maintenir les valeurs documentées via XK02 et ME11/ME12 si applicable
  2. Examiner la détermination achats dans SPRO et OBZT avec FI
  3. Tester la proposition dans ME21N

Validation / paramétrage

Comptabiliser une facture test dans MIRO et contrôler GST avec FI. TAXINN ou TAXINJ sont les procédures citées.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
