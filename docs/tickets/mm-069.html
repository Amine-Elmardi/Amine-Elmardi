MM-069 · L3

GST tax code is not proposed in purchase orders

Problem

After GST implementation, the tax code is absent from item conditions and users must enter it manually.

Error message / number

Not specified in the source.

Root cause

The source links the issue to missing tax determination and missing master-data defaults.

Affected modules

MM / FI

Transactions

XK02, ME11, ME12, ME21N, MIRO, OBZT

Diagnosis / requirements

  1. Review tax-code values in vendor purchasing data and info records
  2. Identify the expected tax procedure with FI

Solution

  1. Maintain the documented values through XK02 and ME11/ME12 where applicable
  2. Review purchasing tax determination in SPRO and OBZT with FI
  3. Test automatic proposal in ME21N

Validation / configuration

Post a test invoice in MIRO and check GST postings with FI. TAXINN or TAXINJ are the source procedure references.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 42, #069. Document-based educational scenario; not independently verified. Production changes require authorization.
