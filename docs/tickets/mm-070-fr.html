MM-L3-003 · L3

Alerte avant épuisement de la valeur d’un programme de livraisons

Problème

Les acheteurs souhaitent être avertis avant la limite, avec 80 % comme seuil dans la source.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit une découverte tardive de l’épuisement sans surveillance proactive.

Modules concernés

MM / ABAP

Transactions

ME33L, ME3L, SE38, SM36

Diagnostic / besoins

  1. Définir valeur cible, valeur appelée et seuil
  2. Identifier les programmes dans EKKO/EKPO cités

Solution

  1. Développer le rapport SE38 ou utiliser BW/Analytics
  2. Calculer valeur appelée divisée par cible et signaler à partir de 80 %
  3. Fournir une liste ALV et éventuellement un courriel via SO_NEW_DOCUMENT_SEND_API
  4. Planifier chaque semaine dans SM36

Validation / paramétrage

Vérifier les valeurs des programmes signalés et confirmer la réception des résultats.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
