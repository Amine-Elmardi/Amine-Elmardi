MM-L3-003 · L3

Alert before scheduling agreement value is exhausted

Problem

Buyers need advance warning when an agreement approaches the limit, with 80% as the source threshold.

Error message / number

Not specified in the source.

Root cause

The source describes late discovery of exhausted target values without proactive monitoring.

Affected modules

MM / ABAP

Transactions

ME33L, ME3L, SE38, SM36

Diagnosis / requirements

  1. Define target and actual release value and the alert threshold
  2. Identify the relevant agreements using the documented EKKO/EKPO data

Solution

  1. Build the report in SE38 or use the BW/Analytics option
  2. Calculate actual release value divided by target value and flag agreements at 80% or above
  3. Provide an ALV list and optional email via the named SO_NEW_DOCUMENT_SEND_API
  4. Schedule weekly execution in SM36

Validation / configuration

Verify flagged agreements against their release values and confirm that buyers receive the monitoring output.

Classification

L3: Configuration or enhancement.
