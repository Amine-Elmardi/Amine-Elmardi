MM-071 · L4

Écran spécifique de prix contractuels avec chargement en masse

Problème

Les achats souhaitent actualiser de nombreux prix contractuels via Excel plutôt que les saisir individuellement.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit le traitement manuel dans ME32K comme inefficace et sujet aux erreurs à cette échelle.

Modules concernés

MM / ABAP

Transactions

SE51, SE38, SE93, ME32K, ME33K

Diagnostic

  1. Recueillir les besoins : contrat, poste, type de condition, quantité de barème, prix et validité.
  2. Concevoir écran et programme selon l’approche SE51 et SE38 du document.

Solution

  1. Développer le chargement avec ABAP et le BAPI_CONTRACT_CHANGE cité.
  2. Ajouter la gestion des erreurs, un journal et un aperçu ALV avant comptabilisation.
  3. Affecter la transaction spécifique dans SE93.
  4. Effectuer les tests unitaires et la recette achats.

Validation / paramétrage

Mettre en production après acceptation et surveiller. Il s’agit d’un projet de développement, non d’une correction de commande isolée.

Classification

L4: Projet de développement en plusieurs étapes.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 43, #071. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
