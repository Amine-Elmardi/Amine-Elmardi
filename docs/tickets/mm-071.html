MM-L4-002 · L4

Custom contract pricing screen with bulk upload

Problem

Procurement needs to update a large number of contract prices using Excel rather than entering them individually.

Error message / number

Not specified in the source.

Root cause

The source describes the manual effort in ME32K as inefficient and error-prone at the required scale.

Affected modules

MM / ABAP

Transactions

SE51, SE38, SE93, ME32K, ME33K

Diagnosis

  1. Gather requirements for contract number, item, condition type, scale quantity, price and validity.
  2. Design the screen and program using the documented SE51 and SE38 approach.

Solution

  1. Implement the upload with the ABAP team using the named BAPI_CONTRACT_CHANGE.
  2. Add error handling, log output and an ALV preview before posting.
  3. Assign the custom transaction using SE93.
  4. Perform unit tests and procurement user acceptance tests.

Validation / configuration

Release after acceptance and monitor operation. This is a custom development project, not a correction of a single purchasing document.

Classification

L4: Multi-stage development project.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
