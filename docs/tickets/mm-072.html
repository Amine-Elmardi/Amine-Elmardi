MM-L4-007 · L4

Redesign certificate of analysis and automate IDoc delivery

Problem

Quality management requires a complete form redesign with 15 additional fields and automatic transmission to buyers.

Error message / number

Not specified in the source.

Root cause

The source describes changed compliance needs and an outdated manually distributed form.

Affected modules

MM / QM / ABAP

Transactions

Smartforms, WE20, WE21, WE60, QA32

Diagnosis / requirements

  1. Collect field requirements with QA
  2. Identify the named sources MCHA, MARA and LFA1
  3. Define layout and transmission requirements

Solution

  1. Redesign Smartform and extend the printing function module
  2. Configure the documented message and IDoc settings via WE60, WE20 and WE21
  3. Test batch creation, certificate printing and outbound transmission end to end

Validation / configuration

Obtain acceptance and accompany go-live. The project spans form development, integration and process testing.

Classification
