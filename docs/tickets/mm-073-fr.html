MM-L4-006 · L4

Écran de conformité achats et mise en œuvre FRICEW

Problème

Le scénario exige des certificats de conformité pour les documents de valeur élevée avant validation via une solution intégrée.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document décrit une exigence réglementaire et un contrôle absent du processus actuel. Aucun pays ni texte juridique précis n’est identifié.

Modules concernés

MM / ABAP / Workflow

Transactions

SE38, SE51, Smartforms, SWDD, SE18, SE19

Diagnostic / besoins

  1. Définir seuil, exigences du certificat et responsable conformité
  2. Spécifier les six composants FRICEW et leur intégration

Solution

  1. Concevoir certificat Smartform et rapport des vérifications en attente
  2. Intégrer la base externe via RFC ou service web décrit
  3. Convertir les commandes ouvertes au nouveau processus
  4. Ajouter Compliance Status à l’en-tête via ME_PROCESS_PO_CUST cité
  5. Concevoir le workflow lors de l’enregistrement au-delà du seuil

Validation / paramétrage

Effectuer tests composants, recette et tests de bout en bout avant mise en production. Les durées de la source divergent, aucune durée fixe n’est affirmée.

Classification

L4: Projet en plusieurs étapes.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
