MM-073 · L4

Procurement compliance screen and FRICEW implementation

Problem

The scenario requires compliance certificates for high-value purchasing documents before release, using a new integrated solution.

Error message / number

Not specified in the source.

Root cause

The document describes a regulatory requirement and an approval control that the existing process does not provide. No specific jurisdiction or law is identified.

Affected modules

MM / ABAP / Workflow

Transactions

SE38, SE51, Smartforms, SWDD, SE18, SE19

Diagnosis / requirements

  1. Define value threshold, certificate requirements and responsible compliance officer
  2. Specify the six FRICEW components and their integration

Solution

  1. Design a Smartform certificate and a report of pending verifications
  2. Integrate the external compliance database via the documented RFC or web service
  3. Convert existing open orders to the new process
  4. Add Compliance Status to the order header using the named ME_PROCESS_PO_CUST enhancement
  5. Design workflow routing on order save when threshold is exceeded

Validation / configuration

Perform component and user acceptance testing plus end-to-end verification before release. The source provides inconsistent duration figures, so no fixed schedule is asserted.

Classification

L4: Multi-stage project.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 44, #073. Document-based educational scenario; not independently verified. Production changes require authorization.
