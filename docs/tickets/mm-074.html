MM-L4-003 · L4

Enterprise procurement dashboard with ALV and Fiori

Problem

Management needs consolidated procurement KPIs including order cycle time, savings, overdue deliveries, suppliers and open GR/IR items.

Error message / number

Not specified in the source.

Root cause

Reporting is dispersed across transactions rather than providing a common overview.

Affected modules

MM / Analytics / ABAP

Transactions

ME2M, MB51, MR11, SE38, PFCG

Diagnosis / requirements

  1. Define KPIs, source data and refresh intervals
  2. Review the named tables EKKO, EKPO, EKET, EKBE, MSEG and RBKP
  3. Determine management access levels

Solution

  1. Develop extraction using the documented ABAP or CDS approach
  2. Create ALV dashboard and Fiori tile, with historical BW reporting as an optional source proposal
  3. Implement role-based access using PFCG

Validation / configuration

Conduct user acceptance testing, verify indicators and access, and release the dashboard.

Classification

L4: Multi-stage implementation or development.
