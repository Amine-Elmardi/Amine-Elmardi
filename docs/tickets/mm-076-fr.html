MM-076 · L2

Unité de mesure différente entre commande et facture

Problème

Le fournisseur facture dans une unité différente de celle de la commande, provoquant des écarts de quantité ou de valeur sur le compte EM/EF.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La conversion entre unités peut manquer dans la fiche article. La source illustre les tonnes et kilogrammes.

Modules concernés

MM / FI

Transactions

MM02, ME11, MIRO, MR8M

Diagnostic

  1. Comparer les unités de commande et de facture.
  2. Dans MM02 examiner les unités supplémentaires des données de base 1.

Solution

  1. Maintenir la conversion nécessaire selon la source, par exemple 1 tonne = 1000 kg.
  2. Dans MIRO sélectionner l’unité correcte avec référence à la réception.
  3. Si une facture a déjà été mal comptabilisée, la source décrit l’annulation dans MR8M puis la nouvelle comptabilisation.

Validation / paramétrage

Contrôler quantité et valeur attendues et vérifier les unités lors de la création de fiches info-achats dans ME11.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source
