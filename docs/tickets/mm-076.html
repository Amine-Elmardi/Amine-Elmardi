MM-L2-053 · L2

Unit of measure differs between purchase order and invoice

Problem

The supplier invoices in a different unit from the order, causing quantity or value discrepancies in the GR/IR account.

Error message / number

Not specified in the source.

Root cause

The material master may lack the conversion between the two units. The source illustrates tonnes and kilograms.

Affected modules

MM / FI

Transactions

MM02, ME11, MIRO, MR8M

Diagnosis

  1. Inspect the units used on the order and invoice.
  2. In MM02 review additional units of measure in Basic Data 1.

Solution

  1. Maintain the required conversion as described, for example 1 tonne = 1000 kg.
  2. Select the correct unit in MIRO with the receipt reference.
  3. If an invoice was already posted incorrectly, the source describes cancellation with MR8M and reposting.

Validation / configuration

Verify the intended quantity and value and check units when creating info records in ME11.

Classification

L2: Functional analysis and coordinated correction.
