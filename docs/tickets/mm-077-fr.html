MM-L2-006 · L2

Historique des appels de contrat incomplet

Problème

La direction souhaite voir toutes les commandes d’appel d’un contrat mais l’historique affiché paraît incomplet.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document cite une documentation d’appels inactive ou un rapport inadapté.

Modules concernés

MM

Transactions

ME33K, ME3M, ME2K, ME32K

Diagnostic / besoins

  1. Examiner statistiques d’en-tête et valeur appelée dans ME33K
  2. Examiner les commandes via ME2K et ME3M avec référence du contrat

Solution

  1. Si le réglage manque, la source décrit l’activation de la documentation dans l’en-tête via ME32K
  2. Utiliser les rapports détaillés pour les appels existants et exporter vers Excel si nécessaire

Validation / paramétrage

Vérifier les futurs appels et rapprocher les valeurs. La source n’établit pas la reconstruction automatique de l’historique manquant.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
