MM-077 · L2

Contract release history is incomplete

Problem

Management needs to see every call-off purchase order for an existing contract, but the displayed history appears incomplete.

Error message / number

Not specified in the source.

Root cause

The document identifies inactive release documentation or use of an unsuitable report.

Affected modules

MM

Transactions

ME33K, ME3M, ME2K, ME32K

Diagnosis / requirements

  1. Inspect header statistics and total released value in ME33K
  2. Review call-off orders through ME2K and ME3M using the contract reference

Solution

  1. If the release documentation setting is missing, the source describes activating it in the contract header using ME32K
  2. Use the detailed reports to review existing releases and export the list to Excel if needed

Validation / configuration

Verify future release documentation and reconcile report values. The source does not establish whether historical missing documentation is reconstructed automatically.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 46–47, #077. Document-based educational scenario; not independently verified. Production changes require authorization.
