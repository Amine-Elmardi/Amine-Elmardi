MM-L2-018 · L2

Goods receipt rejected because MM posting period is closed

Problem

Warehouse staff cannot post a goods receipt because posting is limited to the open MM periods.

Error message / number

Posting only possible in periods xxxx/xx and xxxx/xx in MM — Message number not specified.

Root cause

The document attributes the issue to a period change that has not been performed.

Affected modules

MM

Transactions

MMRV, MMPV, MIGO, SM36

Diagnosis / requirements

  1. Display the current period in MMRV
  2. Identify company code and required period, then compare with open periods

Solution

  1. Have the responsible team perform the documented period change in MMPV
  2. Retry receipt in MIGO once the intended period is open
  3. For recurrence the source suggests a scheduled month-beginning activity via SM36

Validation / configuration

Confirm the period in MMRV and the successful receipt. L2 reflects the company-code impact.

Classification

L2: Functional analysis and coordinated correction.
