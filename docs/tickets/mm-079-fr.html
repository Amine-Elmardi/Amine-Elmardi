MM-079 · L1

La date de livraison de la commande est passée

Problème

Un avertissement apparaît lorsque la date de livraison est antérieure à aujourd’hui.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La date prévue se situe dans le passé. Le document traite le message comme un avertissement attendu et non un défaut technique.

Modules concernés

MM

Transactions

ME21N, ME22N, OMEE

Diagnostic / besoins

  1. Contrôler la date dans ME21N ou ME22N
  2. Déterminer si la date passée est volontaire ou erronée

Solution

  1. Si elle est erronée, saisir une date future réaliste
  2. Si la date historique est volontaire, obtenir confirmation métier et accepter l’avertissement lorsque permis

Validation / paramétrage

Contrôler date et résultat. OMEE n’est cité que pour une règle distincte imposant une erreur plutôt qu’un avertissement.

Classification

L1: Correction opérationnelle individuelle.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 47–48, #079. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification en production nécessite l’autorisation appropriée.
