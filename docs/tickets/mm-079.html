MM-079 · L1

Purchase order delivery date is in the past

Problem

A buyer receives a warning when entering a delivery date earlier than today.

Error message / number

Not specified in the source.

Root cause

The planned date lies in the past. The document treats this as an expected warning, not a technical malfunction.

Affected modules

MM

Transactions

ME21N, ME22N, OMEE

Diagnosis / requirements

  1. Review delivery date in ME21N or ME22N
  2. Determine whether the past date is intentional or an error

Solution

  1. For an incorrect date, enter a realistic future date
  2. For intentional historical entry, confirm with the business and accept the warning where permitted

Validation / configuration

Check the order date and result. OMEE is mentioned only for a separate policy requiring an error instead of a warning.

Classification

L1: Individual operational correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 47–48, #079. Document-based educational scenario; not independently verified. Production changes require appropriate authorization.
