MM-L2-029 · L2

Material missing from slow-moving inventory analysis

Problem

A buyer is reviewing slow-moving stock but cannot find certain materials in the report used.

Error message / number

Not specified in the source.

Root cause

The source attributes the missing results to movement-history or usage selection. Its description of MM60 as movement-dependent is not independently established.

Affected modules

MM

Transactions

MM60, MB51, MB52, MM02

Diagnosis / requirements

  1. Review the actual MM60 selection and material scope
  2. Check movement history for the material in MB51

Solution

  1. The document proposes widening the period where applicable
  2. Use MB52 as the stock basis and compare with MB51 to identify stock without movements
  3. The source suggests a slow-mover indicator in MM02, but the specific field is not identified

Validation / configuration

Verify the resulting material population and movement history before classifying slow stock. No configuration change is prescribed.

Classification

L2: Functional analysis and coordinated correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
