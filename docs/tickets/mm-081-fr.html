MM-L2-011 · L2

Limite de valeur d’une commande cadre épuisée

Problème

La comptabilité fournisseurs ne peut plus comptabiliser de factures sur une commande cadre dont la limite est consommée.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Selon la source, la valeur cible est épuisée et nécessite une augmentation ou un renouvellement approuvé.

Modules concernés

MM / FI

Transactions

ME22N, ME23N, ME21N, MIR6

Diagnostic / besoins

  1. Examiner les statistiques dans ME23N
  2. Déterminer la valeur consommée et l’autorisation d’augmentation ou de remplacement

Solution

  1. Si approuvée, modifier la valeur cible dans ME22N selon le document
  2. Sinon créer une commande cadre FO dans ME21N avec valeur, validité et conditions convenues
  3. Reprendre la facturation sur la commande appropriée

Validation / paramétrage

Contrôler la limite et les factures. La source propose aussi une alerte à 80 % de consommation.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
