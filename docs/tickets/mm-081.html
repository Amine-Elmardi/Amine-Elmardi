MM-L2-011 · L2

Framework order value limit exhausted

Problem

Accounts payable cannot post more invoices against a blanket order whose value limit is consumed.

Error message / number

Not specified in the source.

Root cause

The source links the issue to the exhausted target value and need for an approved increase or renewal.

Affected modules

MM / FI

Transactions

ME22N, ME23N, ME21N, MIR6

Diagnosis / requirements

  1. Review statistics in ME23N
  2. Determine the consumed value and whether an increase or replacement is authorized

Solution

  1. For an approved increase, adjust the target value in ME22N as described
  2. Alternatively create a new framework order of type FO in ME21N with value, validity and supplier terms
  3. Resume invoicing against the correct order

Validation / configuration

Check the limit and invoice processing. The source also proposes an alert at 80% consumption as an improvement.

Classification

L2: Functional analysis and coordinated correction.
