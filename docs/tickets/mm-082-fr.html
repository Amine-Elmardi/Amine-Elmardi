MM-082 · L2

Avoir fournisseur après retour de marchandises

Problème

Après retour avec mouvement 122, le fournisseur émet un avoir à enregistrer sur la commande initiale.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit une opération d’avoir plutôt qu’une facture pour la quantité et la valeur retournées.

Modules concernés

MM / FI

Transactions

MIRO, MIR4, ME23N

Diagnostic / besoins

  1. Identifier commande initiale et quantité retournée
  2. Comparer l’avoir et la référence de commande

Solution

  1. Choisir Avoir dans MIRO
  2. Saisir commande, quantité retournée et valeur de l’avoir
  3. Comptabiliser selon le document

Validation / paramétrage

Vérifier dans MIR4 et examiner la comptabilité avec FI. La source se contredit sur le sens débit/crédit EM/EF, non affirmé ici.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 49, #082. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
