MM-L2-050 · L2

Supplier credit memo after goods return

Problem

After return movement 122, the supplier issues a credit note that must be recorded against the original purchase order.

Error message / number

Not specified in the source.

Root cause

The source describes a credit memo transaction rather than an invoice for the returned quantity and value.

Affected modules

MM / FI

Transactions

MIRO, MIR4, ME23N

Diagnosis / requirements

  1. Identify the original order and returned quantity
  2. Compare supplier credit note and order reference

Solution

  1. Select Credit Memo in MIRO
  2. Enter original PO reference, returned quantity and credit value
  3. Post the credit memo as described

Validation / configuration

Verify the document in MIR4 and review accounting with FI. The source gives inconsistent debit/credit directions for GR/IR, so no specific account direction is asserted here.

Classification

L2: Functional analysis and coordinated correction.
