MM-L2-026 · L2

Mass maintenance of plant MRP data

Problem

A supply-chain policy requires standardized planning parameters across hundreds of materials in multiple plants.

Error message / number

Not specified in the source.

Root cause

The source describes a new data standard that would be slow to implement through individual MM02 changes.

Affected modules

MM / PP

Transactions

MM17, MM02, MM03, LSMW

Diagnosis / requirements

  1. Define materials, plants and approved MRP values
  2. Select material object and MRP 1 view in MM17 and filter the intended records

Solution

  1. Enter the approved values, with PD, safety stock 100 and EX only examples in the source
  2. Run simulation and review the selection and changes
  3. Confirm and execute the approved update

Validation / configuration

Check sample records in MM03. For larger volumes the source mentions LSMW with MM02 BDC.

Classification

L2: Functional analysis and coordinated correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
