MM-L2-038 · L2

Purchase order tax differs from supplier invoice

Problem

The calculated tax in the order differs from the supplier invoice, blocking invoice processing.

Error message / number

Not specified in the source.

Root cause

The document identifies a different tax code, rate or taxable base.

Affected modules

MM / FI

Transactions

ME23N, MIRO, MRBR, FTXP

Diagnosis / requirements

  1. Inspect order item conditions and calculated tax in ME23N
  2. Compare with the supplier invoice and clarify the difference with the tax team

Solution

  1. If appropriate and within tolerance, the source describes adjusting the tax amount in MIRO
  2. If the SAP tax rate is wrong, refer to FI for the FTXP correction
  3. For a blocked invoice, the source names MRBR subject to approval

Validation / configuration

Confirm the correct tax and invoice status. TAXINN/TAXINJ changes are mentioned only as longer-term procedure improvements.

Classification

L2: Functional analysis and coordinated correction.
