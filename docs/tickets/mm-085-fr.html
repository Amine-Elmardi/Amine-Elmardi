MM-L1-008 · L1

Stock projet invisible dans la synthèse standard

Problème

Un utilisateur ne retrouve pas un stock affecté à un élément d’OTP dans la synthèse standard.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source indique que le stock projet est présenté séparément comme stock spécial Q non sélectionné.

Modules concernés

MM / PS

Transactions

MMBE, MB52, CN52N, MIGO (281)

Diagnostic / besoins

  1. Identifier l’élément d’OTP et l’article
  2. Contrôler la sélection des stocks spéciaux dans MMBE ou MB52

Solution

  1. Sélectionner Q et l’élément d’OTP dans MMBE
  2. Inclure Q dans MB52 ou utiliser la synthèse CN52N citée

Validation / paramétrage

Vérifier l’affichage et coordonner les affectations avec PS. La source cite aussi le mouvement 281 pour sorties projet. Aucun paramétrage.

Classification

L1: Correction opérationnelle individuelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
