MM-L1-008 · L1

Project stock not visible in standard stock overview

Problem

A user cannot find stock assigned to a WBS element in the standard overview.

Error message / number

Not specified in the source.

Root cause

The source identifies project stock as separately reported special stock Q, which has not been selected.

Affected modules

MM / PS

Transactions

MMBE, MB52, CN52N, MIGO (281)

Diagnosis / requirements

  1. Identify the relevant WBS element and material
  2. Check special stock selection in MMBE or MB52

Solution

  1. Select project stock Q in MMBE and enter the WBS element
  2. Include Q in MB52 or use the referenced CN52N project stock overview

Validation / configuration

Confirm the project stock appears and coordinate WBS assignment issues with PS. The source also mentions movement 281 for project issues. No configuration change.

Classification

L1: Individual operational correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
