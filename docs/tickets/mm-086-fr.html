MM-L3-023 · L3

Imputation et décompte des coûts d’achat sur ordre interne

Problème

Les coûts d’achat doivent être imputés et décomptés sur des ordres internes pour le contrôle de gestion.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit une nouvelle exigence de suivi des coûts par ordre interne et règles de décompte.

Modules concernés

MM / CO

Transactions

ME21N, KO01, KO02, KO8G, KO23

Diagnostic / besoins

  1. Définir ordre et destinataire avec CO
  2. Examiner imputation achats et affectation automatique

Solution

  1. Utiliser catégorie F dans ME21N et saisir compte général et ordre
  2. Configurer l’affectation SPRO décrite avec CO
  3. Maintenir les règles dans KO01 ou KO02
  4. Exécuter le décompte de période dans KO8G

Validation / paramétrage

Examiner les coûts décomptés dans KO23 selon la source. Tester le cycle avec CO.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
