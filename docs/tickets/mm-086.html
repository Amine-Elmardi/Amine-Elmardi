MM-086 · L3

Internal order assignment and settlement for procurement costs

Problem

Procurement costs must be assigned to internal orders and settled for controlling purposes.

Error message / number

Not specified in the source.

Root cause

The source describes a new requirement to track costs using internal orders and settlement rules.

Affected modules

MM / CO

Transactions

ME21N, KO01, KO02, KO8G, KO23

Diagnosis / requirements

  1. Define the responsible internal order and settlement receiver with CO
  2. Review the purchasing account assignment and automatic assignment configuration

Solution

  1. Use account assignment category F in ME21N and enter the G/L and internal order
  2. Configure the assignment described in SPRO with CO
  3. Maintain settlement rules in KO01 or KO02
  4. Execute period-end settlement in KO8G

Validation / configuration

Review settled costs using KO23 as described. Test the purchasing and settlement sequence with CO.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 51, #086. Document-based educational scenario; not independently verified. Production changes require authorization.
