MM-L1-001 · L1

Materialbeleg bereits storniert

Problem

Der Anwender möchte einen Materialbeleg stornieren, doch das System meldet, dass dieser schon storniert wurde.

Fehlermeldung / Nummer

Document already reversed — Meldungsnummer nicht angegeben.

Ursache

Zur ursprünglichen Buchung existiert bereits ein Stornobeleg.

Betroffene Module

MM

Transaktionen

MB03, MB51, MIGO

Analyse / Anforderungen

  1. Originalbeleg in MB03 öffnen
  2. Stornoreferenz ermitteln und Saldo mit MB51 prüfen

Lösung

  1. Dasselbe Storno nicht wiederholen
  2. Falls der ursprüngliche Wareneingang storniert wurde und ein tatsächlicher Eingang erforderlich ist, beschreibt die Quelle einen neuen WE in MIGO

Erfolgskontrolle / Customizing

Prüfen, ob Belegverlauf und Saldo dem vorgesehenen Ergebnis entsprechen. Anwender zur Statusprüfung informieren. Kein SPRO-Eingriff.

Einordnung

L1: Einzelne operative Korrektur.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig in einem SAP-System validiert. Produktivänderungen nur mit entsprechender Freigabe.
