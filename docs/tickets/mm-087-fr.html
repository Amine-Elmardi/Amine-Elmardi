MM-L1-001 · L1

Document article déjà annulé

Problème

L’utilisateur tente d’annuler un document article, mais le système indique qu’il est déjà annulé.

Message / numéro d’erreur

Document already reversed — Numéro de message non indiqué.

Cause racine

Un document d’annulation existe déjà pour l’écriture initiale.

Modules concernés

MM

Transactions

MB03, MB51, MIGO

Diagnostic / besoins

  1. Ouvrir l’original dans MB03
  2. Identifier la référence d’annulation et vérifier le solde via MB51

Solution

  1. Ne pas répéter la même annulation
  2. Si la réception initiale a été annulée et qu’une réception réelle est nécessaire, la source décrit une nouvelle réception dans MIGO

Validation / paramétrage

Vérifier l’historique et le solde attendus. Expliquer le contrôle du statut. Aucun changement SPRO.

Classification

L1: Correction opérationnelle individuelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
