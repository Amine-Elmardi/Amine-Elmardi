MM-L1-001 · L1

Document already reversed

Problem

The user attempts to cancel a material document but the system reports that the document was previously reversed.

Error message / number

Document already reversed — Message number not specified.

Root cause

A reversal document already exists for the original posting.

Affected modules

MM

Transactions

MB03, MB51, MIGO

Diagnosis / requirements

  1. Open the original document in MB03
  2. Identify the cancellation reference and check the balance using MB51

Solution

  1. Do not repeat the same cancellation
  2. If the original goods receipt was reversed and a receipt is genuinely required, the source describes creating a new receipt in MIGO

Validation / configuration

Verify that the material document history and balance reflect the intended result. Explain how to check reversal status. No SPRO change.

Classification

L1: Individual operational correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
