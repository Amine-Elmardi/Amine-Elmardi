MM-L2-049 · L2

Supplier advance payment linked to purchase order

Problem

A supplier requires a down payment before the normal invoice settlement process.

Error message / number

Not specified in the source.

Root cause

The source describes a distinct process involving both procurement and financial accounting.

Affected modules

MM / FI

Transactions

ME21N, F-47, F-48, MIRO, F-54

Diagnosis / requirements

  1. Confirm order, approved advance amount or percentage and supplier terms
  2. Review the required FI down-payment process

Solution

  1. Enter advance terms in the documented ME21N payment area
  2. FI processes the request via F-47 and payment via F-48
  3. Handle the advance during invoice processing in MIRO
  4. Use F-54 for final clearing as described

Validation / configuration

Confirm that the advance and final settlement are reconciled with FI. The source refers to FI accounts payable down-payment configuration.

Classification

L2: Functional analysis and coordinated correction.
