MM-L2-024 · L2

Invoice randomly blocked despite matching price and quantity

Problem

Some invoices remain blocked even though no price or quantity discrepancy is identified.

Error message / number

Not specified in the source.

Root cause

The source identifies stochastic blocking configured to select invoices for manual review independently of variances.

Affected modules

MM / FI

Transactions

MRBR, MIR6, MIR4

Diagnosis / requirements

  1. Inspect blocked invoices and reason R in MIR6
  2. Review the configured percentage and threshold in SPRO

Solution

  1. Release reviewed invoices using MRBR if approved
  2. If the business wants to change the selection frequency, the source describes adjusting percentage or threshold as a separate configuration decision

Validation / configuration

Confirm release status and review the intended control with the business. A policy change or disabling the block belongs to L3.

Classification

L2: Functional analysis and coordinated correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
