MM-L2-025 · L2

Champ obligatoire empêchant l’enregistrement de la fiche article

Problème

La fiche ne peut pas être enregistrée car un champ obligatoire manque alors qu’il n’est pas visible.

Message / numéro d’erreur

Field X is mandatory — Numéro de message non indiqué.

Cause racine

La source décrit une sélection de zones exigeant un champ dans une autre vue ou un autre onglet.

Modules concernés

MM

Transactions

MM02, OMSR

Diagnostic / besoins

  1. Noter le nom du champ indiqué
  2. Ouvrir la vue pertinente dans MM02 et identifier le champ

Solution

  1. Renseigner le champ et enregistrer
  2. Si l’obligation est inadaptée, la source cite OMSR pour une modification distincte et approuvée

Validation / paramétrage

Vérifier l’enregistrement. Préparer un guide des champs obligatoires par type article comme le suggère le document.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
