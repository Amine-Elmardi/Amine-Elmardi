MM-090 · L2

Mandatory field prevents material master save

Problem

A user cannot save the material record because a required field is missing, although the field is not visible on the selected screen.

Error message / number

Field X is mandatory — Message number not specified.

Root cause

The source describes field selection requiring a field on a different view or tab.

Affected modules

MM

Transactions

MM02, OMSR

Diagnosis / requirements

  1. Record the field named in the message
  2. Open the relevant view in MM02 and identify the field

Solution

  1. Fill in the required field and save
  2. If the field requirement itself is inappropriate, the source refers to OMSR for a separate approved field-status change

Validation / configuration

Verify the material record saves. Create a quick-reference guide for required fields per material type as suggested in the document.

Classification

L2: Functional analysis and coordinated correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 53, #090. Document-based educational scenario; not independently verified. Production changes require authorization.
