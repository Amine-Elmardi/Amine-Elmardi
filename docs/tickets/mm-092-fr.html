MM-L1-009 · L1

Commande créée pour le mauvais fournisseur

Problème

Une commande a été émise pour un fournisseur différent de celui prévu.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

L’acheteur a saisi le mauvais numéro fournisseur. La sortie a peut-être déjà été transmise.

Modules concernés

MM

Transactions

ME22N, ME9F, ME21N

Diagnostic / besoins

  1. Afficher la commande dans ME22N et vérifier l’existence d’une réception
  2. Déterminer si le fournisseur a reçu la commande

Solution

  1. Sans réception, marquer tous les postes pour suppression dans ME22N
  2. Envoyer la sortie d’annulation décrite dans ME9F et informer formellement le fournisseur si la commande a été transmise
  3. Créer la nouvelle commande dans ME21N pour le bon fournisseur

Validation / paramétrage

Vérifier la commande de remplacement et l’annulation. La source ne décrit pas la correction lorsqu’une réception existe déjà.

Classification

L1: Correction opérationnelle individuelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
