MM-092 · L1

Purchase order created for the wrong supplier

Problem

An order was issued to a supplier other than the intended one.

Error message / number

Not specified in the source.

Root cause

The buyer entered the wrong supplier number. The output may already have been transmitted.

Affected modules

MM

Transactions

ME22N, ME9F, ME21N

Diagnosis / requirements

  1. Display the order in ME22N and check whether a goods receipt exists
  2. Determine whether the supplier received the order

Solution

  1. If no receipt exists, mark all items for deletion in ME22N
  2. Send the documented cancellation output in ME9F and formally notify the supplier if the order was transmitted
  3. Create a new order in ME21N for the correct supplier

Validation / configuration

Verify the replacement order and cancellation communication. The source does not describe a correction path when a receipt already exists.

Classification

L1: Individual operational correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 54, #092. Document-based educational scenario; not independently verified. Production changes require authorization.
