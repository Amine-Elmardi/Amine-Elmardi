MM-093 · L2

Ordre de transfert non confirmé

Problème

La réception et l’ordre de transfert existent, mais le stock reste en transit et ne peut pas être déplacé davantage.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source identifie un ordre créé mais non confirmé dans LT12.

Modules concernés

MM / WM

Transactions

LT0A, LT12, LT15, LT22, LT21, LS26

Diagnostic / besoins

  1. Rechercher les ordres ouverts dans LT22 ou examiner LT21
  2. Déterminer si le transfert réel est terminé ou comporte une erreur

Solution

  1. Confirmer le transfert terminé dans LT12
  2. Si l’ordre est erroné, utiliser l’annulation LT15 décrite et le recréer

Validation / paramétrage

Vérifier le stock cible dans LS26. La confirmation automatique est une option de paramétrage distincte.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 55, #093. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
