MM-L2-055 · L2

Warehouse transfer order remains unconfirmed

Problem

A goods receipt and transfer order exist, but the stock remains in transfer status and cannot be moved onward.

Error message / number

Not specified in the source.

Root cause

The source identifies a transfer order created but not confirmed in LT12.

Affected modules

MM / WM

Transactions

LT0A, LT12, LT15, LT22, LT21, LS26

Diagnosis / requirements

  1. Find open orders in LT22 or inspect the relevant order in LT21
  2. Determine whether the actual transfer has been completed or the order contains errors

Solution

  1. Confirm the completed transfer order in LT12
  2. If the order is erroneous, use the documented LT15 cancellation and recreate it

Validation / configuration

Verify target bin stock in LS26. The source describes automatic confirmation as a separate configuration option.

Classification

L2: Functional analysis and coordinated correction.
