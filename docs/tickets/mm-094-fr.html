MM-L3-010 · L3

La version modifiée de la commande n’est pas envoyée au fournisseur

Problème

Après modification du prix ou de la quantité, le fournisseur dispose toujours de la commande initiale.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source attribue cela à la gestion des versions et aux messages de modification non paramétrés.

Modules concernés

MM

Transactions

ME22N, MN04, ME9F

Diagnostic / besoins

  1. Examiner le type de document et le suivi des changements
  2. Contrôler le schéma et les conditions de messages

Solution

  1. Activer la gestion des versions décrite dans SPRO
  2. Configurer le message nommé ÄNDERUNG et les conditions MN04
  3. Tester une modification dans ME22N et transmettre via ME9F

Validation / paramétrage

Confirmer la version et la réception de la commande actualisée. Le cas concerne le paramétrage du type de document.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
