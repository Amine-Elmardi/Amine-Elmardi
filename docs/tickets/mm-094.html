MM-094 · L3

Changed purchase order version is not sent to supplier

Problem

After a price or quantity change the supplier still has the original purchase order.

Error message / number

Not specified in the source.

Root cause

The source attributes this to missing version management and change-output configuration for the order type.

Affected modules

MM

Transactions

ME22N, MN04, ME9F

Diagnosis / requirements

  1. Review the affected order type and current change tracking
  2. Inspect the output schema and condition records

Solution

  1. Activate the documented version management settings in SPRO
  2. Configure the change message type described as ÄNDERUNG and maintain MN04 conditions
  3. Perform a test change in ME22N and transmit through ME9F

Validation / configuration

Confirm version creation and receipt of the updated order by the supplier. The change affects document type configuration.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 55, #094. Document-based educational scenario; not independently verified. Production changes require authorization.
