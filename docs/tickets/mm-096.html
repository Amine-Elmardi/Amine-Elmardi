MM-L3-031 · L3

Restrict purchase order creation to assigned plants

Problem

A new access policy requires buyers to create purchase orders only for their assigned plants.

Error message / number

Not specified in the source.

Root cause

The source identifies purchasing authorization objects that are not restricted to the intended organizational scope.

Affected modules

MM / Basis / HR

Transactions

PFCG, SU01, SU53, ME21N

Diagnosis / requirements

  1. Define approved plant groups and roles
  2. Review M_BEST_WRK, M_BEST_EKO and M_BEST_BSA with authorization administrators

Solution

  1. Restrict plant values in the appropriate PFCG roles and create separate roles if needed
  2. Assign approved roles via SU01 or the described mass assignment
  3. Test an authorized plant and an unauthorized plant in ME21N

Validation / configuration

Verify intended access and use SU53 to analyze authorization failures. Changes are handled by the responsible authorization team.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
