MM-097 · L3

Livraison entrante manquante après sortie sur transfert

Problème

La division expéditrice a comptabilisé la sortie, mais la division destinataire ne trouve pas la livraison entrante attendue.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

Le document évoque une intégration expédition incomplète ou des réglages de livraison entrante manquants.

Modules concernés

MM / Shipping

Transactions

VL02N, VL31N, VL32N, MIGO, OMGN

Diagnostic / besoins

  1. Vérifier sortie et livraison dans VL02N
  2. Contrôler l’existence de la livraison entrante via VL32N selon la source

Solution

  1. Si absente, utiliser la création manuelle VL31N décrite avec référence au transfert
  2. Examiner OMGN et l’indicateur de livraison entrante obligatoire
  3. Si requis, maintenir l’indicateur via le paramétrage approuvé

Validation / paramétrage

Comptabiliser la réception prévue dans MIGO avec référence de livraison et vérifier le processus. La branche paramétrage justifie L3.

Classification

L3: Paramétrage ou évolution.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 57, #097. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
