MM-L3-020 · L3

Inbound delivery missing for stock transfer after goods issue

Problem

The supplying plant posted goods issue, but the receiving plant cannot locate the expected inbound delivery.

Error message / number

Not specified in the source.

Root cause

The document attributes the issue to incomplete shipping integration or inbound-delivery settings for the STO.

Affected modules

MM / Shipping

Transactions

VL02N, VL31N, VL32N, MIGO, OMGN

Diagnosis / requirements

  1. Check outbound delivery and goods issue in VL02N
  2. Check whether the inbound delivery exists using the VL32N route described

Solution

  1. If missing, use the documented manual creation option in VL31N with STO reference
  2. Review plant shipping data in OMGN and the inbound-delivery-required indicator
  3. If required by the process, maintain the indicator through the approved configuration

Validation / configuration

Post the intended receipt in MIGO with inbound-delivery reference and verify the process. The configuration branch motivates L3.

Classification

L3: Configuration or enhancement.
