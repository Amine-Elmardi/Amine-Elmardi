MM-098 · L4

MM master data migration and cutover to S/4HANA

Problem

An organization plans to move from ECC to S/4HANA, covering materials, suppliers, open procurement documents and purchasing records.

Error message / number

Not specified in the source.

Root cause

The source describes changed data models and the need for coordinated data cleansing and migration.

Affected modules

MM / S/4HANA

Transactions

SPDD, SPAU, FLBP_MASS_CONVERT, LTMOM, MM01, XK02

Diagnosis / requirements

  1. Assess custom objects using SPDD/SPAU and the referenced readiness check
  2. Identify material, supplier, condition, source-list and open-document data in scope

Solution

  1. Clean obsolete material records and correct units and required fields
  2. Convert supplier data to Business Partner using the documented approach and cleanse purchasing records
  3. Use the source's LTMOM or BODS migration approach for open documents
  4. Freeze transactions, execute the final data load and validate before cutover

Validation / configuration

Perform go-live and hypercare. The document contains differing duration estimates, so no fixed project duration is asserted.

Classification

L4: Multi-stage project.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 57–58, #098. Document-based educational scenario; not independently verified. Production changes require authorization.
