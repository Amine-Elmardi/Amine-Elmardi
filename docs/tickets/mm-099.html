MM-099 · L3

Contract monitoring dashboard with expiry and utilization alerts

Problem

Management wants advance warnings for contracts approaching expiration or utilization limits.

Error message / number

Not specified in the source.

Root cause

The source describes missed renewal dates without consolidated proactive monitoring.

Affected modules

MM / ABAP

Transactions

ME33K, ME3M, SE38, SM36

Diagnosis / requirements

  1. Define 30/60/90-day expiry intervals and utilization criteria with procurement
  2. Review contract document types and the EKKO/EKPO fields named in the source

Solution

  1. Develop the SE38 report for contracts with MK or WK as source examples
  2. Calculate remaining days and utilization using the documented approach and validate against contract records
  3. Present traffic-light ALV and email alerts, schedule weekly execution via SM36

Validation / configuration

Check alert recipients and contract values. The source mentions an optional Fiori tile.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 58, #099. Document-based educational scenario; not independently verified. Production changes require authorization.
