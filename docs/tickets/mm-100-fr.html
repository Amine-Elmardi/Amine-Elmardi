MM-L4-001 · L4

Création automatique de commandes via interface IDoc externe

Problème

Les demandes approuvées d’un portail externe doivent créer des commandes SAP sans ressaisie.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source décrit retards et erreurs liés à la réplication manuelle.

Modules concernés

MM / ABAP / ALE

Transactions

WE20, WE21, WE57, BD54, WE05, WE07, BD87

Diagnostic / besoins

  1. Définir type de message et correspondance champs/segments IDoc
  2. Définir traitement entrant et gestion des erreurs

Solution

  1. Configurer système logique BD54, profil WE20 et affectation WE57 selon le document
  2. Développer le module entrant avec BAPI_PO_CREATE1 cité
  3. Mettre en œuvre le traitement des erreurs statut 51 et la correction
  4. Tester avec des données représentatives avant mise en production

Validation / paramétrage

Surveiller via WE05/WE07. La source inclut BD87 et WE21 dans le périmètre.

Classification

L4: Projet en plusieurs étapes.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
