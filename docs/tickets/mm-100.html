MM-L4-001 · L4

Automated purchase order creation through external IDoc interface

Problem

Approved procurement requests from an external portal must create SAP purchase orders without repeated manual entry.

Error message / number

Not specified in the source.

Root cause

The source describes delays and data entry errors caused by manual replication.

Affected modules

MM / ABAP / ALE

Transactions

WE20, WE21, WE57, BD54, WE05, WE07, BD87

Diagnosis / requirements

  1. Define message type and field mapping between portal and IDoc segments
  2. Specify inbound processing and error handling requirements

Solution

  1. Configure logical system BD54, partner profile WE20 and message-to-function assignment WE57 as described
  2. Develop the inbound function module using the named BAPI_PO_CREATE1
  3. Implement status 51 error handling and correction workflow
  4. Test with representative portal data before release

Validation / configuration

Monitor productive processing via WE05/WE07. The source lists BD87 and WE21 in the interface scope.

Classification

L4: Multi-stage project.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
