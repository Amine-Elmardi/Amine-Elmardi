MM-L1-005 · L1

Article marqué pour suppression inutilisable

Problème

L’utilisateur ne peut pas utiliser un article pour une nouvelle commande ou réception. La source décrit un message lié à la suppression.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

L’article est marqué pour suppression au niveau division ou mandant.

Modules concernés

MM

Transactions

MM06, MM02, ME21N

Diagnostic / besoins

  1. Identifier article et niveau organisationnel
  2. Clarifier si la suppression est volontaire

Solution

  1. Si l’indicateur est erroné et la correction autorisée, le retirer via MM06 ou MM02 selon la source
  2. Si volontaire, fournir l’article de remplacement approprié

Validation / paramétrage

Retester ME21N. Aucun paramétrage décrit.

Classification

L1: Correction opérationnelle individuelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
