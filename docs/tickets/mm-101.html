MM-101 · L1

Material marked for deletion cannot be used

Problem

A user cannot use an existing material for a new purchase order or goods receipt, and the source describes a deletion-flag warning or error.

Error message / number

Not specified in the source.

Root cause

The material has a deletion indicator at plant or client level.

Affected modules

MM

Transactions

MM06, MM02, ME21N

Diagnosis / requirements

  1. Identify the material and organizational level
  2. Clarify whether the deletion indicator is intentional

Solution

  1. If incorrectly marked and authorized, remove the flag using the documented MM06 or MM02 route
  2. If deletion is intended, provide the correct alternative material

Validation / configuration

Retest order creation in ME21N. No configuration change is described.

Classification

L1: Individual operational correction.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 59, #101. Document-based educational scenario; not independently verified. Production changes require authorization.
