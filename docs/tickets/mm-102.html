MM-L2-005 · L2

Consignment liability not recognized before withdrawal

Problem

Goods are received against a consignment purchase order, but the expected supplier liability is not visible at initial receipt.

Error message / number

Not specified in the source.

Root cause

The source distinguishes physical consignment receipt from the later withdrawal that triggers liability.

Affected modules

MM / FI

Transactions

ME21N, ME23N, MIGO, MB1B (411), MMBE, MIRO

Diagnosis / requirements

  1. Verify item category K in ME23N
  2. Review receipt movement 101 K and special stock K in MMBE
  3. Determine whether withdrawal from consignment stock has occurred

Solution

  1. For the documented withdrawal scenario, the source describes movement 411 in MB1B
  2. Review the resulting financial posting and the subsequent invoice step described in MIRO with FI

Validation / configuration

Monitor special stock K in MMBE and reconcile the liability with FI. The source references OBYC key KON. The accounting and invoice procedure is not independently verified.

Classification

L2: Functional analysis and coordinated correction.
