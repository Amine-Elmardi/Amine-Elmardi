MM-103 · L2

Réception comptabilisée dans la mauvaise division

Problème

L’article a été reçu physiquement dans la division B mais enregistré dans A.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source attribue l’écart à une mauvaise sélection de division dans MIGO.

Modules concernés

MM

Transactions

MIGO, MMBE, MB51

Diagnostic / besoins

  1. Identifier document initial et divisions
  2. Déterminer si des mouvements ultérieurs existent

Solution

  1. En présence de mouvements ultérieurs, coordonner l’ordre des corrections selon la source
  2. Annuler le document erroné dans MIGO
  3. Créer la réception correcte avec référence de commande pour B

Validation / paramétrage

Contrôler les deux divisions dans MMBE et l’historique MB51. Former les utilisateurs au contrôle de division.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 60, #103. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
