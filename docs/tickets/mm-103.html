MM-L2-015 · L2

Goods receipt posted to wrong plant

Problem

The material was physically received at plant B but the receipt was recorded for plant A.

Error message / number

Not specified in the source.

Root cause

The source attributes the discrepancy to incorrect plant selection in MIGO.

Affected modules

MM

Transactions

MIGO, MMBE, MB51

Diagnosis / requirements

  1. Identify original material document and both plants
  2. Determine whether subsequent movements have already been posted

Solution

  1. If downstream postings exist, coordinate the correction sequence before acting as instructed by the source
  2. Cancel the incorrect material document in MIGO
  3. Create the correct goods receipt with purchase order reference for plant B

Validation / configuration

Check both plants in MMBE and document history in MB51. Train users to verify plant selection before posting.

Classification

L2: Functional analysis and coordinated correction.
