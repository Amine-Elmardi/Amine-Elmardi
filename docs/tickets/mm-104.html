MM-L2-048 · L2

Subsequent debit for additional supplier freight costs

Problem

A supplier sends an additional debit note after settlement of the original invoice.

Error message / number

Not specified in the source.

Root cause

The source describes freight or surcharge amounts not included in the original invoice.

Affected modules

MM / FI

Transactions

MIRO, MIR4, MIR6

Diagnosis / requirements

  1. Identify original purchase order and the additional charge
  2. Review the existing invoice and material price control with FI

Solution

  1. Select Subsequent Debit in MIRO
  2. Enter the purchase order reference and approved additional amount
  3. Post the documented transaction

Validation / configuration

Verify accounting in MIR4. The source distinguishes possible moving-average-price effects from price differences for standard price materials. The detailed scenario covers debit, not credit.

Classification

L2: Functional analysis and coordinated correction.
