MM-L1-012 · L1

Requisition quantity change does not update existing purchase order

Problem

The requester changes a purchase requisition after a purchase order has already been created, but the order quantity remains unchanged.

Error message / number

Not specified in the source.

Root cause

The source describes the requisition and order as independent documents after conversion.

Affected modules

MM

Transactions

ME52N, ME22N, ME23N

Diagnosis / requirements

  1. Compare the changed requisition with the existing purchase order
  2. Clarify whether the order quantity itself needs adjustment

Solution

  1. Explain that the requisition change does not automatically update the order
  2. If required, have the buyer adjust item quantity directly in ME22N and save
  3. Resend order output if supplier communication is needed

Validation / configuration

Verify quantity in ME23N. The source describes the requisition status Ordered as expected. No SPRO change.

Classification

L1: Individual operational correction.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
