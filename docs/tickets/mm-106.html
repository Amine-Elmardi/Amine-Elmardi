MM-106 · L3

Automate month-end GR/IR clearing with exceptions

Problem

Finance wants scheduled month-end clearing and an exception report for items requiring manual intervention.

Error message / number

Not specified in the source.

Root cause

The source describes repetitive, time-consuming manual MR11 execution.

Affected modules

MM / FI / ABAP

Transactions

MR11, SM36, SM37

Diagnosis / requirements

  1. Define company code, account and date selection with finance
  2. Agree job timing and exception-report recipients

Solution

  1. Create the documented MR11 variant and schedule the named program RMMR1M01 in SM36
  2. Develop an ABAP exception report for items not cleared and send to the accounts payable group
  3. Process confirmed exceptions using the documented manual MR11 or FI route

Validation / configuration

Monitor job execution via SM37 and reconcile results with FI. The source describes scheduling on the last working day.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 61–62, #106. Document-based educational scenario; not independently verified. Production changes require authorization.
