MM-107 · L3

Import purchase order does not capture planned landed costs

Problem

The material receipt reflects only the basic price although freight, customs duty and insurance should be included in the import cost.

Error message / number

Not specified in the source.

Root cause

The source identifies planned delivery cost conditions missing from the purchasing calculation schema.

Affected modules

MM / FI

Transactions

ME21N, ME22N, MIGO, MIRO, OBYC

Diagnosis / requirements

  1. Review import order conditions and required landed-cost categories
  2. Inspect the calculation schema and OBYC account assignment with FI

Solution

  1. Configure the documented planned-delivery-cost condition types, with ZFR1, ZCD1 and ZINS as custom examples
  2. Maintain approved planned costs in the purchase order and review FRE account assignment in OBYC
  3. Test goods receipt in MIGO and freight or customs invoice using planned delivery costs in MIRO

Validation / configuration

Verify the resulting cost and valuation with FI. The source describes an effect on moving average price, not a universal result for all valuation methods.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 62, #107. Document-based educational scenario; not independently verified. Production changes require authorization.
