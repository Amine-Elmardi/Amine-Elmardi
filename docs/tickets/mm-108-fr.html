MM-108 · L2

Numéro de lot non saisissable à la réception

Problème

Le champ lot dans MIGO est désactivé ou absent alors que le magasin doit saisir un lot.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source évoque une activation article, une classification ou un réglage division manquant.

Modules concernés

MM

Transactions

MM02, MIGO, MSC3N, MSC1N

Diagnostic / besoins

  1. Examiner l’indicateur et la classification dans MM02
  2. Vérifier l’activation pertinente par division

Solution

  1. Si les réglages article manquent, maintenir l’indicateur ou la classe décrite
  2. Si activation par division requise, transmettre le paramétrage SPRO décrit comme changement L3 distinct
  3. Relancer la réception et attribuer le lot selon la numérotation paramétrée

Validation / paramétrage

Contrôler le lot dans MSC3N. L2 couvre diagnostic fonctionnel et données article.

Classification

L2: Analyse fonctionnelle et correction coordonnée.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 63, #108. Cas pédagogique fondé sur le document ; non vérifié indépendamment. Toute modification productive nécessite une autorisation.
