MM-L2-002 · L2

Batch number cannot be entered at goods receipt

Problem

The batch field in MIGO is disabled or missing when warehouse staff need to record a batch.

Error message / number

Not specified in the source.

Root cause

The source identifies missing batch activation for the material, classification or plant-level batch settings.

Affected modules

MM

Transactions

MM02, MIGO, MSC3N, MSC1N

Diagnosis / requirements

  1. Inspect the batch management indicator and classification in MM02
  2. Determine whether the relevant plant-level setting is active

Solution

  1. If material settings are missing, maintain the documented batch indicator or class
  2. If activation is required at plant level, escalate the documented SPRO configuration as a separate L3 change
  3. Retry the receipt and assign a batch according to the configured numbering approach

Validation / configuration

Verify the batch in MSC3N. L2 covers functional diagnosis and material maintenance.

Classification

L2: Functional analysis and coordinated correction.
