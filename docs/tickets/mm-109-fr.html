MM-L3-022 · L3

Facturation intersociétés absente après transfert entre sociétés

Problème

Un transfert entre sociétés a atteint la sortie, mais le document de facturation intersociétés attendu manque chez l’expéditeur.

Message / numéro d’erreur

Non indiqué dans la source.

Cause racine

La source cite des réglages de facturation STO, de contrôle de copie ou de pertinence incomplets.

Modules concernés

MM / SD / FI

Transactions

VL02N, VF01, OMGN, VTFF, MIGO

Diagnostic / besoins

  1. Vérifier transfert, livraison et sortie dans VL02N
  2. Tenter la facturation dans VF01 et examiner le résultat
  3. Examiner VTFF, OMGN et la condition PI01 avec SD

Solution

  1. Corriger le paramétrage manquant confirmé avec l’équipe responsable selon les références
  2. Relancer la facturation décrite
  3. La société destinataire comptabilise la réception avec référence de livraison dans MIGO

Validation / paramétrage

Vérifier facture intersociétés et réception pour les deux sociétés. Le paramétrage et l’intégration justifient L3.

Classification

L3: Paramétrage ou évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans un système SAP. Toute modification en production nécessite une autorisation.
