MM-109 · L3

Intercompany billing missing after cross-company stock transfer

Problem

A cross-company stock transport order has proceeded to goods issue, but the supplying company has no expected intercompany billing document.

Error message / number

Not specified in the source.

Root cause

The source attributes the failure to incomplete STO billing settings or copying control and billing relevance.

Affected modules

MM / SD / FI

Transactions

VL02N, VF01, OMGN, VTFF, MIGO

Diagnosis / requirements

  1. Verify the STO, outbound delivery and goods issue in VL02N
  2. Attempt billing in VF01 and inspect the result
  3. Review the described VTFF copying control, OMGN and PI01 pricing condition with SD

Solution

  1. Correct confirmed missing billing configuration with the responsible team using the source references
  2. Repeat the documented billing process
  3. Receiving company records the goods receipt with inbound delivery reference in MIGO

Validation / configuration

Verify the intercompany document and corresponding receipt with both company codes. Configuration and cross-module coordination justify L3.

Classification

L3: Configuration or enhancement.

Source

Kandala Srinivasulu, SAP MM Support Tickets, PDF p. 63, #109. Document-based educational scenario; not independently verified. Production changes require authorization.
