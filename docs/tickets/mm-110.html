MM-L3-028 · L3

Procurement spend analysis by category, supplier and plant

Problem

Procurement leadership needs monthly spending trends and a comparison with the prior year in one consolidated view.

Error message / number

Not specified in the source.

Root cause

The source describes missing consolidated reporting across category hierarchy, supplier ranking and annual comparison.

Affected modules

MM / Analytics / ABAP

Transactions

ME2M, ME2N, ME80FN, SE38

Diagnosis / requirements

  1. Define spending measures and category hierarchy
  2. Review EKKO, EKPO and EKBE sources and the named T023T mapping

Solution

  1. Develop the described ALV report in SE38 with material group spend, top ten suppliers, plant breakdown and year comparison
  2. Provide drill-down from category to group, supplier and purchase order
  3. Enable Excel export and consider the optional SAP Analytics Cloud visualization

Validation / configuration

Validate totals and drill-down against the agreed purchasing data. The source references material group configuration T023.

Classification

L3: Configuration or enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Production changes require authorization.
