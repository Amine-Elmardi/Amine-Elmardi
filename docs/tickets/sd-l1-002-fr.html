SD-L1-002 · L1

Client absent de la commande

Problème

VA01 refuse le donneur d’ordre.

Message / numéro d’erreur

Customer does not exist — Message décrit; numéro non indiqué.

Cause racine

Fiche ou extension commerciale absente.

Modules concernés

SD-MD

Transactions

VA01, XD03, XD01, VD01, BP

Diagnostic

  1. Examiner XD03 et données organisationnelles
  2. Contrôler groupe et partenaires.

Solution

  1. Créer ou étendre le client approuvé via XD01/VD01 ou BP
  2. Maintenir les partenaires.

Validation / paramétrage

Retester VA01 dans le domaine prévu.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
