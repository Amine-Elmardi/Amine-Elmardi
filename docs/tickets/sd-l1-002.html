SD-L1-002 · L1

Customer missing in order

Problem

VA01 rejects the sold-to party.

Error message / number

Customer does not exist — Reported text; number not provided.

Root cause

Customer or sales-area extension is absent.

Affected modules

SD-MD

Transactions

VA01, XD03, XD01, VD01, BP

Diagnosis

  1. Inspect XD03 and organizational data
  2. Check account group and partner functions.

Solution

  1. Create or extend approved customer via XD01/VD01 or BP
  2. Maintain required partners.

Validation / configuration

Retry VA01 for the intended sales area.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
