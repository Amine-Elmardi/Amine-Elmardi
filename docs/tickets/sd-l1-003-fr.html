SD-L1-003 · L1

Incomplétude bloquant traitement

Problème

Commande ne passe pas en livraison ou facture.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Champs obligatoires manquants.

Modules concernés

SD Order

Transactions

VA02, VA03, OVA2, V.02

Diagnostic

  1. Ouvrir journal
  2. Identifier référence, date, Incoterms ou autre champ.

Solution

  1. Compléter données vérifiées
  2. Transmettre exigence contestée sans contourner le contrôle.

Validation / paramétrage

Vérifier complétude et éligibilité.

Classification

L1: Support opérationnel.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
