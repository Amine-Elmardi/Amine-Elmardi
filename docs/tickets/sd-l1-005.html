SD-L1-005 · L1

Wrong sales area defaults

Problem

VA01 proposes incorrect organizational values.

Error message / number

Exact message and number not provided.

Root cause

User defaults VKO, VTW or VSP are incorrect.

Affected modules

SD / User Settings

Transactions

SU3, SU01, VA01

Diagnosis

  1. Check SU3 parameters and authorized organizational values.

Solution

  1. Set approved defaults in SU3 or user administration.

Validation / configuration

Reopen VA01 and check defaults.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
