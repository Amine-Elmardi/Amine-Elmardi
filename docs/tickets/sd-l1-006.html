SD-L1-006 · L1

Statistical cash discount SKTO has no separate FI line

Problem

User expects a separate discount posting at billing.

Error message / number

Exact message and number not provided.

Root cause

In the described statistical setup, actual cash discount is processed at payment according to terms.

Affected modules

SD / FI-AR

Transactions

V/06, V/08, VF03, OBB8, FBL5N, F-28

Diagnosis

  1. Review SKTO statistical treatment in pricing and payment terms in OBB8
  2. Inspect invoice FI document.

Solution

  1. Explain intended behavior
  2. Coordinate FI review of actual early-payment clearing if incorrect.

Validation / configuration

Verify correct invoice value and discount at payment, where applicable.

Classification

L1: Operational support.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
