SD-L2-001 · L2

ATP confirme seulement une quantité partielle

Problème

Client attend totalité mais confirmation inférieure.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Offre insuffisante à la date demandée.

Modules concernés

SD / ATP / MM / PP

Transactions

CO09, MD04, V_V2, CO06, VA02

Diagnostic

  1. Examiner CO09 et réceptions MD04
  2. Identifier besoins concurrents.

Solution

  1. Coordonner allocation ou replanification approuvée via V_V2/CO06
  2. Demander approvisionnement si nécessaire.

Validation / paramétrage

Vérifier confirmation et communiquer date réaliste.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
