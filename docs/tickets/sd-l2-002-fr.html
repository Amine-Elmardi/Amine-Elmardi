SD-L2-002 · L2

Échéance de facturation absente

Problème

Échéance due non proposée.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Statut, type ou pertinence du plan incorrect.

Modules concernés

SD Billing

Transactions

VA02, VA03, VOV7, VF04, VF01, OVBI

Diagnostic

  1. Examiner dates/statut et sélection VF04
  2. Contrôler VOV7.

Solution

  1. Corriger données approuvées ou transmettre défaut
  2. Facturer échéance éligible.

Validation / paramétrage

Vérifier statut facturé et facture.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
