SD-L2-004 · L2

Stock de consignation absent après remplissage

Problème

Stock spécial W non visible.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Mouvement ou affectation client peut être incorrect.

Modules concernés

SD / MM Consignment

Transactions

MMBE, MB03, MIGO, VA01, VL01N

Diagnostic

  1. Examiner pièce mouvement 631 et client
  2. Contrôler MMBE.

Solution

  1. Coordonner annulation via livraison d’origine et correction approuvée si erreur confirmée.

Validation / paramétrage

Vérifier stock du bon client.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
