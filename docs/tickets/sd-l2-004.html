SD-L2-004 · L2

Consignment stock missing after fill-up

Problem

Customer special stock W is not visible.

Error message / number

Exact message and number not provided.

Root cause

Movement type or customer assignment may be wrong.

Affected modules

SD / MM Consignment

Transactions

MMBE, MB03, MIGO, VA01, VL01N

Diagnosis

  1. Inspect material document for movement 631 and customer
  2. Check MMBE special stock.

Solution

  1. Coordinate approved reversal via originating delivery and correction only if error confirmed.

Validation / configuration

Verify stock at correct customer.
