SD-L2-005 · L2

Credit limit blocks order

Problem

Order cannot proceed to delivery.

Error message / number

Credit limit exceeded — Reported text; number not provided.

Root cause

Credit exposure exceeds approved limit.

Affected modules

SD / Credit

Transactions

FD32, FD33, VKM3, VKM1, VA01

Diagnosis

  1. Review customer credit exposure and limit
  2. Consult credit manager.

Solution

  1. Release only with approval via applicable VKM3 process
  2. Request payment or approved limit change if needed.

Validation / configuration

Verify release and exposure.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
