SD-L2-006 · L2

Prix spécifique client non repris

Problème

Tarif générique remplace prix convenu.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Condition ou priorité d’accès incorrecte.

Modules concernés

SD Pricing

Transactions

VD53, VK11, VK13, V/07, VA02

Diagnostic

  1. Examiner VD53 et condition VK13
  2. Contrôler V/07.

Solution

  1. Maintenir prix spécial approuvé et validité
  2. Transmettre changement de séquence
  3. Recalculer.

Validation / paramétrage

Tester prix sur nouvelle commande.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
