SD-L2-006 · L2

Customer-specific price not selected

Problem

Generic price replaces agreed customer-material price.

Error message / number

Exact message and number not provided.

Root cause

Condition record or access priority is incorrect.

Affected modules

SD Pricing

Transactions

VD53, VK11, VK13, V/07, VA02

Diagnosis

  1. Check customer-material context in VD53 and actual condition in VK13
  2. Inspect V/07.

Solution

  1. Maintain approved special condition and validity
  2. Escalate access-sequence changes
  3. Reprice.

Validation / configuration

Test agreed price on new order.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
