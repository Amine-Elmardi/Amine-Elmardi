SD-L2-007 · L2

Free goods missing at qualifying quantity

Problem

Expected bonus item does not appear.

Error message / number

Exact message and number not provided.

Root cause

Record, validity or determination incomplete.

Affected modules

SD Free Goods

Transactions

VBN1, VBN2, VBN3, VOV8, VA01

Diagnosis

  1. Check VBN3 minimum/free quantities and calculation rule
  2. Review activation.

Solution

  1. Maintain approved record via VBN1/VBN2
  2. Escalate missing procedure.

Validation / configuration

Test below and above threshold.
