SD-L2-009 · L2

Invoice output RD00 absent

Problem

No invoice print or email is generated.

Error message / number

Exact message and number not provided.

Root cause

Condition, dispatch time, printer or procedure is incorrect.

Affected modules

SD Billing / Output

Transactions

VF01, VF02, VV31, NACE, VF31

Diagnosis

  1. Inspect output status in VF02
  2. Review classic NACE V3 and condition settings.

Solution

  1. Maintain approved VV31 record or retry authorized output
  2. Escalate shared configuration defect.

Validation / configuration

Verify status and recipient without duplicate dispatch.

Classification

L2: Functional analysis.
