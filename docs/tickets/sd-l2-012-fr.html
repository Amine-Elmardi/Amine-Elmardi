SD-L2-012 · L2

MWST absente

Problème

Taxe attendue non calculée.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Classification, condition ou procédure incomplète.

Modules concernés

SD / FI Tax

Transactions

VK11, VK13, XD02, MM02, OBBG, VA02

Diagnostic

  1. Examiner classifications et accès VK13
  2. Confirmer traitement avec FI.

Solution

  1. Maintenir condition approuvée ou classification confirmée
  2. Transmettre défaut de procédure
  3. Recalculer.

Validation / paramétrage

Vérifier base, taux et montant.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
