SD-L2-012 · L2

MWST missing

Problem

Expected sales tax is not calculated.

Error message / number

Exact message and number not provided.

Root cause

Tax classification, condition or procedure is incomplete.

Affected modules

SD / FI Tax

Transactions

VK11, VK13, XD02, MM02, OBBG, VA02

Diagnosis

  1. Check customer/material tax classification and VK13 access
  2. Confirm tax treatment with FI.

Solution

  1. Maintain approved condition or verified classifications
  2. Escalate procedure defects
  3. Reprice.

Validation / configuration

Check tax base, rate and amount.

Classification

L2: Functional analysis.
