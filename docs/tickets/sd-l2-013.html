SD-L2-013 · L2

Order remains in process

Problem

Overall status remains incomplete.

Error message / number

Being Processed — Reported text; number not provided.

Root cause

Delivery, goods issue or billing is outstanding.

Affected modules

SD / LE / FI

Transactions

VA03, VL01N, VL02N, VF01, VF04

Diagnosis

  1. Inspect VA03 header/item status and document flow
  2. Identify unfinished process.

Solution

  1. Coordinate authorized delivery, actual picking/goods issue or billing when due.

Validation / configuration

Check document flow and status.

L2: Functional analysis.
