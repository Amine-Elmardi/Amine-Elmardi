SD-L2-015 · L2

PR00 missing in order

Problem

Price is blank or zero.

Error message / number

Exact message and number not provided.

Root cause

Condition missing, expired or access key differs.

Affected modules

SD Pricing

Transactions

VK11, VK12, VK13, OVKK, VA02

Diagnosis

  1. Check pricing analysis, VK13 validity at pricing date and OVKK determination.

Solution

  1. Maintain approved record in VK11/VK12
  2. Reprice using approved pricing type in VA02.

Validation / configuration

Check price and discounts.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
