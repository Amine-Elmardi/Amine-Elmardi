SD-L2-016 · L2

Facture pro forma indisponible

Problème

Pro forma export impossible à créer.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

F5/F8, copie ou pertinence incomplète.

Modules concernés

SD Billing / Export

Transactions

VF01, VF02, VOV7, VTFA, VTFL

Diagnostic

  1. Identifier F5 commande ou F8 livraison
  2. Examiner pertinence et copie.

Solution

  1. Créer pro forma éligible VF01
  2. Transmettre défaut
  3. Traiter sortie autorisée.

Validation / paramétrage

Vérifier pro forma sans pièce FI attendue.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
