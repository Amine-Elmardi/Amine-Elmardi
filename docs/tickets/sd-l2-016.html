SD-L2-016 · L2

Proforma invoice unavailable

Problem

Export proforma cannot be created.

Error message / number

Exact message and number not provided.

Root cause

F5/F8 type, copy control or item relevance incomplete.

Affected modules

SD Billing / Export

Transactions

VF01, VF02, VOV7, VTFA, VTFL

Diagnosis

  1. Identify required order-based F5 or delivery-based F8
  2. Inspect relevance and copy control.

Solution

  1. Create eligible proforma in VF01
  2. Escalate configuration issue
  3. Process authorized output.

Validation / configuration

Verify proforma, with no FI posting expected.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
