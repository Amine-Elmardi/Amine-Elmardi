SD-L2-017 · L2

Règlement de remise incorrect

Problème

Provision ou avoir diffère de l’accord.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Taux, barèmes, validité ou base de chiffre d’affaires incohérents.

Modules concernés

SD / FI Rebates

Transactions

VBO1, VBO2, VBO3, VF01

Diagnostic

  1. Examiner accord et base VBO2/VBO3
  2. Comparer taux et volume.

Solution

  1. Corriger accord approuvé
  2. Régler après revue
  3. Traiter avoir autorisé.

Validation / paramétrage

Rapprocher règlement et provision; confirmer processus classique.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
