SD-L2-017 · L2

Rebate settlement incorrect

Problem

Accrual or credit differs from agreement.

Error message / number

Exact message and number not provided.

Root cause

Rates, scales, validity or turnover basis inconsistent.

Affected modules

SD / FI Rebates

Transactions

VBO1, VBO2, VBO3, VF01

Diagnosis

  1. Inspect agreement and condition basis in VBO2/VBO3
  2. Compare rates and turnover.

Solution

  1. Correct approved agreement data
  2. Settle only after review
  3. Process approved credit memo.

Validation / configuration

Reconcile settlement and accrual; confirm classic rebate applicability.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
