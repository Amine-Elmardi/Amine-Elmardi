SD-L2-018 · L2

Sofortauftrag ohne Sofortlieferung

Problem

Speichern erzeugt keine Lieferung.

Fehlermeldung / Nummer

Genauer Meldungstext und Nummer nicht angegeben.

Ursache

Sofortlieferkennzeichen oder Versandvoraussetzungen falsch.

Betroffene Module

SD / LE

Transaktionen

VOV8, VL01N, VL10A, VL03N, SLG1

Analyse

  1. VOV8 und Versanddaten prüfen
  2. SLG1-Protokoll kontrollieren.

Lösung

  1. Zulässige Lieferung genehmigt manuell anlegen
  2. Bestätigten Customizingfehler weitergeben.

Erfolgskontrolle / Customizing

Lieferung und Belegfluss prüfen.

Einordnung

L2: Funktionale Analyse.

Aufbereiteter Lernfall auf Basis von Schulungsmaterial; nicht unabhängig im SAP-System validiert. Transaktionen sind versionsabhängig. Produktivänderungen nur mit Freigabe.
