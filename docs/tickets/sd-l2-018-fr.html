SD-L2-018 · L2

Commande urgente sans livraison immédiate

Problème

Sauvegarde sans livraison.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Indicateur immédiat ou prérequis incorrect.

Modules concernés

SD / LE

Transactions

VOV8, VL01N, VL10A, VL03N, SLG1

Diagnostic

  1. Examiner VOV8 et données expédition
  2. Contrôler SLG1.

Solution

  1. Créer livraison éligible manuellement après accord
  2. Transmettre défaut confirmé.

Validation / paramétrage

Vérifier livraison et flux.

Classification

L2: Analyse fonctionnelle.
