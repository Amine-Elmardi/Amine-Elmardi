SD-L2-018 · L2

Rush order has no immediate delivery

Problem

Saving rush order produces no delivery.

Error message / number

Exact message and number not provided.

Root cause

Immediate delivery indicator or shipping prerequisites incorrect.

Affected modules

SD / LE

Transactions

VOV8, VL01N, VL10A, VL03N, SLG1

Diagnosis

  1. Inspect VOV8 and shipping data
  2. Review SLG1 log.

Solution

  1. Create eligible delivery manually if approved
  2. Escalate confirmed configuration defect.

Validation / configuration

Verify delivery and document flow.

Classification

L2: Functional analysis.
