SD-L2-019 · L2

Fractionnement inattendu des livraisons

Problème

Une commande produit plusieurs livraisons.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Point, itinéraire, dates ou critères partiels diffèrent.

Modules concernés

SD / LE

Transactions

VL01N, VL04, VTLA, OVL2, VA02

Diagnostic

  1. Comparer journal et données d’expédition
  2. Examiner VTLA si nécessaire.

Solution

  1. Aligner uniquement dates ou données approuvées
  2. Regrouper postes éligibles.

Validation / paramétrage

Vérifier regroupement et engagements.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
