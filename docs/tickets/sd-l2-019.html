SD-L2-019 · L2

Unexpected delivery split

Problem

One order produces several deliveries.

Error message / number

Exact message and number not provided.

Root cause

Shipping point, route, dates or partial delivery criteria differ.

Affected modules

SD / LE

Transactions

VL01N, VL04, VTLA, OVL2, VA02

Diagnosis

  1. Compare split log and shipping data
  2. Inspect VTLA if necessary.

Solution

  1. Align only approved dates or master data
  2. Group eligible items via collective processing.

Validation / configuration

Check grouping and delivery commitments.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
