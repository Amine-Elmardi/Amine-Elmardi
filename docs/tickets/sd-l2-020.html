SD-L2-020 · L2

WM transfer order missing

Problem

Picking order not created automatically.

Error message / number

Exact message and number not provided.

Root cause

WM integration or delivery relevance incomplete.

Affected modules

SD / LE-WM

Transactions

VL02N, LT0A, LT12, LT21, OVLK

Diagnosis

  1. Check warehouse-managed storage location and delivery settings
  2. Inspect existing TO and log.

Solution

  1. Coordinate approved manual TO and confirmation of actual picking
  2. Escalate integration defect.

Validation / configuration

Verify picking and goods issue eligibility.
