SD-L2-021 · L2

Wrong delivering plant

Problem

Order proposes wrong plant.

Error message / number

Exact message and number not provided.

Root cause

Customer-material, customer or material default is incorrect.

Affected modules

SD-MD / MM

Transactions

VD53, VD51, XD03, XD02, MM02, VA02

Diagnosis

  1. Compare VD53, customer shipping and material sales data in priority order.

Solution

  1. Correct approved source
  2. Change order plant only after supply check.

Validation / configuration

Verify plant and reconfirm schedule lines.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
