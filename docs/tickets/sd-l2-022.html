SD-L2-022 · L2

Wrong payment terms on invoice

Problem

Billing has wrong terms and maturity.

Error message / number

Exact message and number not provided.

Root cause

Customer/order defaults or copying logic are incorrect.

Affected modules

SD Billing / FI-AR

Transactions

XD03, XD02, VA02, VF02, VF11, VTFL, VTFA

Diagnosis

  1. Compare customer company-code/sales-area data with order and invoice
  2. Check VTFL/VTFA.

Solution

  1. Correct approved source terms
  2. Coordinate existing invoice correction or cancellation according to FI status.

Validation / configuration

Verify invoice terms and FI maturity.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
