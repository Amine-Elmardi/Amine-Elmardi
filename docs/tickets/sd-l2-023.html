SD-L2-023 · L2

Alternative material not determined

Problem

Expected product substitution is not proposed.

Error message / number

Exact message and number not provided.

Root cause

Determination procedure, record or validity is missing.

Affected modules

SD Material Determination

Transactions

VB11, VB13, VA01, SPRO

Diagnosis

  1. Review VB13 original material and substitution reason/validity
  2. Check procedure assignment.

Solution

  1. Maintain approved VB11 substitution record
  2. Escalate procedure defects and verify manual versus automatic behavior.

Validation / configuration

Test original material entry and resulting alternative.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
