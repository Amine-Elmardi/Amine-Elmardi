SD-L2-024 · L2

ATP significantly below physical stock

Problem

Orders show shortages despite apparent physical stock.

Error message / number

Exact message and number not provided.

Root cause

Existing demands, reservations, safety stock or checking scope reduce ATP.

Affected modules

SD / ATP / MM / PP

Transactions

CO09, MD04, OVZ9, MM03, MB25

Diagnosis

  1. Compare CO09 supply/demand with MD04, reservations and safety stock
  2. Identify legitimate versus erroneous demand.

Solution

  1. Coordinate correction of confirmed erroneous requirements with MM/PP
  2. Escalate scope defect rather than deleting valid demand.

Validation / configuration

Verify ATP and retain legitimate reservations.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
