SD-L2-025 · L2

Annulation facture sans contrepassation FI

Problème

Facture d’annulation présente mais contrepassation absente.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Période, paramètres ou annulation FI antérieure empêchent transfert.

Modules concernés

SD Billing / FI

Transactions

VF11, VF02, VF03, OB52, FBL5N, VOFA

Diagnostic

  1. Examiner flux original/annulation et statut FI
  2. Contrôler période et type d’annulation avec FI.

Solution

  1. Résoudre transfert confirmé via procédure autorisée
  2. Éviter une seconde contrepassation manuelle sans rapprochement.

Validation / paramétrage

Vérifier pièces liées et soldes nets.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
