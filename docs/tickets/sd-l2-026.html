SD-L2-026 · L2

Credit memo remains open against invoice

Problem

Credit and invoice are visible as separate open items.

Error message / number

Exact message and number not provided.

Root cause

Credit posting alone does not clear the corresponding invoice.

Affected modules

SD / FI-AR

Transactions

VF03, FBL5N, F-32, FB05

Diagnosis

  1. Inspect VF03 accounting link and FBL5N invoice/credit references and amounts.

Solution

  1. Coordinate authorized clearing of matched items in F-32
  2. Handle partial credit according to agreed residual/partial-item treatment.

Validation / configuration

Verify clearing status and remaining customer balance.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
