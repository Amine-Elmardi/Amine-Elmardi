SD-L2-027 · L2

Contrôle marchandises dangereuses bloquant livraison

Problème

La livraison dangereuse ne peut avancer.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Données réglementaires ou conformité du transport incomplètes.

Modules concernés

SD / EHS Compliance

Transactions

VL02N, VL10A, DG01, DG02

Diagnostic

  1. Lire message exact
  2. Faire vérifier classification et restrictions par EHS.

Solution

  1. Faire corriger données confirmées ou organiser transport conforme par spécialistes autorisés
  2. Ne pas contourner blocage.

Validation / paramétrage

Obtenir validation conformité et relancer contrôle.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
