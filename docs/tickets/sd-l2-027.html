SD-L2-027 · L2

Dangerous goods check blocks delivery

Problem

Hazardous product delivery cannot proceed.

Error message / number

Exact message and number not provided.

Root cause

Required dangerous goods regulatory data or transport compliance is incomplete.

Affected modules

SD / EHS Compliance

Transactions

VL02N, VL10A, DG01, DG02

Diagnosis

  1. Read exact delivery blocking message
  2. Ask EHS to verify classification and applicable route restrictions.

Solution

  1. Have authorized EHS specialists correct verified master data or arrange compliant transport
  2. Do not bypass block.

Validation / configuration

Obtain compliance confirmation and rerun delivery check.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
