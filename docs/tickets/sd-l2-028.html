SD-L2-028 · L2

Debit memo request not billable

Problem

DR is excluded from due list or fails billing.

Error message / number

Exact message and number not provided.

Root cause

Incompletion, billing block or billing relevance prevents processing.

Affected modules

SD Billing / FI-AR

Transactions

VA03, VA02, VF04, VF01, VOV7, VTFA

Diagnosis

  1. Inspect DR status and incompletion
  2. Review DRN relevance and DR-to-L2 copy control.

Solution

  1. Complete verified fields and release block only with approval
  2. Escalate configuration defects
  3. Bill eligible request.

Validation / configuration

Verify debit memo and customer FI debit.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
