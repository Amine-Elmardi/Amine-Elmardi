SD-L2-029 · L2

Expired invoice output records cause backlog

Problem

Completed invoices are not dispatched for several days.

Error message / number

Exact message and number not provided.

Root cause

RD00 output records expired or were removed.

Affected modules

SD Billing / Output

Transactions

VF31, VV31, VV33, VF02, NACE

Diagnosis

  1. Review VF31 output errors and VV33 validity for relevant keys
  2. Identify already dispatched invoices.

Solution

  1. Maintain approved new validity and output medium
  2. Redetermine/reprocess eligible unsent output and monitor expiry.

Validation / configuration

Verify new automatic output and backlog clearance without duplicate dispatch.

Classification

L2: Functional analysis.
