SD-L2-030 · L2

Données de commerce extérieur absentes

Problème

Code marchandise ou origine manque pour douane.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Données article ou affectation conformité absentes.

Modules concernés

SD / MM / Trade Compliance

Transactions

MM02, VL03N, VF03, SPRO

Diagnostic

  1. Examiner livraison et classification avec conformité
  2. Identifier solution selon version.

Solution

  1. Maintenir code et origine approuvés via processus applicable
  2. Transmettre défaut réglementaire.

Validation / paramétrage

Vérifier données export et revue douanière.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
