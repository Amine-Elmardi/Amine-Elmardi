SD-L2-030 · L2

Export trade data missing from delivery

Problem

Commodity code or origin is absent for customs documentation.

Error message / number

Exact message and number not provided.

Root cause

Relevant material trade data or trade compliance assignment is missing.

Affected modules

SD / MM / Trade Compliance

Transactions

MM02, VL03N, VF03, SPRO

Diagnosis

  1. Check delivery and applicable material trade classification with compliance
  2. Identify release-specific foreign trade solution.

Solution

  1. Maintain approved commodity code and origin via applicable master process
  2. Escalate regulatory configuration issues.

Validation / configuration

Verify new delivery export data and customs review.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
