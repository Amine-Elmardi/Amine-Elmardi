SD-L2-031 · L2

Remise hiérarchique absente pour client enfant

Problème

La remise du nœud n’est pas sélectionnée.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Affectation, validité ou accès incohérent.

Modules concernés

SD Pricing / Customer Hierarchy

Transactions

VDH1N, VK11, VK13, V/07, V/08, VA02

Diagnostic

  1. Vérifier appartenance à date de prix et condition du nœud
  2. Tracer accès.

Solution

  1. Corriger données approuvées
  2. Transmettre accès manquant.

Validation / paramétrage

Recalculer commande test et vérifier remise.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
