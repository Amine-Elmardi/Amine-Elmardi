SD-L2-031 · L2

Hierarchy discount missing for child customer

Problem

Node-level discount is not selected for a subordinate customer.

Error message / number

Exact message and number not provided.

Root cause

Hierarchy assignment, validity or access sequence is inconsistent.

Affected modules

SD Pricing / Customer Hierarchy

Transactions

VDH1N, VK11, VK13, V/07, V/08, VA02

Diagnosis

  1. Check hierarchy membership at pricing date and node record
  2. Trace hierarchy access in pricing analysis.

Solution

  1. Correct approved hierarchy or condition data
  2. Escalate missing hierarchy access configuration.

Validation / configuration

Reprice approved test order and verify node discount.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
