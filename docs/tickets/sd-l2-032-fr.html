SD-L2-032 · L2

Ancien prix sélectionné à cause de la date de prix

Problème

Commandes reprennent des tarifs obsolètes.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Date de prix dans un ancien intervalle.

Modules concernés

SD Pricing

Transactions

VA02, VK13, VOV8, V/08

Diagnostic

  1. Comparer date avec accord et VK13
  2. Contrôler défaut du type si récurrent.

Solution

  1. Corriger date autorisée et recalculer selon type convenu
  2. Transmettre défaut systématique.

Validation / paramétrage

Vérifier validité et prix en préservant prix historiques voulus.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
