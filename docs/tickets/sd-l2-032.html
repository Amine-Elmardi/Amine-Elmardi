SD-L2-032 · L2

Historical price selected due to pricing date

Problem

Orders receive outdated condition prices.

Error message / number

Exact message and number not provided.

Root cause

Pricing date falls in an older validity interval.

Affected modules

SD Pricing

Transactions

VA02, VK13, VOV8, V/08

Diagnosis

  1. Compare actual pricing date with contract terms and VK13 intervals
  2. Check document-type default if recurring.

Solution

  1. Correct authorized date and use agreed repricing type
  2. Escalate incorrect systematic default.

Validation / configuration

Verify selected validity and price while preserving intended historical prices.

Classification

L2: Functional analysis.
