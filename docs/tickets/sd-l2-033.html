SD-L2-033 · L2

India GST conditions absent

Problem

IGST, CGST or SGST does not calculate as expected.

Error message / number

Exact message and number not provided.

Root cause

Tax registration, classifications, valid conditions or procedure are incomplete.

Affected modules

SD / FI Tax India

Transactions

VK11, VK13, XD02, MM02, OBBG, VA02

Diagnosis

  1. Verify registration and customer/material classifications
  2. Trace relevant GST accesses and assigned country procedure.

Solution

  1. Correct verified data and approved condition records with tax team
  2. Escalate configuration defects
  3. Reprice.

Validation / configuration

Check correct tax components and amount for transaction.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
