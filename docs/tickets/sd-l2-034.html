SD-L2-034 · L2

Invoice list does not consolidate invoices

Problem

Eligible invoices do not form one expected invoice list.

Error message / number

Exact message and number not provided.

Root cause

Invoice list cycle or grouping criteria differ.

Affected modules

SD Billing / FI-AR

Transactions

VF21, VF24, XD03, XD02, VTFL, FBL5N

Diagnosis

  1. Inspect payer invoice-list schedule and calendar
  2. Compare payer, currency, terms and actual split criteria.

Solution

  1. Correct approved master or configuration defect
  2. Create eligible list in VF21 or schedule applicable processing.

Validation / configuration

Verify list membership and reconcile FI according to actual invoice-list process.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
