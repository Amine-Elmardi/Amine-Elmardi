SD-L2-035 · L2

Livraisons partielles contraires à l’accord complet

Problème

Le client reçoit des livraisons partielles non convenues.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Indicateurs en-tête ou poste permettent fractionnement.

Modules concernés

SD / LE

Transactions

XD03, XD02, BP, VA02, VL01N

Diagnostic

  1. Examiner défauts client et indicateurs
  2. Confirmer accord avec service client.

Solution

  1. Maintenir paramètres approuvés et commandes éligibles
  2. Coordonner quantités déjà livrées.

Validation / paramétrage

Tester pénurie et vérifier livraisons autorisées.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
