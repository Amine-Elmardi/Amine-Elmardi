SD-L2-035 · L2

Partial shipments violate complete-delivery agreement

Problem

Customer receives partial shipments despite agreement.

Error message / number

Exact message and number not provided.

Root cause

Header complete-delivery or item partial-delivery settings allow splitting.

Affected modules

SD / LE

Transactions

XD03, XD02, BP, VA02, VL01N

Diagnosis

  1. Inspect customer shipping defaults and order header/item indicators
  2. Confirm agreed rule with customer service.

Solution

  1. Maintain approved complete/partial-delivery settings and update eligible orders
  2. Coordinate already shipped quantities.

Validation / configuration

Test shortage scenario and verify only permitted deliveries.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
