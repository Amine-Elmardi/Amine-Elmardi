SD-L2-036 · L2

Quantity contract consumption not updated

Problem

Release orders do not reduce the remaining target quantity.

Error message / number

Exact message and number not provided.

Root cause

Contract reference or statistical update is inconsistent.

Affected modules

SD Contracts

Transactions

VA43, VA02, MC84, MC8C, OVAM

Diagnosis

  1. Compare target and released quantity in VA43 with the release order document flow
  2. Inspect statistical updates separately.

Solution

  1. Correct confirmed reference or release settings
  2. Coordinate any necessary statistics reorganization only after verifying its scope.

Validation / configuration

Compare contract consumption and statistical report.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
