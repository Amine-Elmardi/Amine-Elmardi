SD-L2-037 · L2

Quantity discount scale triggers wrong step

Problem

Discount changes at unexpected quantity or rate.

Error message / number

Exact message and number not provided.

Root cause

Scale basis, unit or scale type differs from agreement.

Affected modules

SD Pricing

Transactions

VK11, VK12, VK13, V/06, VA01

Diagnosis

  1. Inspect VK13 scale table and unit conversions
  2. Trace condition in pricing analysis and review V/06 settings.

Solution

  1. Correct approved condition scale
  2. Escalate shared scale-type defects.

Validation / configuration

Test quantities immediately below, at and above thresholds.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
