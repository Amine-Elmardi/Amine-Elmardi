SD-L2-038 · L2

Date de livraison souhaitée non confirmée

Problème

L’échéance confirme une date tardive ou aucune.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Disponibilité ou délais empêchent la date souhaitée.

Modules concernés

SD / LE / ATP

Transactions

VA03, CO09, OVXB, OVLY, SCAL

Diagnostic

  1. Comparer dates, CO09, calendrier et délais de route.

Solution

  1. Coordonner dates réalistes
  2. Transmettre uniquement défauts de planification confirmés.

Validation / paramétrage

Vérifier confirmation et communiquer engagement réaliste.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
