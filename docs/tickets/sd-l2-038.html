SD-L2-038 · L2

Requested delivery date not confirmed

Problem

Schedule line confirms a later date or none.

Error message / number

Exact message and number not provided.

Root cause

Availability or scheduling lead times prevent the requested date.

Affected modules

SD / LE / ATP

Transactions

VA03, CO09, OVXB, OVLY, SCAL

Diagnosis

  1. Compare requested/confirmed dates, CO09, shipping calendar and route lead times.

Solution

  1. Coordinate realistic logistics dates
  2. Escalate only confirmed scheduling parameter defects for approved correction.

Validation / configuration

Verify confirmation and communicate realistic delivery commitment.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
