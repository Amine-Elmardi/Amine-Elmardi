SD-L2-039 · L2

Commande créée dans le mauvais domaine commercial

Problème

L’équipe responsable ne peut la traiter.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Domaine mal choisi, non modifiable simplement après création.

Modules concernés

SD Order

Transactions

VA01, VA02, VA03, SU3

Diagnostic

  1. Examiner commande et documents suivants
  2. Confirmer domaine correct.

Solution

  1. Rejeter les postes éligibles après accord et recréer correctement
  2. Coordonner documents suivants et défauts.

Validation / paramétrage

Comparer nouvelle commande et éviter double livraison.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
