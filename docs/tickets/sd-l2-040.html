SD-L2-040 · L2

Scheduling agreement confirmations missing

Problem

Customer schedule shows unconfirmed quantities.

Error message / number

Exact message and number not provided.

Root cause

Supply shortage or confirmation settings prevent ATP confirmation.

Affected modules

SD / PP Scheduling Agreements

Transactions

VA33, MD01, MD02, MD04, V_V2

Diagnosis

  1. Review schedule lines in VA33 and supply in MD04
  2. Check agreement type and confirmation relevance.

Solution

  1. Coordinate required planning and approved rescheduling
  2. Refer confirmed configuration issues.

Validation / configuration

Review actual confirmations and communicate feasible dates.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
