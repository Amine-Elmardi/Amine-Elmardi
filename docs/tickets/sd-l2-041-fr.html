SD-L2-041 · L2

Numéros de série absents à la sortie

Problème

La sortie d’un article sérialisé est rejetée.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Numéros requis ou profil manquants.

Modules concernés

SD / MM Serial Numbers

Transactions

MM03, MM02, IQ03, VL02N

Diagnostic

  1. Examiner profil et quantité
  2. Contrôler numéros réels dans IQ03.

Solution

  1. Affecter les numéros physiques vérifiés dans VL02N
  2. Transmettre le défaut de profil.

Validation / paramétrage

Vérifier nombre et pièce de sortie.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
