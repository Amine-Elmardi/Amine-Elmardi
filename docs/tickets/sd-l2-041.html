SD-L2-041 · L2

Serial numbers missing at goods issue

Problem

PGI is rejected for a serialized material.

Error message / number

Exact message and number not provided.

Root cause

Required serial numbers or serial profile settings are missing.

Affected modules

SD / MM Serial Numbers

Transactions

MM03, MM02, IQ03, VL02N

Diagnosis

  1. Inspect serial profile and delivery quantity
  2. Check actual serials in IQ03.

Solution

  1. Assign verified physical serial numbers in VL02N
  2. Escalate any profile defect for approved correction.

Validation / configuration

Verify serial count and goods issue document.

Classification

L2: Functional analysis.
