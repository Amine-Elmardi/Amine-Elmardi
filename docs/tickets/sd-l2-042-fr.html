SD-L2-042 · L2

Consommation du contrat en valeur non actualisée

Problème

Les appels ne réduisent pas la valeur ouverte.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Référence ou mise à jour de valeur/statistiques incohérente.

Modules concernés

SD Contracts

Transactions

VA41, VA43, VA03, MC84, MC8C, OVAM

Diagnostic

  1. Comparer valeurs VA43 et commandes référencées
  2. Examiner reporting séparément.

Solution

  1. Corriger référence ou configuration approuvée
  2. Réorganiser statistiques uniquement si justifié et autorisé.

Validation / paramétrage

Rapprocher valeur ouverte et reporting.

Classification

L2: Analyse fonctionnelle.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
