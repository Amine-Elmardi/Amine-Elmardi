SD-L2-043 · L2

Wrong bill-to party on invoice

Problem

Invoice names the wrong receiving entity.

Error message / number

Exact message and number not provided.

Root cause

Source partner or billing partner determination is incorrect.

Affected modules

SD Billing / FI-AR

Transactions

VA03, VA02, XD02, VF02, VF11, VTFL

Diagnosis

  1. Compare bill-to in order and billing document
  2. Review partner master and copying logic.

Solution

  1. Correct approved source partner
  2. Coordinate cancellation and rebilling if necessary based on accounting and dispatch status.

Validation / configuration

Verify recipient, partner data and FI reconciliation.

Classification

L2: Functional analysis.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
