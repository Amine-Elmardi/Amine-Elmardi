SD-L3-001 · L3

ATP confirme malgré stock insuffisant

Problème

La commande confirme tout malgré manque d’offre.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Groupe, règle ou périmètre inadapté.

Modules concernés

SD / ATP / MM

Transactions

MM03, MM02, OVAZ, OVZ9, CO09, VA02

Diagnostic

  1. Examiner groupe MRP3, CO09 et OVZ9
  2. Confirmer activation.

Solution

  1. Corriger données ou configuration approuvées après test
  2. Relancer ATP.

Validation / paramétrage

Vérifier confirmations réalistes.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
