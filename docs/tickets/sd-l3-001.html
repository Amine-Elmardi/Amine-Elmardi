SD-L3-001 · L3

ATP confirms despite insufficient stock

Problem

Order confirms full quantity regardless of supply.

Error message / number

Exact message and number not provided.

Root cause

Checking group, rule or scope is inappropriate.

Affected modules

SD / ATP / MM

Transactions

MM03, MM02, OVAZ, OVZ9, CO09, VA02

Diagnosis

  1. Inspect MRP3 checking group, CO09 and OVZ9 scope
  2. Confirm check activation.

Solution

  1. Correct approved master or configuration after testing
  2. Retrigger ATP in order.

Validation / configuration

Verify realistic schedule-line confirmations.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
