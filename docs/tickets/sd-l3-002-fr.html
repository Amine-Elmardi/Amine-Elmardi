SD-L3-002 · L3

Détermination de lot absente

Problème

Aucun lot proposé au poste géré par lots.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Stratégie/procédure ou lot éligible absent.

Modules concernés

SD / MM Batch

Transactions

MM03, MSC3N, VCH1, OVCH, VA02

Diagnostic

  1. Examiner MM03 et classification MSC3N
  2. Contrôler OVCH.

Solution

  1. Maintenir stratégie VCH1 approuvée
  2. Transmettre défaut de configuration
  3. Déclencher VA02 si applicable.

Validation / paramétrage

Vérifier lot et critères.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
