SD-L3-003 · L3

Base MWST incorrecte

Problème

Base trop haute ou basse.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Sous-total ou référence De/À utilise mauvaise valeur.

Modules concernés

SD / FI Tax

Transactions

V/08, V/06, VK13, VA01

Diagnostic

  1. Comparer ligne MWST et base au traitement approuvé.

Solution

  1. Corriger logique De/À ou sous-total dans V/08 après contrôle des routines alternatives.

Validation / paramétrage

Tester remises et rapprocher avec FI.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
