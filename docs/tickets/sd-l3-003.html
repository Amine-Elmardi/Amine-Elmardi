SD-L3-003 · L3

Incorrect MWST tax base

Problem

Calculated base is too high or low.

Error message / number

Exact message and number not provided.

Root cause

Subtotal or From/To reference uses wrong value.

Affected modules

SD / FI Tax

Transactions

V/08, V/06, VK13, VA01

Diagnosis

  1. Compare MWST row and base with approved discount/tax treatment.

Solution

  1. Correct approved From/To or subtotal logic in V/08 after checking alternative base routines.

Validation / configuration

Test discount scenarios and reconcile with FI.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
