SD-L3-004 · L3

Facture intersociétés IV absente

Problème

Livraison intersociétés sans facture interne.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Client interne, type ou copie incomplets.

Modules concernés

SD / FI Intercompany

Transactions

OVX0, VF01, VTFL, VOV8

Diagnostic

  1. Confirmer sociétés et client interne
  2. Examiner VTFL pour IV.

Solution

  1. Corriger configuration approuvée
  2. Créer IV uniquement pour livraison éligible.

Validation / paramétrage

Vérifier payeur interne et écriture FI de la société livreuse.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
