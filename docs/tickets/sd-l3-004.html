SD-L3-004 · L3

Intercompany invoice IV absent

Problem

Cross-company delivery produces no internal invoice.

Error message / number

Exact message and number not provided.

Root cause

Internal customer, billing type or copy control incomplete.

Affected modules

SD / FI Intercompany

Transactions

OVX0, VF01, VTFL, VOV8

Diagnosis

  1. Confirm company codes and internal customer
  2. Inspect VTFL for IV.

Solution

  1. Correct approved organizational/billing configuration
  2. Create IV only for eligible delivery.

Validation / configuration

Verify internal payer and delivering-company FI posting.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
