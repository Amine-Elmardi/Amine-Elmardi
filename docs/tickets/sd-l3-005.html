SD-L3-005 · L3

Order fields not copied to delivery

Problem

Batch, storage location or notes missing in delivery.

Error message / number

Exact message and number not provided.

Root cause

Copy requirements or data transfer routines do not transfer fields.

Affected modules

SD / LE / ABAP

Transactions

VTLA, VOFM, VL02N, VA02

Diagnosis

  1. Identify missing field and source value
  2. Inspect VTLA and VOFM routine.

Solution

  1. Coordinate approved configuration or ABAP correction
  2. Transport to QA.

Validation / configuration

Verify fields and regression-test other document combinations.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
