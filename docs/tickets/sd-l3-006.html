SD-L3-006 · L3

Order text lost in subsequent documents

Problem

Instructions are missing in delivery, invoice or output.

Error message / number

Exact message and number not provided.

Root cause

Text determination, copying or form reading is incomplete.

Affected modules

SD / Output

Transactions

VA02, VL02N, VF02, VTLA, VTFL, VOTXN

Diagnosis

  1. Check source/target text types and VOTXN
  2. Review transfer and form logic.

Solution

  1. Coordinate approved text or form correction
  2. Copy manually only in authorized individual case.

Validation / configuration

Test entire document and print text flow.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
