SD-L3-007 · L3

Pricing procedure not determined

Problem

Order conditions unavailable.

Error message / number

Exact message and number not provided.

Root cause

Sales area, document and customer procedure combination is absent.

Affected modules

SD Pricing

Transactions

VOV8, XD03, OVKK, V/08, VA01

Diagnosis

  1. Check VOV8 and customer procedure
  2. Inspect OVKK and V/08.

Solution

  1. Maintain approved OVKK assignment
  2. Test representative order.

Validation / configuration

Verify procedure and required conditions.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
