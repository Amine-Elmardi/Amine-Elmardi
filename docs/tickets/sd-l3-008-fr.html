SD-L3-008 · L3

Retour RE impossible avec référence facture

Problème

La commande de retour ne se crée pas.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Type, détermination de poste ou copie incomplets.

Modules concernés

SD / LE

Transactions

VA01, VOV8, VTAF, VOV4, VL01N, VL02N

Diagnostic

  1. Examiner RE VOV8, VOV4 et combinaison VTAF.

Solution

  1. Corriger configuration approuvée
  2. Créer retour et réception uniquement pour retour réel validé.

Validation / paramétrage

Vérifier référence et mouvement.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
