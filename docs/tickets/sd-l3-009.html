SD-L3-009 · L3

Revenue account determination fails

Problem

Billing cannot transfer to FI.

Error message / number

No G/L account found — Reported text; number not provided.

Root cause

Chart, sales org, assignment groups or account key mapping incomplete.

Affected modules

SD / FI-GL

Transactions

VF01, VF02, VKOA, V/08, FS00, XD03, MM03

Diagnosis

  1. Review V/08 account key, customer/material groups and VKOA access
  2. Check FS00.

Solution

  1. Maintain approved missing VKOA entry with FI
  2. Release billing after test.

Validation / configuration

Verify FI document and revenue account.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
