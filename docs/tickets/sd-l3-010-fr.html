SD-L3-010 · L3

Itinéraire non déterminé

Problème

La livraison manque d’itinéraire.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Zones, condition ou groupe de transport incompatibles.

Modules concernés

SD / LE

Transactions

OVR1, OVR2, OVXD, XD03, MM03, VL02N

Diagnostic

  1. Examiner zones et données
  2. Contrôler mapping.

Solution

  1. Corriger données ou configuration approuvées
  2. Saisie manuelle seulement autorisée.

Validation / paramétrage

Vérifier itinéraire et planification.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
