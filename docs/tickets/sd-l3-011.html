SD-L3-011 · L3

Shipping point not determined

Problem

Delivery creation lacks shipping point.

Error message / number

No shipping point could be determined — Reported text; number not provided.

Root cause

Plant, shipping condition and loading group combination is missing.

Affected modules

SD / LE

Transactions

VL01N, OVL2, XD03, MM03

Diagnosis

  1. Inspect customer shipping condition, material loading group and plant
  2. Check OVL2.

Solution

  1. Correct verified master data or approved OVL2 assignment
  2. Test in QA.

Validation / configuration

Verify shipping point and delivery.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
