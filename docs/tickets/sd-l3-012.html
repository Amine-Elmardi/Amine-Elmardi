SD-L3-012 · L3

Static or dynamic credit check incorrect

Problem

Permitted orders blocked or expected blocks absent.

Error message / number

Exact message and number not provided.

Root cause

Risk category, check type, horizon or exposure update inconsistent.

Affected modules

SD / Credit

Transactions

OVA8, FD32, FD33, VKM3, F.28

Diagnosis

  1. Compare OVA8 rule with customer risk/exposure
  2. Inspect horizon and update settings.

Solution

  1. Coordinate approved credit configuration with FI
  2. Test allowed and blocked scenarios in QA.

Validation / configuration

Verify exposure and preserve credit controls.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
