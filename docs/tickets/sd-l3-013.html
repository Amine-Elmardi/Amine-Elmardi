SD-L3-013 · L3

Third-party order has no purchase requisition

Problem

Direct supplier shipment order produces no requisition.

Error message / number

Exact message and number not provided.

Root cause

TAS item or CS schedule-line configuration incomplete.

Affected modules

SD / MM Third-party

Transactions

VA03, VOV7, VOV6, VOV4, ME53N, ME21N

Diagnosis

  1. Inspect actual item/schedule categories
  2. Review VOV7/VOV6 purchasing document settings.

Solution

  1. Correct approved third-party configuration
  2. Test new order.

Validation / configuration

Verify requisition references order in ME53N.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
