SD-L3-014 · L3

ATP ignores production dependent demand

Problem

Confirmed quantity overstates usable stock.

Error message / number

Exact message and number not provided.

Root cause

Relevant reservations or dependent requirements may be excluded by checking scope.

Affected modules

SD / ATP / PP

Transactions

OVZ9, CO09, MD04, VA02

Diagnosis

  1. Compare CO09 with MD04 demand and actual checking group/rule
  2. Review OVZ9 inclusion settings with PP.

Solution

  1. Correct approved scope only after impact analysis
  2. Recheck ATP for representative existing and new orders.

Validation / configuration

Verify demand categories and realistic confirmations.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
