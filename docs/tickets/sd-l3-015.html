SD-L3-015 · L3

Competing discounts applied together

Problem

Several discounts apply when only the agreed winner should apply.

Error message / number

Exact message and number not provided.

Root cause

Condition exclusion group or method is missing or wrong.

Affected modules

SD Pricing

Transactions

V/06, V/08, VA01, VK13

Diagnosis

  1. Inspect pricing analysis and competing conditions
  2. Review exclusion groups and procedure assignments.

Solution

  1. Configure approved exclusion rule for the agreed business outcome
  2. Test representative competing discounts.

Validation / configuration

Verify active and excluded conditions and net value.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
