SD-L3-016 · L3

Facture IV de transfert intersociétés absente

Problème

Livraison de transfert terminée sans facture interne.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Client interne de division réceptrice, pertinence ou copie incomplète.

Modules concernés

SD / MM / FI Intercompany STO

Transactions

ME23N, ME21N, VF01, OVX0, VTFL, FBL5N

Diagnostic

  1. Confirmer sociétés distinctes ME23N et sortie réelle
  2. Examiner paramètres livraison-IV applicables.

Solution

  1. Corriger configuration STO approuvée
  2. Créer IV éligible avec référence livraison.

Validation / paramétrage

Vérifier FI société fournisseuse et processus récepteur.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
