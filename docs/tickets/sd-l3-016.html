SD-L3-016 · L3

Cross-company STO invoice IV missing

Problem

Stock transport delivery completed without intercompany billing.

Error message / number

Exact message and number not provided.

Root cause

Receiving-plant internal customer, delivery/item relevance or copying configuration is incomplete.

Affected modules

SD / MM / FI Intercompany STO

Transactions

ME23N, ME21N, VF01, OVX0, VTFL, FBL5N

Diagnosis

  1. Confirm different company codes in ME23N and actual goods issue in document flow
  2. Review applicable delivery-to-IV settings.

Solution

  1. Correct approved STO billing configuration
  2. Create eligible IV referencing supplying delivery.

Validation / configuration

Verify supplying-company accounting and receiving-company process.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
