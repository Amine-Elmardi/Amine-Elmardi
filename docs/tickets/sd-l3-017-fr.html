SD-L3-017 · L3

Fractionnement excessif surchargeant le magasin

Problème

Commandes volumineuses génèrent trop de livraisons.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Dates, points, routes, partenaires ou logique spécifique diffèrent.

Modules concernés

SD / LE / ABAP

Transactions

VL10A, VA02, VTLA, VL01N

Diagnostic

  1. Examiner journal collectif et critères entre groupes
  2. Analyser routines avec ABAP.

Solution

  1. Corriger données communes approuvées ou logique confirmée
  2. Recréer livraisons non traitées après contrôle du statut aval.

Validation / paramétrage

Comparer nombre et conserver fractionnements légitimes.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
