SD-L3-017 · L3

Excessive delivery splits overload warehouse

Problem

Bulk orders generate unusually many deliveries.

Error message / number

Exact message and number not provided.

Root cause

Dates, shipping points, routes, partners or custom split logic differ.

Affected modules

SD / LE / ABAP

Transactions

VL10A, VA02, VTLA, VL01N

Diagnosis

  1. Inspect collective processing log and compare header criteria across delivery groups
  2. Review custom routines with ABAP.

Solution

  1. Correct only approved common data or confirmed split logic
  2. Recreate unprocessed deliveries only after checking downstream status.

Validation / configuration

Compare delivery count and verify legitimate splits remain.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
