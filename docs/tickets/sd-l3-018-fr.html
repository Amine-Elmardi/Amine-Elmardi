SD-L3-018 · L3

IDocs entrants ORDERS05 en erreur

Problème

Les commandes EDI ne créent pas de documents.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Profil, mapping, données ou traitement entrant défectueux.

Modules concernés

SD / EDI / ALE

Transactions

WE02, WE05, WE19, WE20, BD87, VA03

Diagnostic

  1. Examiner statut 51 et message WE02/WE05 pour ORDERS/type de base ORDERS05
  2. Contrôler WE20.

Solution

  1. Corriger données ou mapping approuvés avec intégration
  2. Tester WE19 en environnement contrôlé
  3. Retraiter IDocs éligibles BD87.

Validation / paramétrage

Vérifier commandes sans doublon de référence.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
