SD-L3-019 · L3

Calcul de coût à la commande non déclenché

Problème

Le poste ne possède pas l’estimation attendue.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Pertinence, classe de besoins ou variante incohérente.

Modules concernés

SD / CO-PC / PP

Transactions

VA02, CK11N, VOV7, OVZ0, OKK8

Diagnostic

  1. Examiner catégorie, stratégie/type et classe
  2. Contrôler paramètres avec CO.

Solution

  1. Corriger réglages approuvés
  2. Déclencher calcul de poste applicable sans le remplacer par un simple coût article.

Validation / paramétrage

Vérifier estimation avec CO.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
