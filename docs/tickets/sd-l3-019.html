SD-L3-019 · L3

Make-to-order costing not triggered

Problem

Sales order has no expected item cost estimate.

Error message / number

Exact message and number not provided.

Root cause

Costing relevance, requirement class or costing variant is inconsistent.

Affected modules

SD / CO-PC / PP

Transactions

VA02, CK11N, VOV7, OVZ0, OKK8

Diagnosis

  1. Review item category, strategy/requirement type and class
  2. Check sales order costing settings with CO.

Solution

  1. Correct approved settings
  2. Trigger applicable sales-order item costing rather than assuming a material estimate substitutes it.

Validation / configuration

Verify item cost estimate and reconcile with CO.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
