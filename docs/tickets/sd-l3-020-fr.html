SD-L3-020 · L3

Facturation de masse en échec avec erreurs diverses

Problème

Le traitement nocturne laisse des documents non traités.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Défauts différents de compte, période, numéro ou données.

Modules concernés

SD Billing / FI / Basis

Transactions

VF06, SM37, VKOA, OB52, VN01, VF01

Diagnostic

  1. Examiner SM37 et liste d’erreurs
  2. Regrouper par message et identifier réussites.

Solution

  1. Coordonner corrections approuvées SD/FI/Basis
  2. Retraiter uniquement les échecs après correction.

Validation / paramétrage

Rapprocher factures et écritures FI sans doublon.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
