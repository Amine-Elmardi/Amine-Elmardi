SD-L3-021 · L3

Demande d’acompte FAZ absente au jalon

Problème

Le jalon ne génère pas la demande attendue.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Règle de date ou paramétrage incomplet.

Modules concernés

SD Billing / FI-AR

Transactions

VA02, VF01, VOV7, OBXR, OVBI

Diagnostic

  1. Examiner plan, règle et FAZ
  2. Vérifier traitement spécial avec FI.

Solution

  1. Corriger plan ou configuration approuvés
  2. Créer FAZ éligible avec référence.

Validation / paramétrage

Vérifier demande/poste statistique distinct du paiement réel.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
