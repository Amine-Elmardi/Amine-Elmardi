SD-L3-021 · L3

Milestone down payment request FAZ missing

Problem

A project milestone does not generate the expected request.

Error message / number

Exact message and number not provided.

Root cause

Billing plan date rule or relevant billing configuration is incomplete.

Affected modules

SD Billing / FI-AR

Transactions

VA02, VF01, VOV7, OBXR, OVBI

Diagnosis

  1. Inspect milestone plan, rule and FAZ settings
  2. Review special G/L treatment with FI.

Solution

  1. Correct approved plan or configuration
  2. Create eligible FAZ request referencing the milestone.

Validation / configuration

Verify noted item/request and distinguish it from receipt of actual cash.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
