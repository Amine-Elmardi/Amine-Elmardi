SD-L3-022 · L3

Missing order reason affects profitability reporting

Problem

Management analysis lacks expected order-reason values.

Error message / number

Exact message and number not provided.

Root cause

Order reason is not consistently captured or transferred to relevant reporting characteristic.

Affected modules

SD / CO-PA

Transactions

OVAU, OVA2, V.02, KE24, KEDR

Diagnosis

  1. Inspect order AUGRU, incompletion settings and CO-PA characteristic mapping
  2. Confirm required reasons with business.

Solution

  1. Maintain approved reason codes and completeness control
  2. Coordinate characteristic derivation with CO and avoid fabricated historical values.

Validation / configuration

Test new order and verify reporting field.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
