SD-L3-023 · L3

IDoc facture sortant non envoyé

Problème

Système EDI client ne reçoit pas facture.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Sortie, profil INVOIC, port ou middleware incomplet.

Modules concernés

SD / EDI / ALE

Transactions

VF02, WE02, WE20, WE21, BD87, NACE

Diagnostic

  1. Examiner sortie et existence WE02
  2. Contrôler WE20 et port WE21 avec intégration.

Solution

  1. Corriger mapping approuvé
  2. Retraiter IDocs éligibles ou coordonner middleware après contrôle.

Validation / paramétrage

Confirmer réception sans doublon.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
