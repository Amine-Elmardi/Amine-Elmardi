SD-L3-024 · L3

Return receipt assigned to wrong storage location

Problem

Returned goods appear in unintended stock location.

Error message / number

Exact message and number not provided.

Root cause

Return location determination or delivery item assignment is wrong.

Affected modules

SD / MM / QM Returns

Transactions

OVLG, VL02N, MIGO, IQ03

Diagnosis

  1. Check return delivery item, plant and shipping point
  2. Review OVLG applicability and inspection stock requirements.

Solution

  1. Correct approved location determination or unposted delivery
  2. For posted goods coordinate eligible transfer with MM/QM rather than bypassing inspection.

Validation / configuration

Verify correct stock location and quality status.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
