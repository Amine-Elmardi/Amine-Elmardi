SD-L3-025 · L3

Returnable packaging stock not tracked

Problem

Pallets or crates delivered to customer are not visible in the expected tracking stock.

Error message / number

Exact message and number not provided.

Root cause

Packaging item or movement determination is inappropriate.

Affected modules

SD / MM Returnable Packaging

Transactions

VA01, VL01N, MMBE, MB52, VOV7

Diagnosis

  1. Inspect packaging material type LEIH, item category and material document
  2. Check customer special stock V.

Solution

  1. Correct approved packaging process settings with MM
  2. Use the applicable returnable-packaging movements, not consignment movements merely because the source scenario mentions them.

Validation / configuration

Verify customer packaging balances after delivery and return.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
