SD-L3-026 · L3

Revenue posted to wrong profit center

Problem

Billing revenue reaches unintended profit center.

Error message / number

Exact message and number not provided.

Root cause

Source account assignment, master data or derivation logic is inconsistent.

Affected modules

SD / FI / CO-PCA

Transactions

VF03, MM03, MM02, KEDR, KE5T

Diagnosis

  1. Trace VF03 accounting lines back to sales item and material profit center
  2. Distinguish FI profit center from CO-PA characteristic derivation.

Solution

  1. Correct approved source master or confirmed derivation rule with CO
  2. Coordinate historical adjustment separately.

Validation / configuration

Test new billing and reconcile profit center reporting.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
