SD-L3-028 · L3

Route schedule does not trigger shipment creation

Problem

Eligible deliveries do not generate expected shipments.

Error message / number

Exact message and number not provided.

Root cause

Route schedule assignment, transportation settings or automation job is incomplete.

Affected modules

SD / LE Transportation

Transactions

VL02N, OVR1, VT01N, VT04, SPRO

Diagnosis

  1. Inspect delivery route schedule and relevant shipment-type and job settings
  2. Confirm whether classic LE transportation is used.

Solution

  1. Correct approved schedule/automation configuration
  2. Create eligible shipment manually only if required and authorized.

Validation / configuration

Verify shipment reference, schedule and automatic processing test.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
