SD-L3-029 · L3

Sales BOM components not exploded

Problem

Only the header material appears in the sales order.

Error message / number

Exact message and number not provided.

Root cause

BOM usage, validity or item category/structure settings are incomplete.

Affected modules

SD / PP BOM

Transactions

CS03, CS01, MM03, MM02, VOV4, VA01

Diagnosis

  1. Check ERLA/LUMF group, active sales BOM in CS03 and item category determination.

Solution

  1. Correct approved BOM or relevant determination/structure settings with PP
  2. Test a fresh order.

Validation / configuration

Verify component explosion and intended pricing/delivery relevance.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
