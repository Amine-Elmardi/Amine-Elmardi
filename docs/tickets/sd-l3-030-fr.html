SD-L3-030 · L3

Configuration de variante KMAT en erreur

Problème

Le poste configurable échoue sur caractéristique ou dépendance.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Valeurs, profil, classe ou règles incomplets ou contradictoires.

Modules concernés

SD / LO-VC / PP

Transactions

VA01, CT04, CU41, CU50, CU01

Diagnostic

  1. Recueillir message et caractéristique
  2. Examiner profil/classe et simuler CU50.

Solution

  1. Coordonner correction approuvée avec équipe VC
  2. Tester combinaisons valides et invalides.

Validation / paramétrage

Vérifier configuration et composants dépendants.

Classification

L3: Paramétrage / évolution.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
