SD-L3-030 · L3

Variant configuration error for KMAT

Problem

Configurable sales item fails on characteristic or dependency.

Error message / number

Exact message and number not provided.

Root cause

Allowed values, profile, class or dependency rules are incomplete or conflicting.

Affected modules

SD / LO-VC / PP

Transactions

VA01, CT04, CU41, CU50, CU01

Diagnosis

  1. Capture exact editor error and characteristic
  2. Inspect profile/class and simulate configuration in CU50.

Solution

  1. Coordinate approved characteristic or dependency correction with VC team
  2. Test valid and invalid combinations.

Validation / configuration

Verify order configuration and consistent dependent components.

Classification

L3: Configuration / enhancement.
