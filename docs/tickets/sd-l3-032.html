SD-L3-032 · L3

Conflicting hierarchy rules derive wrong profitability segment

Problem

Customer and product hierarchy combinations populate unintended CO-PA characteristics.

Error message / number

Exact message and number not provided.

Root cause

Sequential derivation rules conflict or overwrite specific values.

Affected modules

SD / CO-PA

Transactions

KEDR, KE4ST, KE4I, KEND, KE24

Diagnosis

  1. Trace affected document data with applicable derivation test and inspect KEDR rule order and overwrite behavior
  2. Compare hierarchy fields and expected characteristics.

Solution

  1. Correct approved specific/general rule order and mappings with CO
  2. Test hierarchy combinations and plan historical realignment only if appropriate to the CO-PA model.

Validation / configuration

Validate KE24 characteristics and expected profitability breakdown, including unaffected cases.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
