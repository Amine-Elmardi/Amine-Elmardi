SD-L3-034 · L3

SD billing and FI receivables reconciliation mismatch

Problem

Audit identifies unexplained differences between billing and customer balances.

Error message / number

Exact message and number not provided.

Root cause

Missing FI transfers, independent reversals, partial payments or clearing may explain differences.

Affected modules

SD Billing / FI-AR Audit

Transactions

VFX3, VF05, VF03, FBL5N, VF11, FB08

Diagnosis

  1. Compare billing document links and FI customer items for consistent scope/date
  2. Review VFX3 as transfer exception list, not an open receivables report
  3. Classify differences by payment, clearing and reversal state.

Solution

  1. Resolve confirmed transfer or reversal defects with FI through authorized originating process
  2. Document valid payment/clearing differences instead of forcing totals to equal.

Validation / configuration

Reconcile document-level exceptions and obtain FI approval of explained residuals.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
