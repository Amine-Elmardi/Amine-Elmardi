SD-L3-035 · L3

Shipment freight cost differs from customer charge

Problem

Freight billing and actual shipment cost differ unexpectedly, causing margin and customer disputes.

Error message / number

Exact message and number not provided.

Root cause

Pricing or transfer logic is inconsistent, or shipment costing was not finalized before billing.

Affected modules

SD / LE Transportation / FI

Transactions

VT03N, VI03, VF03, VF11, VTFL, V/08

Diagnosis

  1. Compare shipment and cost document with invoice freight conditions
  2. Confirm agreed freight pricing versus actual cost and review copy/pricing logic.

Solution

  1. Correct approved condition or process setting with transportation and FI
  2. Coordinate invoice correction only if contractual billing is wrong
  3. Introduce completion check where needed.

Validation / configuration

Reconcile agreed charge and actual cost separately and test shipment-to-billing flow.

Classification

L3: Configuration / enhancement.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
