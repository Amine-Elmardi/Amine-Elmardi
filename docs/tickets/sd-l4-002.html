SD-L4-002 · L4

Billing batch performance blocks closing

Problem

Billing runtime increases from minutes to hours and delays closing.

Error message / number

Exact message and number not provided.

Root cause

Volume, inefficient custom exits, database bottlenecks or job design may be responsible.

Affected modules

SD Billing / Basis / ABAP

Transactions

VF06, SM37, SM50, ST05, ST12, VF04, SM36

Diagnosis

  1. Inspect SM37 throughput and SM50 processes with Basis
  2. Use approved ST05/ST12 tracing to isolate costly operations
  3. Review billing exits and workload distribution.

Solution

  1. Optimize confirmed bottleneck with Basis/ABAP
  2. Partition eligible documents into disjoint monitored jobs only if capacity and locking permit
  3. Avoid overlapping runs.

Validation / configuration

Measure runtime and reconcile all processed documents;Define performance baseline and alert thresholds.

Classification

L4: Major projects / critical cross-functional incidents.
