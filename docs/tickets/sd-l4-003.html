SD-L4-003 · L4

Contract termination requires coordinated mass order cancellation

Problem

A major contract ends with hundreds of open orders and partially processed deliveries/invoices.

Error message / number

Exact message and number not provided.

Root cause

Different downstream statuses require distinct cancellation actions and sequencing.

Affected modules

SD / LE / FI / Contract Management

Transactions

VA05, VA02, VL02N, VL09, VF11, OVAG

Diagnosis

  1. Obtain written commercial/legal scope and effective date
  2. Extract open orders and classify unshipped, goods-issued, billed and partially fulfilled items
  3. Identify financial obligations.

Solution

  1. Cancel eligible unposted deliveries, coordinate actual returns/reversal only where justified, and agree invoice credits/cancellations with FI
  2. Reject eligible remaining order items in controlled batches using approved reasons.

Validation / configuration

Reconcile cancelled quantities and values, remaining commitments and FI records;Obtain business sign-off.

Classification

L4: Major projects / critical cross-functional incidents.
