SD-L4-006 · L4

Panne d’intégration CRM avec important retard de commandes

Problème

Les commandes externes n’arrivent plus dans ERP.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Connexion, authentification, mapping, données ou file middleware potentiellement en cause.

Modules concernés

SD / CRM / Middleware / Basis

Transactions

SM59, WE02, BD87, VA03, XD01, MM01

Diagnostic

  1. Escalader à intégration
  2. Examiner monitoring et identifiants de corrélation
  3. Contrôler connexion autorisée et statut IDoc si applicable
  4. Identifier commandes déjà créées.

Solution

  1. Corriger défaut confirmé de connexion, mapping ou données vérifiées
  2. Rejouer uniquement échecs par lots avec protection contre doublons.

Validation / paramétrage

Vérifier commandes représentatives et rapprocher retard CRM avec références ERP avant reprise.

Classification

L4: Projets majeurs / incidents critiques transverses.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
