SD-L4-006 · L4

CRM order integration outage creates large backlog

Problem

Orders from external CRM are not reaching ERP, halting processing.

Error message / number

Exact message and number not provided.

Root cause

Middleware connectivity, authentication, payload mapping, missing master data or queue backlog may be responsible.

Affected modules

SD / CRM / Middleware / Basis

Transactions

SM59, WE02, BD87, VA03, XD01, MM01

Diagnosis

  1. Escalate to integration team
  2. Inspect middleware message monitoring and correlation IDs
  3. Check authorized connectivity and IDoc status where applicable
  4. Identify already created orders.

Solution

  1. Correct confirmed connection, mapping or verified master data issue
  2. Replay only failed messages with idempotency/duplicate checks in controlled batches.

Validation / configuration

Confirm representative orders and reconcile CRM backlog with ERP order references before full restart.

Classification

L4: Major projects / critical cross-functional incidents.
