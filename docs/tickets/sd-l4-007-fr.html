SD-L4-007 · L4

Intégration sortante EWM empêchant la sortie

Problème

Livraisons magasin bloquées, expéditions retardées.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Tâches incomplètes ou erreurs qRFC peuvent empêcher synchronisation.

Modules concernés

SD / EWM / Basis

Transactions

SMQ1, SMQ2, /SCWM/MON, VL02N

Diagnostic

  1. Examiner livraison et tâches dans /SCWM/MON
  2. Tracer files entrantes/sortantes des deux systèmes et message exact
  3. Confirmer mouvement physique.

Solution

  1. Coordonner correction confirmée avec EWM/Basis
  2. Retraiter messages autorisés dans l’ordre avec protection doublon
  3. Ne pas supprimer files ou comptabiliser une seconde sortie sans rapprochement.

Validation / paramétrage

Tester nouvelle livraison et rapprocher stock/statuts FI EWM-ERP avant reprise.

Classification

L4: Projets majeurs / incidents critiques transverses.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
