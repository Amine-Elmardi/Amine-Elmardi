SD-L4-008 · L4

Global pricing calculation type changed incorrectly

Problem

A percentage or fixed-amount condition calculates wrong prices across orders.

Error message / number

Exact message and number not provided.

Root cause

The condition calculation type was changed without preserving record semantics.

Affected modules

SD Pricing / FI / Change Management

Transactions

V/06, VK12, VA05, VA02, SE10, STMS

Diagnosis

  1. Declare major incident and determine affected condition types, records and document scope
  2. Compare V/06 to approved design
  3. Assess effect on already billed orders.

Solution

  1. Restore approved type via tested emergency transport
  2. Review and correct affected condition records and reprice eligible open orders in controlled batches
  3. Agree billing corrections with FI.

Validation / configuration

Test scale, unit and amount scenarios and reconcile corrected orders and revenue.

Classification

L4: Major projects / critical cross-functional incidents.
