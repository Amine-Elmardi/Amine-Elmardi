SD-L4-009 · L4

Go-live cutover leaves legacy deliveries unresolved

Problem

In-flight legacy deliveries cause opening-stock discrepancies in the new system.

Error message / number

Exact message and number not provided.

Root cause

Cutover mapping did not include outstanding goods movements and their timing.

Affected modules

SD / MM / LE / Migration Cutover

Transactions

MMBE, MI01, MI07, VA05, LSMW, MB1C (legacy)

Diagnosis

  1. Enforce approved transaction freeze and extract open deliveries with material, quantity, plant and physical shipment status
  2. Reconcile legacy closing stock to SAP opening stock.

Solution

  1. Choose approved completion-in-legacy or migration-of-open-delivery strategy with project and FI/MM
  2. Apply only verified stock adjustments via supported migration process
  3. Avoid double goods issue.

Validation / configuration

Reconcile physical count, opening values and delivery status;Obtain business sign-off before release.

Classification

L4: Major projects / critical cross-functional incidents.
