SD-L4-011 · L4

Intercompany process fails after organizational restructure

Problem

Cross-company sales and billing stop after plant/company-code changes.

Error message / number

Exact message and number not provided.

Root cause

Organizational assignments, internal partner or intercompany copy control no longer match.

Affected modules

SD / MM / FI Enterprise Structure

Transactions

SPRO, OVX0, VTFL, VF01, STMS

Diagnosis

  1. Suspend affected flows in coordination with business
  2. Map old/new plant, company code and sales organization relationships
  3. Inspect internal customer and IV determination.

Solution

  1. Correct approved organizational and billing settings in DEV
  2. Test order, delivery, external invoice and IV with postings in both companies
  3. Transport under controlled cutover.

Validation / configuration

Reconcile inventory and accounting in both entities before reopening processing.

Classification

L4: Major projects / critical cross-functional incidents.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
