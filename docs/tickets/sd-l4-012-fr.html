SD-L4-012 · L4

Corruption massive des limites de crédit bloquant les commandes

Problème

Une mise à jour de masse bloque le traitement des commandes.

Message / numéro d’erreur

Texte exact et numéro non indiqués.

Cause racine

Les limites chargées sont erronées, éventuellement nulles.

Modules concernés

SD Credit / FI / Migration

Transactions

SM37, FD32, FD33, F.28, VKM1, VKM3

Diagnostic

  1. Suspendre le chargement défectueux
  2. Comparer limites et exposition aux valeurs sauvegardées approuvées
  3. Recenser commandes bloquées.

Solution

  1. Restaurer les limites vérifiées via processus autorisé
  2. Réévaluer commandes par lots contrôlés avec accord crédit, sans libération globale.

Validation / paramétrage

Vérifier limites, exposition et blocages légitimes;Documenter incident et double contrôle.

Classification

L4: Projets majeurs / incidents critiques transverses.

Cas pédagogique adapté de supports de formation, non validé indépendamment dans SAP. Transactions selon version. Modifications en production uniquement avec autorisation.
