SD-L4-013 · L4

Mass customer migration created duplicate accounts

Problem

Many business partners have duplicate customer numbers after bulk creation.

Error message / number

Exact message and number not provided.

Root cause

The migration lacked reliable duplicate matching on verified identifying data.

Affected modules

SD-MD / FI / Migration

Transactions

LSMW, XD03, XD05, RFDKAG00, VA02, F-30

Diagnosis

  1. Stop faulty upload and affected order creation as authorized
  2. Use duplicate analysis by verified tax ID, name/address and existing document history
  3. Identify authoritative record with data owner.

Solution

  1. Block confirmed duplicates through approved master governance without deleting history
  2. Coordinate open order recreation or eligible partner corrections and FI open-item handling separately
  3. Implement validated duplicate prevention.

Validation / configuration

Verify active master selection, document continuity and reconciled balances.

Classification

L4: Major projects / critical cross-functional incidents.
