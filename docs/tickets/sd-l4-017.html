SD-L4-017 · L4

Open sales order migration has incorrect values at go-live

Problem

Migrated orders contain wrong prices, quantities or dates, affecting deliveries and invoices.

Error message / number

Exact message and number not provided.

Root cause

Legacy field mapping or conversion rules were defective.

Affected modules

SD / Migration / LE / FI

Transactions

VA05, VA02, LSMW, VF04, SM37

Diagnosis

  1. Coordinate controlled freeze of affected follow-on processing
  2. Extract migrated orders and compare field by field with validated legacy data
  3. Identify follow-on documents.

Solution

  1. Correct approved mapping and eligible order fields
  2. Reject and recreate only when document status permits
  3. Track all delta corrections and coordinate posted invoice/delivery corrections.

Validation / configuration

Obtain business sign-off on reconciled orders and downstream data before restart.

Classification

L4: Major projects / critical cross-functional incidents.
