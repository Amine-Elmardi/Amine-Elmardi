SD-L4-018 · L4

Payment authorization outage halts e-commerce orders

Problem

Card-based orders fail authorization across the channel.

Error message / number

Exact message and number not provided.

Root cause

External PSP availability, connectivity or authorization configuration may be defective.

Affected modules

SD / Payment Cards / Basis / PSP

Transactions

OV9A, OVAC, SM59, SLG1, VA01

Diagnosis

  1. Escalate to payment provider and infrastructure
  2. Inspect application logs and applicable payment-card configuration
  3. Have Basis test authorized RFC/API connectivity without exposing card data.

Solution

  1. Restore confirmed connection or approved configuration
  2. Use only an existing compliant alternative payment process if business authorizes it
  3. Avoid duplicate authorization or capture.

Validation / configuration

Test a controlled order and reconcile PSP and SAP authorization state before resuming full traffic.

Classification

L4: Major projects / critical cross-functional incidents.

Training case adapted from learning material; not independently validated in an SAP system. Transactions depend on release. Production changes require authorization.
