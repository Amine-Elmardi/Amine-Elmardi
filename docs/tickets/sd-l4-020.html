SD-L4-020 · L4

System-wide invoice dispatch outage

Problem

Invoices have not been printed or emailed for an extended period, delaying collections.

Error message / number

Exact message and number not provided.

Root cause

A shared output job, condition validity, mail or spool infrastructure may have failed.

Affected modules

SD Output / Basis

Transactions

SCOT, SM37, SP01, VV33, VV31, VF31, NACE

Diagnosis

  1. Open cross-team incident
  2. Inspect SCOT send logs, SP01 spool, SM37 output job and VV33 validity
  3. Identify already delivered outputs.

Solution

  1. Repair the confirmed component with Basis or SD
  2. Reprocess only eligible unsent outputs in monitored batches via applicable VF31 or output framework.

Validation / configuration

Confirm recipient delivery and absence of duplicate dispatch;Establish daily output failure monitoring.

Classification

L4: Major projects / critical cross-functional incidents.
